怎么读（方法）

  1. 先读完，再抠词。第一遍尽量不点词，抓大意；卡壳再点蓝色/朱砂词。
  2. 语境里记。释义只给中文义 + 一句例句，不堆同义词表。
  3. 朱砂标高考常考。红褐色词优先进你的复习本。
  4. 三道轻题收口。对错立刻反馈，不排名、不徽章轰炸。
  5. 一天一篇就够。碎片时间用手机读，比硬啃词表更容易坚持。
