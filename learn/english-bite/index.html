更新说明

  1. 难度阶梯。书架用标签区分「高一试读 / 高二 / 高考冲刺」；每张卡片和篇内抬头都标深度与难度星级（各 ★×5），一眼可判。
  2. 材料口径。短文为原创，篇幅与词汇密度贴近高考阅读常见特征（论述链、学术向实词、推断题），不粘贴真题原文或报纸成篇转载。
  3. 怎么加篇。优先 STEM／社会议题 → 标星级 → 写入 sessions.json → 挂进本页。先稳高二基准（约 300–380 词），再向冲刺加长加难。
  4. 与词根馆。释义里的词根链回 ieso-vocab；词根馆不再内嵌情景短文。

怎么读

  1. 先读再抠词。朱砂词优先进复习本。
  2. 题型围着记忆转。配对、填空、用法、限时回忆 + 读懂／推断；可选随手一想。
  3. 看星选篇。深度看概念链条，难度看词汇与推断；同一标签下也可按星级递进。
