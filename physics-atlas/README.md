物理学图谱｜简体中文交互式离线版

这是基于 Nathan Liow 的 Atlas of Physics MIT 开源项目构建的中文离线版本。主页进入后可打开 15 个章节；每章保留原项目的 Three.js 实时 3D 场景、动画、滚动/滑动翻页、拖拽旋转视角、触控点击模型拆解、练习答题及跨章跳转。教材正文与题目使用简体中文译稿。

启动（无需联网）：
1. 解压整个 ZIP。
2. Windows 双击“开始离线版.bat”；macOS/Linux 在项目目录执行 ./开始离线版.command（需要 Python 3）。
3. 浏览器打开 http://127.0.0.1:8137/ 。

由于浏览器安全规则，必须经本地服务器打开，不要直接双击 index.html。服务器仅监听本机；不访问外网，不上传数据。请保留 vendor、各章节文件夹和资源目录，不要拆开移动。

交互：滚动或滑动翻页；拖动旋转 3D 场景；Shift+拖动（电脑）平移；点击/轻触场景对象查看拆解；按 Esc 或点空白处关闭；左右方向键翻页。公式表可从主页打开，公式链接会跳到对应章节页。

附带“离线阅读版.html”作为纯文字补充阅读；动态交互入口是本目录的 index.html。
