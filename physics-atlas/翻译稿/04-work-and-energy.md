# 第 4 章：功与能

## 功

### 力在一段距离上做功

**功**是力传入物体或从物体带走的能量。只有物体在力作用期间发生移动，该力才做功。

$$W = |F|\,|\Delta x|\cos\theta$$

`θ` 是力与位移之间的夹角。功的单位是焦耳：`1 J` 就是 `1 N` 的力作用 `1 m` 所做的功。

一根绳子以 `30°` 的角度，用 `20 N` 的力拉着这个 `4.0 kg` 的箱子在无摩擦地面上移动。只有 `F cos θ = 17.3 N` 的分量沿运动方向。`F sin θ = 10.0 N` 的分量横向拉它，不做功。在 `3.12 m` 的距离上，绳子做功 `54.0 J`，小于水平拉力本来会做的 `62.4 J`。

**图表：** 功与位移的关系。横轴：位移 `Δx (m)`；纵轴：绳子做的功 `(J)`；曲线标签：`θ = 0°`、`θ = 30°`。

**图注：** `30°` 角的拉力。

## 4.1 正功与负功

### 与运动同向或反向

沿运动方向的力（`θ < 90°`）做**正功**：物体获得动能。与运动反向的力（`θ > 90°`）做**负功**：物体失去动能。

一个质量为 `0.50 kg` 的球以 `6.0 m/s` 的速度向上抛出：上升时，重力与运动方向相反（`θ = 180°`），到达球停止的最高点时，重力做功 `−9.0 J`。下落时（`θ = 0°`），重力把 `9.0 J` 还回来。各能量条相加：`K₀ + W_g = K`。

**图表：** 动能和重力做功与时间的关系。横轴：时间 `(s)`；纵轴：能量 `(J)`；曲线标签：`K`、重力做功。

> 箭头：`v` 每 `m/s` 对应 `15 cm`，`F_g` 每 `N` 对应 `10 cm`。能量条：每 `J` 对应 `12 cm`。

**图注：** 逆着重力向上，顺着重力向下。

## 4.2 不做功的力

### 与运动方向垂直

与位移成 `90°` 角的力不做功，因为 `cos 90° = 0`。它可以改变运动方向，但永远不会改变速度大小。

一个质量为 `0.50 kg` 的球系在长 `1.0 m` 的绳子上，以 `3.0 m/s` 的速度在光滑桌面上转圈。绳子以 `<i>T</i> = 4.5 N` 的力把它拉向中心，并始终横切其速度方向。它的动能保持为 `2.25 J`。

圆轨道上的卫星也是同样的情况：重力指向行星，横切速度方向，所以重力不对它做功。水平地面上的支持力也不做功。

**图表：** 功与角度的关系。横轴：角度 `θ (°)`；纵轴：`10 N` 的力在 `1 m` 上所做的功 `(J)`；标记：`90°` 时为零，正功，负功。

> 点击球查看更早的时刻。`v`：每 `m/s` 对应 `25 cm`；`T`：每 `N` 对应 `15 cm`。

**图注：** 横切速度方向的张力。

## 4.3 动能

### 功—能定理

**动能**是运动的能量，`K = ½mv²`。它是标量，单位为焦耳，并且永远不为负。

**功—能定理：** 合功等于动能的变化。

$$W_{net} = \Delta K = ½mv_f^2 − ½mv_0^2$$

行驶 `7.20 m` 后，道路做功 `21.60 kJ`，汽车速度达到 `6.0 m/s`：`½ × 1200 × 6.0² = 21.60 kJ`。两根能量条一起增长。

**图表：** 动能与距离的关系。横轴：距离 `(m)`；纵轴：`K = W_net (kJ)`；斜率：`F = 3.0 kN`。

> 点击汽车：重力和支持力不做功。箭头：每 `kN` 对应 `25 cm`。能量条：每 `kJ` 对应 `7.5 cm`。

**图注：** 合功输入，动能输出。

## 4.4 重力势能

### 高度所对应的能量

**势能**是取决于位置的储存能量。在地球表面附近，

$$U_g = mg\Delta y$$

其中，`Δy` 是相对于你选定的 `U_g = 0` 位置测量的高度差。它等于把物体逆着重力提升到那里所需的最小功。

这个 `0.50 kg` 的球从 `3.0 m` 高处落下：`U_g = 14.7 J`，`K = 0`。下落时，`U_g` 转化为 `K`；就在落地前，`K = 14.7 J`，所以 `v = 7.67 m/s`。从某一高度释放时，`U_{g0} = K_f`。

**图表：** 势能和动能与高度的关系。横轴：距地面的高度 `(m)`；纵轴：能量 `(J)`；曲线标签：`E`、`U_g`、`K`。

> 点击球以移动零点。能量条：每焦耳对应 `10 cm`。

**图注：** 高度变成速度。

## 4.5 弹簧势能

### 胡克定律

弹簧会向其自然长度方向推回；压缩或伸长得越多，反推力越大。

| 公式 | 说明 |
|---|---|
| `F_s = −kΔx` | 与 `Δx` 反向；`k` 的单位为 `N/m` |
| `U_s = ½kΔx²` | 储存的能量 |

当 `k = 50 N/m` 时，质量为 `2.0 kg` 的物块（`K = 4.0 J`）在 `Δx = 0.40 m` 处停止：全部 `4.0 J` 被储存起来，随后又全部释放。功就是**力—位移图像下的面积**；在 `kx` 曲线下方，它是一个三角形：`½ · Δx · kΔx`。

**图表：** 弹簧力与压缩量的关系；阴影面积等于储存的能量。横轴：压缩量 `Δx (m)`；纵轴：弹簧力 `(N)`。

> 无摩擦。箭头：每牛顿 `4 cm`。能量条：每焦耳 `30 cm`。

## 4.6 · AP Physics C：变化力所做的功

### `F(x)` 下的面积

当力沿途发生变化时，把路径切成许多窄条，对每一条加上 `FΔx`，再让这些窄条不断变薄。这些和就变成**`F(x)` 图像下的面积**：

$$W = \lim \sum F(x_i)\Delta x = \int F(x)\,dx$$

一个质量为 `5.0 kg` 的箱子在光滑地面上受到 `F = F_0(1 − x/L)(1 + 2x/L)` 的力；力从 `16 N` 逐渐减小，并在 `L = 3.0 m` 处变为 `0`。积分得 `W = ⅚F_0L = 40.0 J`，全部转化为动能。

**图表：** 推力与位置的关系；箱子移动到的位置以前的面积为阴影，并画出了六个窄条。横轴：位置 `x (m)`；纵轴：推力 `F(x) (N)`。

> `6` 个窄条（虚线）为 `40.2 J`；`64` 个窄条为 `40.002 J`。比例：`5 cm/N`。

**图注：** 功是 `F(x)` 下的面积。

## 4.7 能量守恒

### 机械能保持不变

当没有摩擦或阻力时，机械能 `E = K + U_g + U_s` 保持不变。

$$U_{g0} + U_{s0} + K_0 = U_{gf} + U_{sf} + K_f$$

一个质量为 `1.0 kg`、绳长为 `2.0 m` 的摆球从 `40°` 处释放。在两端，能量全部是 `U_g`，为 `4.59 J`。在最低点，能量全部是 `K`，速度为 `3.03 m/s`。绳子的拉力横切运动方向，因此不做功。提示：先找出为零的项（两端 `v = 0`，最低点 `Δy = 0`）。

**图表：** 能量条：`K`、`U_g` 和 `E`。

> 点击摆球，将其重力分解。箭头：每牛顿 `8 cm`。能量条：每焦耳 `30 cm`。

**图注：** `K` 与 `U` 互相转换。

## 4.8 · AP Physics C：由势能求力

### `U` 的负斜率

由于 `dW = F dx = −dU`，保守力就是 `U(x)` **斜率的负值**：它指向下坡方向，在 `U` 平坦的地方为零。

$$F_x = −dU/dx$$

一个质量为 `0.20 kg` 的小珠在光滑导线上运动，`x` 沿导线测量：`U = mgh(x)`。

**图表：** 导线上的势能，以及小珠所在处的切线。横轴：沿导线的 `x (m)`；纵轴：`U (J)` 及其切线 `；曲线标签：`E`。

## 4.9 · AP Physics C：能量图

### 转向点与平衡

在总能量 `E` 处画一条水平线：它与 `U(x)` 之间的间隔就是 `K`。粒子在**转向点**处折返，此时 `U = E`。

| 状态 | 条件与说明 |
|---|---|
| 稳定 | `U` 最小，`U″ > 0`：`F` 将其推回 |
| 不稳定 | `U` 最大，`U″ < 0`：`F` 将其推离（山丘） |
| 中性 | `U` 平坦：没有力（导线的右端） |

一个轻原子与一个重原子结合，总能量为 `E = −0.6 eV`。在势阱底部附近，势阱表现得像弹簧，`k = U″`：

$$ω² = U″(x_0)/m \to T = 11.3 fs$$

## 4.10 非守恒情形

### 摩擦把能量变成热

摩擦和阻力是**阻力**。它们指向运动的反方向，所以做功总是负的。它们带走的机械能变成热能。

$$E_{mech,i} = E_{mech,f} + |W_{resistive}|$$

质量为 `2.0 kg` 的物块以 `4.0 m/s` 的速度滑上粗糙地面。`μ_k = 0.40` 时，摩擦力为 `f = μ_kmg = 7.84 N`。它滑过 `2.04 m` 后停止：`|W_f| = f·d = 16.0 J`，这正好是它全部的 `K`。`E_mech` 降到零；但包括热能在内的总能量从不改变。

**图表：** 动能和热能与滑行距离的关系。横轴：滑行距离 `(m)`；纵轴：能量 `(J)`；曲线标签：总能量、`K`、热能。

> 点击物块。箭头：每牛顿 `5 cm`。能量条：每焦耳 `8 cm`。

**图注：** 动能变成热。

## 4.11 功率

### 做功的快慢

**功率**是做功的速率，也就是把能量从一种形式转化为另一种形式的速率。功率的单位是瓦特：`1 W = 1 J/s`，且 `1 horsepower = 746 W`。

$$P = W/t = F\Delta x/t = Fv$$

两个质量均为 `10 kg` 的箱子以恒定速度上升 `2.0 m`，所以每根绳子的拉力都是 `T = mg = 98 N`，并做功 `196 J`。快的箱子用时 `2.0 s`：`98 W`。慢的箱子用时 `4.0 s`：`49 W`。做功相同，功率却是两倍。已知速度和时间时，`P = ΔE/t` 通常是最快的求法。

**图表：** 快速和慢速做功与时间的关系。横轴：时间 `(s)`；纵轴：做功 `(J)`；曲线标签：快速：斜率 `98 W`；慢速：`49 W`。

> 忽略短暂的启动和停止过程。箭头：每牛顿 `0.8 cm`。

**图注：** 相同的功，用时一半。

## 点击场景：它所分解出的组成部分

### 拉力 `pull`

拉力分解为两个分量（灰色）。`F cos θ` 沿位移方向，完成全部功。`F sin θ` 竖直向上，与运动成 `90°` 角，不做功；它只使地面对箱子的向上推力变小。

事实：

- `F cos θ (along Δx)`：`17.3 N`
- `F sin θ (across)`：`10.0 N，不做功`
- `Δx`：位移 `x(t)`，随动画时间 `t` 变化
- `W = F Δx cos θ`：功 `W(t)`，由当前位移 `x(t)` 决定
- `K = ½mv²`：动能 `K(t)`，由当前速度 `v(t)` 决定

### 抛球 `toss`

观察重力与速度之间的夹角。向上时二者反向（`180°`）：重力做负功，`K` 能量条缩短。向下时二者同向（`0°`）：功为正，`K` 又增长。任意时刻都有 `K = K₀ + W_g`。

事实：高度为 `y(t)`，速度为 `v(t)`，二者随动画时间 `t` 变化；截至当前时刻重力做功为 `W_g(t) = −mg\,y(t)`，动能满足 `K(t) = K₀ + W_g(t)`。

### 圆周运动 `whirl`

每隔四分之一圈取一个更早的时刻：在每个时刻，张力（指向固定点）与速度（沿圆周方向）都成 `90°`。在任意一个很小的步长中，位移沿着 `v`，因此 `T·Δx·cos 90° = 0`。重力和桌面的支持力也都是竖直的，同样不做功。

事实：张力 `T` 为 `4.5 N`；`T` 与 `v` 的夹角为 `90°`；`T` 做功 `0 J`；速度 `3.0 m/s`，保持不变；`K` 为 `2.25 J`，保持不变。

### 汽车 `car`

重力和支持力都是竖直的，与运动成 `90°`，所以不做功，可以忽略。沿 `Δx` 的唯一力是道路的推力，它也就是合力（红色）。它所做的功 `F·Δx` 就是动能的全部变化。

事实：道路向前的力 `F` 为恒定的 `3.0 kN`；位移为 `Δx(t)`，速度为 `v(t)`；`W_net(t) = FΔx(t)`，且 `K(t) = ½mv(t)² = W_net(t)`，这些量随动画时间变化。

### 下落 `drop`

把零点上移到 `1.0 m`，`U_g` 的每个数值都会减少 `mg × 1.0 m = 4.90 J`。在新的零点以下，`U_g` 为负。但下落过程中 `U_g` 的**变化量**相同，所以你预测的速度也相同。选择最方便计算的零点。

### 弹簧 `spring`

灰色箭头是压缩量 `Δx`，从弹簧的自然长度起测。弹簧力 `F_s = −kΔx` 指向相反方向。物块减速时，它的 `K` 能量条转入 `U_s` 能量条；完全压缩时，能量全是 `U_s`。总能量从不改变。

### 推力 `push`

`F(x)` 下的面积可分成 `6` 个窄条。每一条都是 `F(x_i)·Δx`，表示在推力几乎不变的一小步中所做的功。它们的和 `40.2 J` 已经接近积分值 `40.0 J`；窄条越薄，差距越小。地面水平且光滑，因此重力和支持力不做功，全部面积就是动能。

### 小珠 `bead`

虚线是导线的切线。重力分解为沿导线的分量 `mg sin θ`，以及横向分量；横向分量由导线的支持力承担。由于 `U = mgh` 且沿导线有 `dh/dx = sin θ`，沿导线的分量正好是 `−dU/dx`。在谷底和山丘顶部，切线都是水平的：没有力，处于平衡。

### 化学键 `bond`

该化学键采用 Lennard-Jones 模型：`U = ε[(r₀/r)¹² − 2(r₀/r)⁶]`，`r₀ = 0.15 nm`；重原子几乎不动。幽灵标记显示转向点，此处 `U = E`，原子停止。蓝色虚线抛物线是 `½k(r − r₀)²`，其中 `k = U″(r₀) = 768 N/m`；它适合描述势阱底部，这就是为什么小振动是简谐振动，且 `ω² = U″/m`。在更高能量处，真实势阱左右不对称：内侧陡峭，外侧平缓，所以这个摆动更慢，在伸长状态停留更久。

### 摆 `pendulum`

重力分解为沿路径的 `mg sin θ` 和沿绳子的 `mg cos θ`。只有 `mg sin θ` 做功：它使摆球上升时减速，下落时加速。张力和 `mg cos θ` 横切运动方向，不做功，这就是为什么 `K + U_g` 保持不变。

### 滑动 `slide`

重力和支持力不做功，可以忽略。摩擦力是沿运动方向的唯一力，并且指向后方：`θ = 180°`，所以它做功 `−f·Δx`。这个负功正好等于损失的动能，并以热的形式重新出现在物块和地面中。

### 提升 `lift`

灰色箭头表示每个箱子的上升量 `Δy`。以恒定速度运动时，绳子的拉力等于重力，所以每根绳子做功 `W = mgΔy`。上升高度相同意味着做功相同；较快的箱子用一半时间到达，因此它的绳子提供两倍功率。
