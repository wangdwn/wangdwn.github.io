# 练习：牛顿定律

> 本练习单元共 13 页，每页包含一或两道题。所有数值、选项与解析均依据实际运行时数据翻译。

## 第 0 页：支持力与受力图

### 题 0.1

2.0 kg 的方块放在地板上静止不动，同时你以 5.0 N 的力竖直向下按压它。地板提供的支持力是多少？

**选项**

1. 24.6 N
2. 19.6 N
3. 14.6 N
4. 5.00 N

**正确答案：** 1. 24.6 N

**解析**

受力图中，重力 19.6 N 向下，你的推力 5.0 N 向下，支持力向上。方块保持静止，因此 Σ<i>F</i> = 0：

<div class="eq"><i>F</i><sub>N</sub> = <i>mg</i> + <i>F</i><sub>push</sub> = 19.6 + 5.0 = 24.6 N</div>

支持力是表面必须提供的力；只有在没有其他竖直方向的推力时，它才等于 <i>mg</i>。

### 题 0.2

一个方块在无摩擦地板上以恒定速度滑动（无空气阻力）。哪些力应画在它的受力图上？

**选项**

1. 重力、支持力，以及维持其运动的向前力
2. 只有重力
3. 支持力和向前力
4. 只有重力和支持力

**正确答案：** 4. 只有重力和支持力

**解析**

只有接触方块的物体（以及重力）会对它施力。地板提供支持力，地球提供重力。没有任何东西向前推动它：它的速度保持不变，是因为合力为零，而不是因为有某种力驱动它。

## 第 1 页：两根倾斜绳的张力

### 题 1.1

2.0 kg 的方块由两根绳子悬挂并保持静止，每根绳子都位于水平线以上 25°。每根绳子的张力是多少？

**选项**

1. 10.8 N
2. 23.2 N
3. 46.4 N
4. 9.80 N

**正确答案：** 2. 23.2 N

**解析**

水平方向的分量相互抵消。两根绳子的竖直分量共同支撑重力：

<div class="eq">2<i>T</i> sin θ = <i>mg</i> &nbsp;→ <i>T</i> = 19.6 / (2 sin 25°) = 23.2 N</div>

角度是从水平方向测量的，所以竖直分量是 <i>T</i> sin θ，而不是 <i>T</i> cos θ。每根绳子的张力都大于重力的一半 9.80 N。

### 题 1.2

两根绳子被拉得越来越平、越来越接近水平方向，而方块仍保持静止。张力会怎样变化？

**选项**

1. 它会趋近于零。
2. 它保持为重力的一半。
3. 它会无限增大；完全水平的绳子是不可能的。
4. 它会趋近于完整的重力。

**正确答案：** 3. 它会无限增大；完全水平的绳子是不可能的。

**解析**

<i>T</i> = <i>mg</i>/(2 sin θ)。当 θ → 0 时，sin θ → 0，因此 <i>T</i> → ∞。水平绳子完全没有竖直分量，所以不存在能够支撑方块的有限张力。

## 第 2 页：恒速运动的电梯与惯性

### 题 2.1

2.0 kg 的方块悬挂在电梯内的一根绳子上；电梯正以**恒定的 3.0 m/s 向上运动**。绳子的张力是多少？

**选项**

1. 25.6 N
2. 6.00 N
3. 13.6 N
4. 19.6 N

**正确答案：** 4. 19.6 N

**解析**

恒定速度意味着 <i>a</i> = 0，因此方块处于平衡状态：Σ<i>F</i> = <i>T</i> − <i>mg</i> = 0。

<div class="eq"><i>T</i> = <i>mg</i> = 2.0 × 9.80 = 19.6 N</div>

速度从未进入计算；力会改变速度，而不是维持速度所必需的力。（<i>mv</i> 甚至都不是力。）

### 题 2.2

一个冰球在无摩擦的冰面上以稳定速度滑行。要让它继续运动，需要什么？

**选项**

1. 什么都不需要；合力为零时，它的速度保持不变。
2. 一个等于其重力的恒定向前力
3. 一个逐渐减小的向前力
4. 它的“惯性力”，这种力会随时间逐渐耗尽

**正确答案：** 1. 什么都不需要；合力为零时，它的速度保持不变。

**解析**

第一定律：当 Σ<i>F</i> = 0 时，无论物体是否运动，速度都保持不变。惯性是一种性质（抵抗速度变化），而不是一种力；它也不会耗尽。

## 第 3 页：飞机的推力与阻力

### 题 3.1

质量为 1200 kg 的飞机正在水平巡航，阻力为 1800 N。飞行员将推力提高到 2400 N。在刚刚提高推力后、阻力尚未变化之前，飞机的加速度是多少？

**选项**

1. 2.00 m/s²
2. 1.50 m/s²
3. 0.500 m/s²
4. 3.50 m/s²

**正确答案：** 3. 0.500 m/s²

**解析**

升力仍然抵消重力。沿飞行路径方向，合力是推力减去阻力：

<div class="eq"><i>a</i> = (2400 − 1800) / 1200 = 0.500 m/s² 向前</div>

只使用推力会忽略仍然存在的阻力。

### 题 3.2

在 55 m/s 的稳定水平飞行中，向前的推力与阻力相比如何？

**选项**

1. 推力更大，否则飞机会减速。
2. 两者相等。
3. 推力比飞机的重力大。
4. 阻力更大，因为飞机正在运动。

**正确答案：** 2. 两者相等。

**解析**

恒定速度意味着合力为零（第一定律），所以推力 = 阻力 = 1800 N。推力大于阻力会使飞机加速，而不仅仅是保持运动。

## 第 4 页：合力、加速度与位移

### 题 4.1

6.0 N 的推力从静止开始作用于 2.0 kg 的方块，表面无摩擦。经过 1.2 s 后，它移动了多远？

**选项**

1. 4.32 m
2. 1.08 m
3. 3.60 m
4. 2.16 m

**正确答案：** 4. 2.16 m

**解析**

<i>a</i> = Σ<i>F</i>/<i>m</i> = 6.0/2.0 = 3.00 m/s²，且为常量，因此

<div class="eq">Δ<i>x</i> = ½<i>at</i>² = ½ × 3.00 × (1.2)² = 2.16 m</div>

4.32 m 忘记了 ½；3.60 是达到的速度，单位为 m/s。

### 题 4.2

一辆小车所受的合力加倍，同时它的质量也加倍。它的加速度会变为

**选项**

1. 原来的四分之一
2. 不变
3. 原来的两倍
4. 原来的四倍

**正确答案：** 2. 不变

**解析**

<i>a</i> = Σ<i>F</i>/<i>m</i> = (2Σ<i>F</i>)/(2<i>m</i>)：两个因子相互抵消。

## 第 5 页：汽车加速的外力

### 题 5.1

汽车在水平道路上加速。什么外力将汽车向前推动？

**选项**

1. 发动机对汽车的力
2. 轮胎对道路的力
3. 道路对轮胎的静摩擦力
4. 道路对轮胎的动摩擦力

**正确答案：** 3. 道路对轮胎的静摩擦力

**解析**

发动机是汽车的一部分；内力不能使汽车整体加速。轮胎向后推道路，根据第三定律，道路向前推轮胎。轮胎表面没有在道路上滑动，所以这是**静**摩擦力。轮胎对道路的力作用在道路上，而不是作用在汽车上。

### 题 5.2

在道路提供相同的 3.6 kN 向前推力时，质量为 1200 kg 的汽车达到 30 m/s，此时阻力为 351 N。它此时的加速度是多少？

**选项**

1. 3.00 m/s²
2. 2.71 m/s²
3. 3.29 m/s²
4. 0.292 m/s²

**正确答案：** 2. 2.71 m/s²

**解析**

阻力向后，方向与运动相反：

<div class="eq"><i>a</i> = (<i>F</i> − <i>F</i><sub>d</sub>)/<i>m</i> = (3600 − 351) / 1200 = 2.71 m/s²</div>

3.00 m/s² 忽略了阻力，这就是现实中的汽车在高速下加速更慢的原因。

## 第 6 页：粗糙地面上的方块

### 题 6.1

2.0 kg 的方块放在粗糙地面上（μ<sub>s</sub> = 0.50，μ<sub>k</sub> = 0.30）。你以 8.0 N 的力水平推它。方块受到的摩擦力是多少？

**选项**

1. 9.80 N
2. 5.88 N
3. 8.00 N
4. 0 N

**正确答案：** 3. 8.00 N

**解析**

静摩擦力的上限是 μ<sub>s</sub><i>F</i><sub>N</sub> = 0.50 × 19.6 = 9.80 N。8.0 N 小于该上限，因此方块保持静止，静摩擦力恰好平衡推力：8.00 N。μ<sub>s</sub><i>F</i><sub>N</sub> 是**最大值**，而不是实际值。

### 题 6.2

方块开始滑动后，推力增大到 12.0 N。方块的加速度是多少？

**选项**

1. 1.10 m/s²
2. 6.00 m/s²
3. 8.94 m/s²
4. 3.06 m/s²

**正确答案：** 4. 3.06 m/s²

**解析**

方块正在滑动，因此动摩擦力 μ<sub>k</sub><i>mg</i> = 5.88 N 向后作用：

<div class="eq"><i>a</i> = (12.0 − 5.88) / 2.0 = 3.06 m/s²</div>

一旦方块开始滑动，静摩擦力的 9.80 N 上限就不再适用。

## 第 7 页：接触力与第三定律

### 题 7.1

相同的 6.0 N 推力现在作用在 B（4.0 kg）上，将它推向无摩擦地板上的 A（2.0 kg）。两个方块彼此施加多大的力？

**选项**

1. 2.00 N
2. 4.00 N
3. 6.00 N
4. 3.00 N

**正确答案：** 1. 2.00 N

**解析**

把两个方块看作整体：<i>a</i> = 6.0/(2.0 + 4.0) = 1.00 m/s²。接触力是 A 所受的唯一水平力，因此

<div class="eq"><i>F</i><sub>BA</sub> = <i>m</i><sub>A</sub><i>a</i> = 2.0 × 1.00 = 2.00 N</div>

从后方推动较轻的方块只需要较小的接触力；4.00 N 是推力作用在 A 上时的答案。

### 题 7.2

方块放在桌面上。方块重力（地球向下拉方块）的第三定律作用力是哪一个？

**选项**

1. 桌子向上推方块
2. 方块向上拉地球
3. 方块向下推桌子
4. 桌子向下推地板

**正确答案：** 2. 方块向上拉地球

**解析**

第三定律力对是同一相互作用从两面来看的结果：地球拉方块，方块拉地球；两者大小相同、方向相反，并且作用在不同物体上。桌子的支持力也作用在方块上，所以它不可能是该作用力对的另一半，尽管在这里它们的大小相等。

## 第 8 页：质心与滑冰者

### 题 8.1

滑冰者 A（50 kg）和 B（75 kg）在无摩擦冰面上相距 4.9 m，并拉动一根轻绳直到相遇。他们相遇的位置距离 A 的起点多远？

**选项**

1. 2.45 m
2. 1.96 m
3. 2.94 m
4. 3.27 m

**正确答案：** 3. 2.94 m

**解析**

水平方向只有内力作用，因此质心保持不动；他们会在质心处相遇。从 A 的起点量起：

<div class="eq"><i>x</i><sub>cm</sub> = (<i>m</i><sub>A</sub> · 0 + <i>m</i><sub>B</sub> · <i>d</i>) / (<i>m</i><sub>A</sub> + <i>m</i><sub>B</sub>) = 75 × 4.9 / 125 = 2.94 m</div>

较轻的滑冰者移动得更远。1.96 m 把两个质量交换了。

### 题 8.2

对于由两个滑冰者和绳子组成的系统，他们拉绳时下列哪一项正确？

**选项**

1. 质心向较重的滑冰者移动。
2. 绳子的张力使系统的质心加速。
3. 只有当 A 和 B 质量相等时，作用在 A 和 B 上的张力才会抵消。
4. 质心保持静止，因为张力是内力。

**正确答案：** 4. 质心保持静止，因为张力是内力。

**解析**

绳子以大小相等、方向相反的力拉 A 和 B；这些力都在系统内部，因此无论两人的质量如何，它们的合力都为零。重力和支持力相互抵消。当 Σ<i>F</i><sub>ext</sub> = 0 时，<i>a</i><sub>cm</sub> = 0，而系统一开始处于静止状态。

## 第 9 页：木板与方块的相对滑动

### 题 9.1

对木板的拉力增大到 24 N；2.0 kg 的方块仍在 4.0 kg 的木板上滑动（μ<sub>k</sub> = 0.15）。方块的加速度是多少？

**选项**

1. 4.00 m/s²
2. 1.47 m/s²
3. 1.96 m/s²
4. 5.26 m/s²

**正确答案：** 2. 1.47 m/s²

**解析**

方块所受的唯一水平力是动摩擦力 μ<sub>k</sub><i>mg</i> = 2.94 N，与拉力大小无关：

<div class="eq"><i>a</i> = μ<sub>k</sub><i>g</i> = 0.15 × 9.80 = 1.47 m/s²</div>

绳子拉的是木板，而不是方块。4.00 m/s² 是整体质心的加速度。

### 题 9.2

仍然施加 24 N 的拉力。方块与木板整体的质心加速度是多少？

**选项**

1. 6.00 m/s²
2. 5.26 m/s²
3. 3.51 m/s²
4. 4.00 m/s²

**正确答案：** 4. 4.00 m/s²

**解析**

方块与木板之间的摩擦力是内力，会相互抵消。唯一的水平外力是拉力：

<div class="eq"><i>a</i><sub>cm</sub> = Σ<i>F</i><sub>ext</sub>/<i>M</i> = 24 / 6.0 = 4.00 m/s²</div>

检验：(2.0 × 1.47 + 4.0 × 5.26) / 6.0 = 4.00 m/s²。

## 第 10 页：斜面上的运动

### 题 10.1

方块从静止开始沿无摩擦的 30° 斜面向下滑行 3.0 m。到达底部时速度多大？

**选项**

1. 7.67 m/s
2. 3.83 m/s
3. 5.42 m/s
4. 7.14 m/s

**正确答案：** 3. 5.42 m/s

**解析**

沿斜面方向，<i>a</i> = <i>g</i> sin θ = 4.90 m/s²。从静止出发，且题目未给出时间：

<div class="eq"><i>v</i> = √(2<i>aL</i>) = √(2 × 4.90 × 3.0) = 5.42 m/s</div>

7.67 m/s 使用了完整的 <i>g</i>，相当于物体竖直下落了 3.0 m；cos θ 是指向**斜面内部**的分量。

### 题 10.2

现在斜面变得粗糙，μ<sub>k</sub> = 0.30。方块沿斜面向下滑动时的加速度是多少？

**选项**

1. 4.90 m/s²
2. 7.45 m/s²
3. 2.35 m/s²
4. 1.96 m/s²

**正确答案：** 3. 2.35 m/s²

**解析**

摩擦力为 μ<sub>k</sub><i>F</i><sub>N</sub>；在斜面上，<i>F</i><sub>N</sub> = <i>mg</i> cos θ。摩擦力指向斜面上方，与滑动方向相反：

<div class="eq"><i>a</i> = <i>g</i>(sin θ − μ<sub>k</sub> cos θ) = 9.80(0.500 − 0.30 × 0.866) = 2.35 m/s²</div>

1.96 m/s² 使用了 <i>F</i><sub>N</sub> = <i>mg</i>，这只有在水平地面上才成立。

## 第 11 页：线性阻力下的终端速度

### 题 11.1

质量为 0.50 kg 的球（<i>b</i> = 1.25 kg/s）从静止释放。它需要多长时间才能达到终端速度的一半？

**选项**

1. 0.200 s
2. 0.277 s
3. 0.400 s
4. 0.693 s

**正确答案：** 2. 0.277 s

**解析**

从 <i>m</i> d<i>v</i>/d<i>t</i> = <i>mg</i> − <i>bv</i> 出发，分离变量并积分得到 <i>v</i> = <i>v</i><sub>t</sub>(1 − e<sup>−<i>t</i>/τ</sup>)，τ = <i>m</i>/<i>b</i> = 0.40 s。令 <i>v</i> = <i>v</i><sub>t</sub>/2：

<div class="eq">e<sup>−<i>t</i>/τ</sup> = ½ &nbsp;→ <i>t</i> = τ ln 2 = 0.40 × 0.693 = 0.277 s</div>

速度不会线性增长，所以不是 τ/2；在 τ 时它已经达到终端速度的 63%。

### 题 11.2

对于同一个球（<i>m</i> d<i>v</i>/d<i>t</i> = <i>mg</i> − <i>bv</i>，从静止开始），对 <i>v</i>(<i>t</i>) 求导以找出 <i>a</i>(<i>t</i>)。然后求出在 <i>a</i> = <i>g</i>/4 的瞬间阻力，以及这一瞬间发生的时间。

**参考解答**

1. <i>v</i> = <i>v</i><sub>t</sub>(1 − e<sup>−<i>t</i>/τ</sup>)，所以 <i>a</i> = d<i>v</i>/d<i>t</i> = (<i>v</i><sub>t</sub>/τ) e<sup>−<i>t</i>/τ</sup> = <i>g</i> e<sup>−<i>t</i>/τ</sup>，因为 <i>v</i><sub>t</sub>/τ = (<i>mg</i>/<i>b</i>)(<i>b</i>/<i>m</i>) = <i>g</i>。

2. 根据微分方程，<i>ma</i> = <i>mg</i> − <i>F</i><sub>d</sub>。当 <i>a</i> = <i>g</i>/4 时：

<div class="eq"><i>F</i><sub>d</sub> = <i>mg</i> − <i>mg</i>/4 = ¾<i>mg</i> = ¾ × 4.90 = 3.68 N</div>

3. e<sup>−<i>t</i>/τ</sup> = ¼，因此 <i>t</i> = τ ln 4 = 0.40 × 1.386 = 0.555 s。检验：<i>v</i> = ¾<i>v</i><sub>t</sub> = 2.94 m/s，且 <i>bv</i> = 3.68 N。

## 第 12 页：线性阻力下的下落距离

### 题 12.1

球（<i>v</i><sub>t</sub> = 3.92 m/s，τ = 0.40 s）从静止释放后 1.00 s，已经下落了多远？

**选项**

1. 3.92 m
2. 2.48 m
3. 2.35 m
4. 4.90 m

**正确答案：** 2. 2.48 m

**解析**

对速度积分：

<div class="eq"><i>x</i> = ∫<sub>0</sub><sup><i>t</i></sup> <i>v</i><sub>t</sub>(1 − e<sup>−<i>t</i>′/τ</sup>) d<i>t</i>′ = <i>v</i><sub>t</sub>[<i>t</i> − τ(1 − e<sup>−<i>t</i>/τ</sup>)]</div>

<div class="eq">= 3.92 × [1.00 − 0.40(1 − e<sup>−2.5</sup>)] = 2.48 m</div>

2.35 m 是晚期渐近式 <i>v</i><sub>t</sub>(<i>t</i> − τ)；在 <i>t</i> = 2.5τ 时，e<sup>−<i>t</i>/τ</sup> 项还不能忽略。4.90 m 忽略了阻力。

### 题 12.2

两个球，其中一个的质量是另一个的 4 倍，但大小和形状相同；两者都下落到终端速度。在**线性阻力**（<i>bv</i>）和**二次阻力**（<i>kv</i>²）下，较重球的 <i>v</i><sub>t</sub> 分别是较轻球的多少倍？

**选项**

1. 线性 2 倍，二次 4 倍
2. 线性 4 倍，二次 4 倍
3. 线性 2 倍，二次 2 倍
4. 线性 4 倍，二次 2 倍

**正确答案：** 4. 线性 4 倍，二次 2 倍

**解析**

在终端速度下，阻力 = <i>mg</i>。线性阻力：<i>bv</i><sub>t</sub> = <i>mg</i>，<i>v</i><sub>t</sub> = <i>mg</i>/<i>b</i> ∝ <i>m</i>，因此是 4 倍。二次阻力：<i>kv</i><sub>t</sub>² = <i>mg</i>，<i>v</i><sub>t</sub> = √(<i>mg</i>/<i>k</i>) ∝ √<i>m</i>，因此是 2 倍。大小和形状相同意味着 <i>b</i> 和 <i>k</i> 相同。
