# 练习：流体

> 本文件对应 Atlas of Physics《流体》章节的独立练习模块。本译文按练习模块实际运行后导出的题目、选项、数值与解析整理。

## 第 1 页

### 1. 铝立方体的密度

一个边长为 10 cm 的铝立方体（ρ = 2700 kg/m³）被切成八个大小相等的小立方体。每个小立方体的密度是：

1. 337.5 kg/m³
2. 1350 kg/m³
3. 2700 kg/m³
4. 21600 kg/m³

**正确答案：** 3. 2700 kg/m³

**解析：** 每一块的质量是原来的 ⅛，体积也是原来的 ⅛，因此 ρ = m/V 不变。密度属于材料，而不是物体。

### 2. 冰块的质量

一个边长为 5.0 cm 的冰块质量是多少？（ρ<sub>ice</sub> = 917 kg/m³）

1. 0.459 kg
2. 0.115 kg
3. 0.229 kg
4. 115 kg

**正确答案：** 2. 0.115 kg

**解析：** 先换算成米：V = (0.05 m)³ = 1.25 × 10<sup>−4</sup> m³。

<div class="eq">m = ρV = 917 × 1.25 × 10<sup>−4</sup> = 0.115 kg</div>

边长减半会使体积变为原来的 ⅛，而不是 ½：10 cm 立方体的 0.917 kg 变为 0.115 kg。

## 第 2 页

### 3. 单脚站立时的压强

一个质量为 70 kg 的人站在**一只**鞋上（鞋底为 10 cm × 25 cm）。雪地受到的压强是：

1. 13.7 kPa
2. 2.80 kPa
3. 54.9 kPa
4. 27.4 kPa

**正确答案：** 4. 27.4 kPa

**解析：**

<div class="eq">P = F/A = mg / A = 686 N / 0.025 m² = 27.4 kPa</div>

这是一双鞋总面积的一半，因此压强是双脚站立时 13.7 kPa 的两倍。2.80 kPa 把质量而不是重力除以面积。

### 4. 钉子的尖端压强

你用 50 N 的力把钉子压入木头，力作用在钉子面积为 1 cm² 的钉帽上；钉子没有加速。与拇指作用在钉帽上相比，钉尖对木头施加的是：

1. 相同的力和相同的压强
2. 更大的力和更大的压强
3. 相同的力和大得多的压强
4. 更小的力和更大的压强

**正确答案：** 3. 相同的力和大得多的压强

**解析：** 钉子处于平衡状态（且质量几乎为零），所以木头以相同的 50 N 的力推回钉子。钉尖的面积小 200 倍，因此压强大 200 倍：钉尖处为 100 MPa，而钉帽处为 500 kPa。

## 第 3 页

### 5. 湖底的绝对压强

湖面下 12 m 处的湖底，绝对压强是多少？（<i>P</i><sub>0</sub> = 101.3 kPa）

1. 117.6 kPa
2. 218.9 kPa
3. 101.3 kPa
4. 202.6 kPa

**正确答案：** 2. 218.9 kPa

**解析：**

<div class="eq"><i>P</i> = <i>P</i><sub>0</sub> + ρ<i>gh</i> = 101.3 kPa + 1000 × 9.80 × 12 = 101.3 kPa + 117.6 kPa = 218.9 kPa</div>

117.6 kPa 是表压：它没有计入液面处的大气压。

### 6. 不同形状容器底部的压强

一个高而细的花瓶、一个宽碗和一个向上变窄的圆锥形容器，都装水至相同深度。底部的压强是：

1. 宽碗中最大，因为它装的水最多
2. 圆锥形容器中最大，因为水被挤在一起
3. 细花瓶中最大
4. 三者相同

**正确答案：** 4. 三者相同

**解析：** <i>P</i> = <i>P</i><sub>0</sub> + ρ<i>gh</i> 只取决于开放液面以下的深度，而不取决于形状或水量。重量差异由容器壁承担。

## 第 4 页

### 7. 液压升降机

一个液压升降机的活塞半径分别为 2.0 cm 和 10.0 cm。若大活塞上有一辆重力为 12000 N 的汽车，小活塞上需要施加多大的力才能托住汽车？

1. 2400 N
2. 480 N
3. 12000 N
4. 300000 N

**正确答案：** 2. 480 N

**解析：** 两个活塞上受到相同的 Δ<i>P</i>，所以 <i>F</i><sub>1</sub>/<i>A</i><sub>1</sub> = <i>F</i><sub>2</sub>/<i>A</i><sub>2</sub>，而面积与半径的平方成正比：

<div class="eq"><i>F</i><sub>1</sub> = 12000 × (2.0 / 10.0)² = 480 N</div>

2400 N 使用的是半径之比，而不是面积之比。

### 8. 液压机活塞的位移

在本页的液压机中，小活塞（201 cm²）被向下压 32 cm。大活塞（3217 cm²）上升多远？

1. 8.00 cm
2. 32.0 cm
3. 512 cm
4. 2.00 cm

**正确答案：** 4. 2.00 cm

**解析：** 水不可压缩，因此向下压入的体积会从另一侧上升：<i>A</i><sub>1</sub><i>d</i><sub>1</sub> = <i>A</i><sub>2</sub><i>d</i><sub>2</sub>。

<div class="eq"><i>d</i><sub>2</sub> = 32 cm × 201 / 3217 = 2.00 cm</div>

通过十六分之一的距离传递十六倍的力：输入功等于输出功。

## 第 5 页

### 9. 完全浸没的铝立方体

一个边长为 30 cm 的铝立方体（W = 714 N）悬挂在绳子上，完全浸没在水中。绳子的张力是：

1. 714 N
2. 265 N
3. 979 N
4. 450 N

**正确答案：** 4. 450 N

**解析：**

<div class="eq"><i>F</i><sub>b</sub> = ρ<sub>water</sub><i>Vg</i> = 1000 × 0.027 × 9.80 = 265 N</div>

<div class="eq"><i>T</i> = <i>W</i> − <i>F</i><sub>b</sub> = 714 − 265 = 450 N</div>

浮力使用的是**水的**密度，而不是铝的密度；265 N 是浮力，不是张力。

### 10. 深度对浮力的影响

立方体完全浸没后，继续把它下沉到更深处。它受到的浮力：

1. 增大，因为越深处压强越大
2. 减小，因为它上方有更多的水
3. 保持不变
4. 增大，直到等于重力

**正确答案：** 3. 保持不变

**解析：** 下沉得更深时，顶面和底面上的压强都增加相同的 ρgΔh。两者之差仍为 ρgs，因此 <i>F</i><sub>b</sub> = ρ<i>Vg</i> 不变。（取水为不可压缩流体。）

## 第 6 页

### 11. 海水中的木块

密度为 600 kg/m³ 的木块漂浮在海水（1025 kg/m³）中，而不是淡水中。木块有多大比例浸没在水下？

1. 60.0%
2. 41.5%
3. 58.5%
4. 40.0%

**正确答案：** 3. 58.5%

**解析：** 漂浮时，<i>F</i><sub>b</sub> = <i>W</i>：ρ<sub>sea</sub><i>V</i><sub>under</sub><i>g</i> = ρ<sub>wood</sub><i>Vg</i>。

<div class="eq"><i>V</i><sub>under</sub>/<i>V</i> = 600 / 1025 = 58.5%</div>

密度更大的水可以用更小的体积托住木块，因此浸没部分略少于它在淡水中的 60.0%。41.5% 是露出水面的部分。

### 12. 池底钢球受到的支持力

一个钢球（半径 0.15 m，ρ = 7850 kg/m³）静止在水池底部。池底向上推它的力是：

1. 1088 N
2. 949 N
3. 139 N
4. 1226 N

**正确答案：** 2. 949 N

**解析：**

<div class="eq">V = ⁴⁄₃πr³ = 0.0141 m³，W = ρ<sub>steel</sub>Vg = 1088 N，<i>F</i><sub>b</sub> = ρ<sub>water</sub>Vg = 139 N</div>

<div class="eq"><i>F</i><sub>N</sub> = W − <i>F</i><sub>b</sub> = 949 N</div>

水仍会向上推一个沉底的球；池底只需提供剩余的那部分力。

## 第 7 页

### 13. 管道变窄处的流速

水在半径为 30 cm 的管道中以 0.5 m/s 的速度流动，随后进入半径为 10 cm 的管段。在那里，水的速度是：

1. 1.50 m/s
2. 4.50 m/s
3. 0.0556 m/s
4. 0.167 m/s

**正确答案：** 2. 4.50 m/s

**解析：**

<div class="eq"><i>A</i><sub>1</sub><i>v</i><sub>1</sub> = <i>A</i><sub>2</sub><i>v</i><sub>2</sub> → <i>v</i><sub>2</sub> = <i>v</i><sub>1</sub>(r<sub>1</sub>/r<sub>2</sub>)² = 0.5 × 3² = 4.50 m/s</div>

面积与 r² 成正比，因此半径变为三分之一时，面积变为九分之一。1.50 m/s 使用的是半径之比。

### 14. 用宽管注满水箱所需的时间

半径为 30 cm、流速为 0.5 m/s 的宽管，需要多长时间才能装满一个 1000 L 的水箱？

1. 1.77 s
2. 1.06 s
3. 7.07 s
4. 22.2 s

**正确答案：** 3. 7.07 s

**解析：**

<div class="eq"><i>Q</i> = <i>Av</i> = π(0.30)² × 0.5 = 0.1414 m³/s</div>

<div class="eq">t = V/Q = 1.000 m³ / 0.1414 m³/s = 7.07 s</div>

1000 L 等于 1 m³。把 60 cm 的直径当作半径，会得到大 4 倍的面积。

## 第 8 页

### 15. 伯努利方程：管道变窄

在本页的管道中，水在宽管部分以 2.0 m/s 流动，表压为 50 kPa；在同一高度的窄管部分，速度加快到 8.0 m/s。那里表压是：

1. 80 kPa
2. 50 kPa
3. 12.5 kPa
4. 20 kPa

**正确答案：** 4. 20 kPa

**解析：**

<div class="eq"><i>P</i><sub>2</sub> = <i>P</i><sub>1</sub> + ½ρ(<i>v</i><sub>1</sub>² − <i>v</i><sub>2</sub>²) = 50 kPa + ½ × 1000 × (2² − 8²) = 20 kPa</div>

流速快，压强低。80 kPa 把符号弄反了：水之所以加速，是因为它后方的压强更高。

### 16. 管道上升后的压强

水的速度随后回到 2.0 m/s，管道接着上升 1.2 m。高处宽管部分的表压是：

1. 61.8 kPa
2. 38.2 kPa
3. 50.0 kPa
4. 26.5 kPa

**正确答案：** 2. 38.2 kPa

**解析：** 速度与第 1 点相同，因此 ½ρv² 项相互抵消：

<div class="eq"><i>P</i><sub>3</sub> = <i>P</i><sub>1</sub> − ρ<i>g</i>Δy = 50 kPa − 1000 × 9.80 × 1.2 = 38.2 kPa</div>

把水提升到更高处需要付出压强，正如潜得更深会增加压强一样。

## 第 9 页

### 17. 水柱高度与喷流速度

把孔上方的水面高度提升到原来高度的四倍。水流离开小孔时：

1. 速度相同
2. 速度是原来的 √2 倍
3. 速度是原来的两倍
4. 速度是原来的四倍

**正确答案：** 3. 速度是原来的两倍

**解析：** <i>v</i> = √(2<i>gh</i>)：<i>h</i> 变为四倍会使速度变为 √4 = 2 倍，这与石头从四倍高度落下时的情形相同。

### 18. 水箱喷流的落点

小孔位于地面上方 1.08 m。当水面高出小孔 0.60 m 时，喷流会落在距水箱多远处？

1. 0.805 m
2. 1.61 m
3. 2.28 m
4. 1.14 m

**正确答案：** 2. 1.61 m

**解析：**

<div class="eq"><i>v</i> = √(2 × 9.80 × 0.60) = 3.43 m/s，t = √(2 × 1.08 / 9.80) = 0.469 s</div>

<div class="eq">x = vt = 2√(h y<sub>hole</sub>) = 1.61 m</div>

2.28 m 是水箱装满时（1.2 m）的射程，不是当前情形的射程。
