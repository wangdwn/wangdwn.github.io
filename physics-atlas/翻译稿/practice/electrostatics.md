# 练习：静电学

> Atlas of Physics《静电学》独立练习模块的非官方简体中文翻译。

## 第 0 页

### 题目 1

两个相同的金属球分别带有 `+6 nC` 和 `−2 nC` 的电荷。将它们接触后再拉开。此时每个球带有的电荷是：

1. `+4 nC`
2. `+2 nC`
3. `+3 nC` 和 `−1 nC`
4. `0`

**正确答案：** 2. `+2 nC`

**解析：** 电荷守恒：总电荷为 `6 + (−2) = +4 nC`，相同的金属球将其等量分配。

\[
q=(6-2)/2=+2\ \text{nC}
\]

把电荷量的大小相加得到 `+4 nC` 是忽略了符号；负球上的电子抵消了正球电荷的一部分。

### 题目 2

一根细塑料棒沿 `x` 轴从 `0` 延伸到 `0.50 m`，单位长度电荷为 `λ = cx`，其中 `c = +40 nC/m²`。它失去了多少个电子？

1. `1.04 × 10¹⁰`
2. `6.25 × 10¹⁰`
3. `3.13 × 10¹⁰`
4. `1.25 × 10¹¹`

**正确答案：** 3. `3.13 × 10¹⁰`

**解析：** `λ` 沿棒变化，因此要对微元 `dq = λ dx` 求和：

\[
Q=\int_0^L cx\,dx=cL^2/2=40\times0.50^2/2=5.00\ \text{nC}
\]

\[
n=Q/e=5.00\times10^{-9}/(1.60\times10^{-19})=3.13\times10^{10}
\]

省略 `1/2`（把远端的 `λ` 乘以长度）会得到两倍过多的结果。

## 第 1 页

### 题目 1

本页的中性金属球实验中：将负棒靠近金属球，使金属球接地，剪断接地线，然后移走金属棒。最终金属球会：

1. 保持中性
2. 带负电，并均匀分布在球面上
3. 带正电，并均匀分布在球面上
4. 带正电，电荷集中在金属棒原来所在的一侧

**正确答案：** 3. 带正电，并均匀分布在球面上

**解析：** 金属棒将金属球中的自由电子推向远离金属棒的一侧，而接地会让其中一部分电子离开。先断开接地线会把电子亏缺锁定下来：在本题中，金属球带有 `+2.89 nC` 的正电荷，与金属棒的电性相反。金属棒移走后，没有任何因素再使电荷保持在某一侧，因此电荷会均匀分布在球面上。

### 题目 2

在另一个静电感应装置中，金属球接地时，接地线中的电流为

\[
I(t)=I_0e^{-t/τ}
\]

其中 `I₀ = 2.4 mA`，`τ = 1.5 μs`。总共有多少个电子离开？

1. `1.42 × 10¹⁰`
2. `1.13 × 10¹⁰`
3. `8.28 × 10⁹`
4. `2.25 × 10¹⁰`

**正确答案：** 4. `2.25 × 10¹⁰`

**解析：** 电荷是电流的积分：

\[
Q=\int_0^\infty I_0e^{-t/τ}\,dt=I_0τ=3.60\ \text{nC},\qquad n=Q/e=2.25\times10^{10}
\]

若在 `t = τ` 时停止计数，只能数到其中的 `63%`，即 `1.42 × 10¹⁰` 个。

## 第 2 页

### 题目 1

本页的 `+4 μC` 和 `−2 μC` 两个电荷相距 `20 cm`。作用在 `−2 μC` 电荷上的力的大小是：

1. `0.360 N`
2. `3.60 N`
3. `1.80 N`
4. `0.899 N`

**正确答案：** 3. `1.80 N`

**解析：**

\[
F=k|q_1q_2|/r^2=8.99\times10^9\times(4\times10^{-6})(2\times10^{-6})/(0.20)^2=1.80\ \text{N}
\]

两个电荷都受到大小相同的 `1.80 N`，它们构成牛顿第三定律中的作用力与反作用力对；较小的电荷并不会只受到一半大小的力（`0.899 N`）。

### 题目 2

本页的一对同号电荷 `+4 μC` 和 `+2 μC` 被保持在相距 `20 cm` 的位置。释放 `+2 μC` 电荷（另一个电荷保持固定）。当它们相距 `40 cm` 时，电场力对该电荷所做的功是多少？

1. `0.360 J`
2. `0.0899 J`
3. `0.225 J`
4. `0.180 J`

**正确答案：** 4. `0.180 J`

**解析：** 力会随位置变化，因此需要积分：

\[
W=\int_{r_1}^{r_2}kq_1q_2/r^2\,dr=kq_1q_2(1/r_1-1/r_2)=0.0719\times(5.0-2.5)=0.180\ \text{J}
\]

用起始力乘以距离（`0.360 J`）会过大：推力会按 `1/r²` 减弱。把起始力和末力取平均（`0.225 J`）也不对，因为 `F` 并不是 `r` 的线性函数。

## 第 3 页

### 题目 1

在本页中，A（`+4 μC`）和 B（`+1 μC`）相距 `45 cm`。在它们之间距离 A 多远的位置，试探电荷所受的合力为零？

1. `15.0 cm`
2. `36.0 cm`
3. `22.5 cm`
4. `30.0 cm`

**正确答案：** 4. `30.0 cm`

**解析：**

\[
kq_A/x^2=kq_B/(d-x)^2
\]

\[
(d-x)/x=\sqrt{q_B/q_A}=0.50\quad\Longrightarrow\quad x=30.0\ \text{cm}
\]

它位于较小的电荷 B 附近。按电荷之比将 `d` 分割（`36.0 cm`）忽略了力与 `1/r²` 成正比，因此距离应当按电荷的平方根之比划分。

### 题目 2

`+0.1 μC` 的试探电荷从上述平衡点沿连线被轻轻推动一小段距离 `s`。此时合力为 `F ≈ −κs`。`κ` 是：

1. `0.799 N/m`
2. `0.400 N/m`
3. `0.266 N/m`
4. `0.0799 N/m`

**正确答案：** 1. `0.799 N/m`

**解析：** 在 `x_eq` 处，`κ = −dF/dx`，其中

合力表达式为

\[
F=kq_0q_A/x^2-kq_0q_B/(d-x)^2
\]

\[
κ=2kq_0[q_A/x^3+q_B/(d-x)^3]=0.799\ \text{N/m}
\]

两项会相加：向 B 移动时，A 的推力减弱，而 B 的推力增强；两者都会把电荷推回去。将两项相减会得到 `0.266 N/m`。

## 第 4 页

### 题目 1

原点处有一个 `−1.0 nC` 的点电荷。它以东 `20 cm` 处的电场为：

1. `225 N/C，向西`
2. `225 N/C，向东`
3. `44.9 N/C，向西`
4. `0.0225 N/C，向西`

**正确答案：** 1. `225 N/C，向西`

**解析：**

\[
E=k|Q|/r^2=8.99\times10^9\times1.0\times10^{-9}/(0.20)^2=225\ \text{N/C}
\]

负电荷的电场指向电荷本身：位于它东侧的正试探电荷会被向西吸引。把 `r` 用厘米代入会得到 `0.0225 N/C`；`kQ/r` 表示的是电势，而不是电场。

### 题目 2

一个试探电荷以 `5.0 cm/s` 的速度沿直线远离本页的 `+1 nC` 电荷。当它距离该电荷 `20 cm` 时，电荷所在位置的电场减小得有多快？

1. `56.2 N/C/s`
2. `112 N/C/s`
3. `22.5 N/C/s`
4. `562 N/C/s`

**正确答案：** 2. `112 N/C/s`

**解析：** 使用链式法则：`E(r) = kQ/r²`，而 `r` 以速度 `v` 增长：

\[
dE/dt=(dE/dr)(dr/dt)=-(2kQ/r^3)v=-2\times8.99\times0.050/0.20^3=-112\ \text{N/C/s}
\]

从幂函数求导法则中漏掉系数 `2` 会得到 `56.2 N/C/s`。

## 第 5 页

### 题目 1

对于本页的偶极子（`±2 nC`，两电荷相距 `20 cm`），在距中心 `10 cm` 的垂直平分线上，电场的大小为：

1. `3596 N/C`
2. `1271 N/C`
3. `1798 N/C`
4. `636 N/C`

**正确答案：** 2. `1271 N/C`

**解析：** 每个电荷距离该点 `√(a² + y²) = 14.1 cm`，并给出 `kq/(a² + y²) = 899 N/C` 的电场。`y` 分量抵消；`x` 分量各自乘以 `cos θ = a/√(a² + y²)` 后相加：

\[
E=2kqa/(a^2+y^2)^{3/2}=1271\ \text{N/C}
\]

电场平行于轴线，方向从正电荷指向负电荷。远场表达式 `2kqa/y³`（`3596 N/C`）只有在 `y ≫ a` 时才适用；本题中 `y = a`。

### 题目 2

偶极子在 `x = +a` 处有 `+q`，在 `x = −a` 处有 `−q`。求它在轴线上 `x ≫ a` 处的电场，并说明它按 `1/x³` 衰减。

**解答：** 两个电场都沿轴线方向；较近的 `+q` 电荷占优势：

\[
E=kq/(x-a)^2-kq/(x+a)^2=kq\cdot4ax/(x^2-a^2)^2
\]

当 `x ≫ a` 时，`(x² − a²)² → x⁴`，所以 `E → 4kqa/x³ = 2kp/x³`，其中 `p = 2qa`，方向为 `+x`。另一种看法是：`g(x)=kq/x²` 在两个电荷之间的变化量约为 `g′(x)·(−2a)`，因此 `E ≈ −2a·(−2kq/x³) = 4kqa/x³`。两个电场几乎相互抵消，只留下一个比任一单独电场多衰减一个幂次的差值。

## 第 6 页

### 题目 1

本页的细棒（总电荷为 `+4 nC`，长度为 `40 cm`）。在它的一端外沿轴线方向 `10 cm` 处，电场为：

1. `3596 N/C`
2. `400 N/C`
3. `719 N/C`
4. `899 N/C`

**正确答案：** 3. `719 N/C`

**解析：**

\[
E=\int_a^{a+L}kλ\,dx/x^2=kQ/[a(a+L)]=35.96/(0.10\times0.50)=719\ \text{N/C}
\]

若把全部电荷都当作位于近端（`3596 N/C`）或中点（`400 N/C`），结果都会错误：各个电荷微元到观测点的距离不同，而且 `1/x²` 的权重不是线性的。

### 题目 2

细棒（线电荷密度为 `λ`，长度为 `L`）位于 `x` 轴上，从 `−L/2` 延伸到 `L/2`。哪个积分给出了它在中点上方距离 `a` 处的电场？

1. `∫ kλ dx/(x² + a²)`
2. `∫ kλx dx/(x² + a²)^(3/2)`
3. `∫ kλ dx/(x² + a²)^(1/2)`
4. `∫ kλa dx/(x² + a²)^(3/2)`

**正确答案：** 4. `∫ kλa dx/(x² + a²)^(3/2)`

**解析：** 每个微元给出 `dE = kλ dx/(x² + a²)`。侧向分量成对抵消，因此只保留沿 `a` 方向的分量，并乘以 `cos θ = a/√(x² + a²)`：

\[
E=\int_{-L/2}^{L/2}kλa\,dx/(x^2+a^2)^{3/2}=kQ/[a\sqrt{L^2/4+a^2}]
\]

第一项是在不做抵消的情况下直接相加电场大小；含 `x dx` 的积分是侧向分量，结果为零；`1/2` 次幂对应的是电势。

## 第 7 页

### 题目 1

本页的带电圆环（总电荷为 `+15 nC`，`R = 20 cm`）。在距圆心 `15 cm` 的轴线上，电场为：

1. `2158 N/C`
2. `1295 N/C`
3. `5993 N/C`
4. `1726 N/C`

**正确答案：** 2. `1295 N/C`

**解析：** 每个电荷微元距离观测点均为 `√(z² + R²) = 25 cm`；只有轴向分量能够保留下来，其中 `cos φ = z/√(z² + R²) = 0.60`：

\[
E=kQz/(z^2+R^2)^{3/2}=1295\ \text{N/C}
\]

如果不乘以 `cos φ`，会得到 `2158 N/C`；在这个距离上，圆环也不能当作点电荷处理（那会得到 `5993 N/C`）。

### 题目 2

距离该圆环圆心多远的位置，圆环轴线上的电场最强？

1. `20.0 cm`
2. `10.0 cm`
3. `28.3 cm`
4. `14.1 cm`

**正确答案：** 4. `14.1 cm`

**解析：** 对 `E = kQz(z² + R²)^(−3/2)` 令 `dE/dz = 0`：

\[
kQ[(z^2+R^2)-3z^2]/(z^2+R^2)^{5/2}=0\quad\Longrightarrow\quad z=R/\sqrt2=14.1\ \text{cm}
\]

电场在圆心处为零，在远处按 `1/z²` 衰减，因此峰值位于这两者之间。

## 第 8 页

### 题目 1

本页的电子以 `2.0 × 10⁷ m/s` 的速度进入 `5000 N/C` 电场，并沿平行于长度为 `8 cm` 的平板方向运动。当电子离开平板时，它在侧向移动了多远？

1. `14.1 mm`
2. `28.1 mm`
3. `0.00383 mm`
4. `7.03 mm`

**正确答案：** 4. `7.03 mm`

**解析：** 横向存在恒定力，纵向没有力，因此这是一个抛体运动。

\[
a=eE/m_e=8.78\times10^{14}\ \text{m/s}^2,\qquad t=L/v_0=4.0\ \text{ns}
\]

\[
y=\tfrac12at^2=7.03\ \text{mm}
\]

忘记 `1/2` 会使结果加倍。若换成质子，质子的质量会给出 `0.00383 mm`，小 `1833` 倍。

### 题目 2

现在假设平板之间的电场沿平板方向增长：

\[
E=E_0x/L
\]

其中在远端 `E₀ = 5000 N/C`。电子离开平板时的侧向速度为：

1. `3.51 × 10⁶ m/s`
2. `1.76 × 10⁶ m/s`
3. `1.17 × 10⁶ m/s`
4. `0.88 × 10⁶ m/s`

**正确答案：** 2. `1.76 × 10⁶ m/s`

**解析：** `x = v₀t`，所以侧向加速度随时间增大：

\[
a(t)=(eE_0/m)(v_0t/L)
\]

因此

\[
v_y=\int_0^{L/v_0}(eE_0v_0/mL)t\,dt=\tfrac12(eE_0/m)(L/v_0)=1.76\times10^6\ \text{m/s}
\]

这是均匀电场结果（`3.51 × 10⁶ m/s`）的一半：因为电场的平均强度只有远端强度的一半。
