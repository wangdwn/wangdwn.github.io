# 练习：电路

> 本文件对应 Atlas of Physics《电路》章节的独立练习模块。题目、选项、正确答案、解析和自由作答解答均依据运行时练习数据翻译；公式、符号、数值与单位保持准确。

## 第 0 页

### 练习 0.1

**题目：** 一根**直径**为 2.0 mm 的铜线载有 3.0 A 电流（<i>n</i> = 8.5 × 10<sup>28</sup> m<sup>−3</sup>）。其中电子的漂移速率为

**选项：**

1. 0.0702 mm/s
2. 0.0176 mm/s
3. 0.0551 mm/s
4. 0.2206 mm/s

**正确答案：** 1. 0.0702 mm/s

**解析：** 由**半径**求面积：<i>A</i> = π(1.0 mm)<sup>2</sup> = 3.142 mm²。然后

<div class="eq"><i>v</i><sub>d</sub> = <i>I</i>/(<i>neA</i>) = 3/(8.5×10<sup>28</sup> × 1.60×10<sup>−19</sup> × 3.142×10<sup>−6</sup>) = 0.0702 mm/s</div>

把直径当作半径会得到 0.0176 mm/s，速度慢了四倍。

### 练习 0.2

**题目：** 一根导线中的电流为 <i>I</i>(<i>t</i>) = 4.0<i>t</i> − 1.0<i>t</i><sup>2</sup>（单位为 A，<i>t</i> 以 s 为单位），时间从 <i>t</i> = 0 到 4.0 s。通过某一横截面的电荷量为

**选项：**

1. 16.0 C
2. 8.0 C
3. 10.7 C
4. 32.0 C

**正确答案：** 3. 10.7 C

**解析：**

<div class="eq"><i>q</i> = ∫<i>I dt</i> = ∫<sub>0</sub><sup>4</sup> (4<i>t</i> − <i>t</i><sup>2</sup>) <i>dt</i> = 2(4)<sup>2</sup> − (4)<sup>3</sup>/3 = 32 − 21.33 = 10.7 C</div>

这是 <i>I</i>(<i>t</i>) 曲线（在 4 A 处达到峰值的抛物线）下的面积。用峰值乘时间会高估结果（16.0 C）；用三角形面积会低估结果（8.0 C）。

## 第 1 页

### 练习 1.1

**题目：** 本页的细镍铬线（ρ = 1.10 × 10<sup>−6</sup> Ω·m，**直径**为 0.5 mm）长 2.0 m。它的电阻为

**选项：**

1. 2.80 Ω
2. 35.20 Ω
3. 11.20 Ω
4. 8.80 Ω

**正确答案：** 3. 11.20 Ω

**解析：**

<div class="eq"><i>R</i> = ρ<i>L</i>/<i>A</i> = ρ<i>L</i>/π<i>r</i><sup>2</sup> = 1.10×10<sup>−6</sup> × 2 / (π × (0.25×10<sup>−3</sup>)<sup>2</sup>) = 11.20 Ω</div>

半径是直径的一半；把直径当作半径会得到 2.80 Ω，只有正确结果的四分之一。

### 练习 1.2

**题目：** 一根长 2.0 m 的镍铬棒呈锥形：半径从一端的 0.25 mm 线性增大到另一端的 0.50 mm。它从一端到另一端的电阻为

**选项：**

1. 4.98 Ω
2. 7.00 Ω
3. 11.20 Ω
4. 5.60 Ω

**正确答案：** 4. 5.60 Ω

**解析：** 厚度为 <i>dx</i> 的薄片彼此串联；每片满足 <i>dR</i> = ρ <i>dx</i>/π<i>r</i>(<i>x</i>)<sup>2</sup>，其中 <i>r</i> = <i>a</i> + (<i>b</i> − <i>a</i>)<i>x</i>/<i>L</i>，所以 <i>dx</i> = <i>L dr</i>/(<i>b</i> − <i>a</i>)：

<div class="eq"><i>R</i> = (ρ<i>L</i>/π(<i>b</i> − <i>a</i>)) ∫<sub><i>a</i></sub><sup><i>b</i></sup> <i>dr</i>/<i>r</i><sup>2</sup> = ρ<i>L</i>/π<i>ab</i> = 5.60 Ω</div>

电阻不是平均半径对应的结果（4.98 Ω），也不是两端数值的平均值（7.00 Ω）：较细的一端影响更大，但并非完全由它决定。

## 第 2 页

### 练习 2.1

**题目：** 在本页的电路中（6 V 电池、3 Ω 电阻、理想导线），连接电池正端与电阻的导线两端之间的电势差是多少？

**选项：**

1. 6 V
2. 3 V
3. 2 V
4. 0 V

**正确答案：** 4. 0 V

**解析：** 理想导线的 <i>R</i> = 0，所以无论电流多大，沿导线都有 Δ<i>V</i> = <i>IR</i> = 0。该导线上的每一点都处在电池正端的电势；全部 6 V 的电势降落发生在电阻两端。

### 练习 2.2

**题目：** 一根碳管（ρ = 3.5 × 10<sup>−5</sup> Ω·m），内半径为 1 cm，外半径为 2 cm，长度为 5 cm，电流沿**径向**从内表面流向外表面。它的电阻为

**选项：**

1. 11.14 × 10<sup>−5</sup> Ω
2. 7.72 × 10<sup>−5</sup> Ω
3. 5.57 × 10<sup>−5</sup> Ω
4. 185.68 × 10<sup>−5</sup> Ω

**正确答案：** 2. 7.72 × 10<sup>−5</sup> Ω

**解析：** 厚度为 <i>dr</i> 的薄圆柱壳彼此串联；每个薄壳沿电流方向的长度为 <i>dr</i>，面积为 2π<i>rL</i>：

<div class="eq"><i>R</i> = ∫<sub><i>a</i></sub><sup><i>b</i></sup> ρ <i>dr</i>/(2π<i>rL</i>) = (ρ/2π<i>L</i>) ln(<i>b</i>/<i>a</i>) = 7.72 × 10<sup>−5</sup> Ω</div>

面积随 <i>r</i> 增大，因此只使用内侧面积（11.14）或只使用外侧面积（5.57）都不正确。

## 第 3 页

### 练习 3.1

**题目：** 本页的两个灯泡（每个 24 Ω）串联接在 12 V 电池两端。它们消耗的总功率为

**选项：**

1. 12.0 W
2. 6.0 W
3. 3.0 W
4. 1.5 W

**正确答案：** 3. 3.0 W

**解析：** 串联时 <i>R</i><sub>eq</sub> = 48 Ω，因此

<div class="eq"><i>P</i> = Δ<i>V</i><sup>2</sup>/<i>R</i><sub>eq</sub> = 12<sup>2</sup>/48 = 3.0 W</div>

这是一只灯泡单独工作时功率（6.0 W）的一半：电流减半，而每只灯泡得到的功率为其单独功率的四分之一（1.5 W）。如果并联，总功率将为 12.0 W。

### 练习 3.2

**题目：** 一个 24 Ω 电阻两端的电压在 10 s 内从 0 稳定升高到 12 V。这段时间内它转化为热的能量为

**选项：**

1. 30.0 J
2. 20.0 J
3. 60.0 J
4. 15.0 J

**正确答案：** 2. 20.0 J

**解析：** 当 Δ<i>V</i> = (12/10)<i>t</i> 时，<i>P</i> = Δ<i>V</i><sup>2</sup>/<i>R</i> 随 <i>t</i><sup>2</sup> 增长：

<div class="eq"><i>E</i> = ∫<i>P dt</i> = ∫<sub>0</sub><sup><i>T</i></sup> (12<i>t</i>/10)<sup>2</sup>/24 <i>dt</i> = (12<sup>2</sup>/24)·<i>T</i>/3 = 20.0 J</div>

对功率作线性平均会得到 30.0 J，使用平均电压会得到 15.0 J；这两种方法都忽略了 <i>P</i> 与 Δ<i>V</i> 的平方成正比这一点。

## 第 4 页

### 练习 4.1

**题目：** 本页的电池（ℰ = 12 V，<i>r</i> = 2 Ω）驱动一个 4 Ω 灯泡。电池端子之间的电势差为

**选项：**

1. 12.0 V
2. 4.0 V
3. 8.0 V
4. 6.0 V

**正确答案：** 3. 8.0 V

**解析：**

<div class="eq"><i>I</i> = ℰ/(<i>R</i> + <i>r</i>) = 12/6 = 2.0 A，&nbsp; Δ<i>V</i> = ℰ − <i>Ir</i> = 12 − 4.0 = 8.0 V</div>

只有在没有电流流过时，电动势才等于端电压；4.0 V 是电池**内部**的电势降。

### 练习 4.2

**题目：** 现在灯泡固定为 <i>R</i> = 4 Ω，你可以选择电池的内阻 <i>r</i>（ℰ 相同）。哪个 <i>r</i> 会使灯泡最亮？

**选项：**

1. <i>r</i> = 8 Ω
2. <i>r</i> = 4 Ω，与负载匹配
3. <i>r</i> = 2 Ω
4. <i>r</i> = 0

**正确答案：** 4. <i>r</i> = 0

**解析：** <i>P</i> = ℰ<sup>2</sup><i>R</i>/(<i>R</i> + <i>r</i>)<sup>2</sup>，而现在 <i>r</i> 是变量：

<div class="eq"><i>dP</i>/<i>dr</i> = −2ℰ<sup>2</sup><i>R</i>/(<i>R</i> + <i>r</i>)<sup>3</sup> &lt; 0</div>

对每个 <i>r</i> 都成立，因此 <i>P</i> 在最小的 <i>r</i> 处最大，即 <i>r</i> = 0。当电池固定而改变**负载**时，<i>R</i> = <i>r</i> 会使功率最大；这里改变的是电池内阻，而不是负载。

## 第 5 页

### 练习 5.1

**题目：** 在本页理想的 9 V 电池上，与原有的 2 Ω、4 Ω 和 6 Ω 电阻并联，再增加第四个电阻。会发生什么变化：（i）2 Ω 支路中的电流；（ii）电池提供的电流？

**选项：**

1. （i）增加；（ii）增加
2. （i）不变；（ii）增加
3. （i）减少；（ii）增加
4. （i）减少；（ii）不变

**正确答案：** 2. （i）不变；（ii）增加

**解析：** 每个支路仍然承受完整的 9 V，因此 2 Ω 支路保持 9/2 = 4.5 A。新支路会增加自身的电流，而电池提供的是各支路电流之和：通路更多，等效电阻更低，总电流更大。（如果存在内阻，端电压会下降，支路电流会略微减小。）

### 练习 5.2

**题目：** 一根电导率均匀为 σ<sub>0</sub> 的棒材，端到端电阻应为 12 Ω。现在它的电导率沿**宽度方向**线性增加，从一侧边缘的 σ<sub>0</sub> 增加到另一侧的 3σ<sub>0</sub>。它端到端的电阻为

**选项：**

1. 6.59 Ω
2. 4.00 Ω
3. 6.00 Ω
4. 12.00 Ω

**正确答案：** 3. 6.00 Ω

**解析：** 宽度为 <i>dy</i>、沿长度方向的条带都跨接同样的两个端点，因此它们是**并联**的，电导相加：

<div class="eq">1/<i>R</i> = ∫<sub>0</sub><sup><i>w</i></sup> σ(<i>y</i>)<i>t dy</i>/<i>L</i> = (σ<sub>0</sub><i>wt</i>/<i>L</i>)·∫<sub>0</sub><sup>1</sup>(1 + 2<i>u</i>) <i>du</i> = 2/<i>R</i><sub>0</sub></div>

所以 <i>R</i> = 12/2 = 6.00 Ω。把条带当作串联会得到 (ln 3/2)<i>R</i><sub>0</sub> = 6.59 Ω。

## 第 6 页

### 练习 6.1

**题目：** 在本页的组合电路中（9 V；<i>R</i><sub>1</sub> = 2 Ω，<i>R</i><sub>3</sub> = 2 Ω，<i>R</i><sub>2</sub> + <i>R</i><sub>4</sub> + <i>R</i><sub>5</sub> = 8 Ω），<i>R</i><sub>3</sub> 烧坏而断路。通过 <i>R</i><sub>1</sub> 的电流变为

**选项：**

1. 2.50 A
2. 0.90 A
3. 4.50 A
4. 1.13 A

**正确答案：** 2. 0.90 A

**解析：** <i>R</i><sub>3</sub> 断开后，<i>R</i><sub>1</sub> 与 8 Ω 电阻串联：

<div class="eq"><i>I</i> = 9 V/(2 + 8) Ω = 0.90 A</div>

这小于原来的 2.50 A：移除一条并联通路会使等效电阻增大。

### 练习 6.2

**题目：** 用一个可变电阻 <i>x</i> 替换 <i>R</i><sub>3</sub>；其他部分保持不变。<i>x</i> 取何值时其中的功率最大？

**选项：**

1. 1.6 Ω
2. 2.0 Ω
3. 8.0 Ω
4. 10.0 Ω

**正确答案：** 1. 1.6 Ω

**解析：** 从 <i>x</i> 看进去，其余部分是带电池的 <i>R</i><sub>1</sub> 支路与 8 Ω 支路并联。移除 <i>x</i> 时，其戴维南电压为 ℰ<sub>th</sub> = 9 × 8/10 = 7.2 V，其电阻为 <i>R</i><sub>th</sub> = 2 × 8/(2 + 8) = 1.6 Ω。于是

<div class="eq"><i>P</i>(<i>x</i>) = ℰ<sub>th</sub><sup>2</sup><i>x</i>/(<i>R</i><sub>th</sub> + <i>x</i>)<sup>2</sup>，&nbsp; <i>dP</i>/<i>dx</i> = 0 → <i>x</i> = <i>R</i><sub>th</sub> = 1.6 Ω</div>

只取 <i>R</i><sub>1</sub>（2 Ω）会忽略 8 Ω 支路也连接在 <i>x</i> 两端这一事实。

## 第 7 页

### 练习 7.1

**题目：** 在本页的网络中，6 V 电池被一根普通导线替换。通过 12 V 电池的电流（<i>I</i><sub>1</sub>）变为

**选项：**

1. 518 mA
2. 491 mA
3. 600 mA
4. 200 mA

**正确答案：** 2. 491 mA

**解析：** 只剩下一块电池时，网络可化简为：<i>R</i><sub>3</sub> + <i>R</i><sub>4</sub> = 40 Ω 与 <i>R</i><sub>5</sub> = 5 Ω 并联，得到 4.444 Ω；它再与 <i>R</i><sub>1</sub> + <i>R</i><sub>2</sub> = 20 Ω 串联：

<div class="eq"><i>I</i><sub>1</sub> = 12 V/24.444 Ω = 491 mA</div>

电流从 518 mA 下降：按叠加原理，原先正端在底部的 6 V 电池曾向 <i>I</i><sub>1</sub> 增加 27 mA。把 <i>R</i><sub>5</sub> 当作短路会得到 600 mA；去掉它会得到 200 mA。

### 练习 7.2（自由作答）

**题目：** 在本页的网络中，把第二个电池的电动势 ℰ<sub>2</sub>（正端在底部，如图所示）视为变量。使用本页的两个回路方程以及 <i>I</i><sub>1</sub> = <i>I</i><sub>2</sub> + <i>I</i><sub>3</sub>，求 <i>dI</i><sub>3</sub>/<i>d</i>ℰ<sub>2</sub>，以及使 <i>I</i><sub>3</sub> = 0 时的 ℰ<sub>2</sub>。

**参考答案：**

回路 1：20<i>I</i><sub>1</sub> + 5<i>I</i><sub>2</sub> = 12。回路 2：40<i>I</i><sub>3</sub> − 5<i>I</i><sub>2</sub> = ℰ<sub>2</sub>。将 <i>I</i><sub>1</sub> = <i>I</i><sub>2</sub> + <i>I</i><sub>3</sub> 代入回路 1：

<div class="eq">25<i>I</i><sub>2</sub> + 20<i>I</i><sub>3</sub> = 12 → <i>I</i><sub>2</sub> = (12 − 20<i>I</i><sub>3</sub>)/25</div>

<div class="eq">40<i>I</i><sub>3</sub> − (12 − 20<i>I</i><sub>3</sub>)/5 = ℰ<sub>2</sub> → <i>I</i><sub>3</sub> = (ℰ<sub>2</sub> + 2.4)/44</div>

所以 <i>dI</i><sub>3</sub>/<i>d</i>ℰ<sub>2</sub> = 1/44 A/V = 22.7 mA/V。电路是线性的，因此该结果对任意 ℰ<sub>2</sub> 都成立。当 ℰ<sub>2</sub> = 6 V 时，<i>I</i><sub>3</sub> = 8.4/44 = 0.191 A，即本页的数值。当 <i>I</i><sub>3</sub> = 0 时，ℰ<sub>2</sub> = −2.4 V：这相当于一块 2.4 V、电池正端在**顶部**的电池，恰好抵消 12 V 电池通过 <i>R</i><sub>5</sub> 产生的推动作用。

## 第 8 页

### 练习 8.1

**题目：** 在本页的 RC 电路中（ℰ = 12 V，τ = <i>RC</i> = 2.0 s），电容器起初没有电荷。要经过多长时间，电容器电压才达到 9.0 V？

**选项：**

1. 0.58 s
2. 2.77 s
3. 1.50 s
4. 2.00 s

**正确答案：** 2. 2.77 s

**解析：**

<div class="eq">Δ<i>V</i><sub>C</sub> = ℰ(1 − e<sup>−<i>t</i>/τ</sup>) → <i>t</i> = −τ ln(1 − Δ<i>V</i><sub>C</sub>/ℰ) = 2.0 s × ln 4 = 2.77 s</div>

充电不是线性的（线性估计为 1.50 s）：随着电容器充满，充电速度会变慢。经过一个 τ 后，电压只能达到 12 V 的 63%。

### 练习 8.2

**题目：** 现在，充满电的电容器通过 <i>R</i> 放电。经过一个时间常数后，它所储存的能量中有多大比例已经在 <i>R</i> 中转化为热？

**选项：**

1. 63.2%
2. 86.5%
3. 36.8%
4. 50.0%

**正确答案：** 2. 86.5%

**解析：** 电流为 <i>I</i><sub>0</sub>e<sup>−<i>t</i>/τ</sup>，所以功率 <i>I</i><sup>2</sup><i>R</i> 的衰减速度加倍：

<div class="eq"><i>E</i> = ∫<sub>0</sub><sup>τ</sup> <i>I</i><sub>0</sub><sup>2</sup><i>R</i> e<sup>−2<i>t</i>/τ</sup> <i>dt</i> = ½<i>I</i><sub>0</sub><sup>2</sup><i>R</i>τ(1 − e<sup>−2</sup>) = <i>U</i><sub>0</sub>(1 − e<sup>−2</sup>)</div>

其中 ½<i>I</i><sub>0</sub><sup>2</sup><i>R</i>τ = <i>Q</i><sup>2</sup>/2<i>C</i> = <i>U</i><sub>0</sub>。因此转化为热的比例为 86.5%。电荷已经降至 36.8%，但能量与 <i>q</i><sup>2</sup> 成正比：只剩下 e<sup>−2</sup> = 13.5%。
