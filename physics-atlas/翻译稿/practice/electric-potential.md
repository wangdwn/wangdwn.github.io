# 练习：电势

> 本练习对应 Atlas of Physics《电势》章节的独立练习模块。请为每道题选择一个答案。

## 第 1 页

### 1. 将电荷移近固定电荷所需的功

**题目：** 要把本页的 `+2 nC` 电荷从距离固定的 `+4 nC` 电荷 `40 cm` 处移到 `10 cm` 处（初态和末态均静止），你必须做多少功？

**选项：**

1. `0.719 μJ`
2. `0.539 μJ`
3. `2.158 μJ`
4. `0.240 μJ`

**正确答案：** 2. `0.539 μJ`

**解析：** 你要克服

<div class="eq"><i>F</i> = <i>kq</i><sub>1</sub><i>q</i><sub>2</sub>/<i>r</i>²</div>

而且在移动过程中它会增大，因此要积分：

<div class="eq"><i>W</i> = −∫<sub><i>r</i><sub>0</sub></sub><sup><i>r</i><sub>1</sub></sup> <i>kq</i><sub>1</sub><i>q</i><sub>2</sub>/<i>r</i>² d<i>r</i> = <i>kq</i><sub>1</sub><i>q</i><sub>2</sub>(1/<i>r</i><sub>1</sub> − 1/<i>r</i><sub>0</sub>) = Δ<i>U</i> = 0.539 μJ</div>

`kq₁q₂/r₁`（`0.719 μJ`）是从无穷远移来的功，而不是从 `40 cm` 处移来的功。

### 2. 势能函数的极值

**题目：** 两个粒子之间的势能为 <i>U</i>(<i>r</i>) = <i>A</i>/<i>r</i>² − <i>B</i>/<i>r</i>（<i>A</i>、<i>B</i> > 0）。它们之间的力在什么距离处为零？

**选项：**

1. <i>A</i>/<i>B</i>
2. √(<i>A</i>/<i>B</i>)
3. <i>B</i>/2<i>A</i>
4. 2<i>A</i>/<i>B</i>

**正确答案：** 4. 2<i>A</i>/<i>B</i>

**解析：** <i>F</i> = −d<i>U</i>/d<i>r</i>，所以令斜率为零：

<div class="eq">d<i>U</i>/d<i>r</i> = −2<i>A</i>/<i>r</i>³ + <i>B</i>/<i>r</i>² = 0 &nbsp;→&nbsp; <i>r</i> = 2<i>A</i>/<i>B</i></div>

`A/B` 是 <i>U</i> = 0 的位置，而不是斜率为零的位置。在 `2A/B` 处，<i>U</i> 取得最小值，因此该间距是稳定的。

## 第 2 页

### 3. 正方形四个顶点的电势能

**题目：** 本页的四个 `+2 nC` 电荷位于边长 `20 cm` 的正方形四个顶点。这个电荷组的电势能为

**选项：**

1. `0.719 μJ`
2. `1.947 μJ`
3. `0.973 μJ`
4. `1.228 μJ`

**正确答案：** 3. `0.973 μJ`

**解析：** 一共有六对电荷：四条边上的距离为 <i>a</i>，两条对角线上的距离为 √2<i>a</i>。

<div class="eq"><i>U</i> = 4<i>kq</i>²/<i>a</i> + 2<i>kq</i>²/√2<i>a</i> = (4 + √2)<i>kq</i>²/<i>a</i> = 0.973 μJ</div>

对每个电荷求和 `qV` 会把每一对电荷计算两次（`1.947 μJ`）；对角线长度是 √2<i>a</i>，不是 <i>a</i>/√2。

### 4. 给金属球充电所需的功

**题目：** 一个半径为 `15 cm` 的金属球，通过把微小电荷 d<i>q</i> 从无穷远移来，充电至 `2.0 nC`。所需的总功为

**选项：**

1. `0.240 μJ`
2. `0.060 μJ`
3. `0.120 μJ`
4. `0.799 μJ`

**正确答案：** 3. `0.120 μJ`

**解析：** 当球上已有 <i>q</i> 时，它的电势为 <i>kq</i>/<i>R</i>；移来 d<i>q</i> 所需的功为（<i>kq</i>/<i>R</i>）d<i>q</i>：

<div class="eq"><i>W</i> = ∫<sub>0</sub><sup><i>Q</i></sup> (<i>kq</i>/<i>R</i>) d<i>q</i> = <i>kQ</i>²/2<i>R</i> = 0.120 μJ</div>

`Q` × 最终电势（`0.240 μJ`）相当于让每个 d<i>q</i> 都支付完整的最终价格；最早移来的电荷几乎没有遇到排斥。

## 第 3 页

### 5. 均匀电场中电荷从 A 移到 C

**题目：** 在本页中，一个 `+1 nC` 电荷在 `50 N/C` 的均匀电场中从 A 移到 C，且 <i>V</i><sub>C</sub> − <i>V</i><sub>A</sub> = −10 V。电场对它所做的功为

**选项：**

1. `−10 nJ`
2. `0 nJ`
3. `+22.4 nJ`
4. `+10 nJ`

**正确答案：** 4. `+10 nJ`

**解析：**

<div class="eq"><i>W</i><sub>field</sub> = −Δ<i>U</i> = −<i>q</i>Δ<i>V</i> = −(1 nC)(−10 V) = +10.0 nJ</div>

路径不重要：只有沿 <b>E</b> 方向的 `20 cm` 起作用，而不是 `44.7 cm` 的直线路径（`22.4 nJ`）。正电荷沿 <b>E</b> 移动时会损失 <i>U</i>，因此电场做正功。

### 6. 非均匀电场中的电势差

**题目：** 一个电场沿 +<i>x</i> 方向，且 <i>E</i> = 3<i>x</i>²（单位为 N/C，<i>x</i> 以 m 为单位）。<i>V</i>(2 m) − <i>V</i>(0) 为

**选项：**

1. `+8 V`
2. `−24 V`
3. `−8 V`
4. `−12 V`

**正确答案：** 3. `−8 V`

**解析：**

<div class="eq">Δ<i>V</i> = −∫<sub>0</sub><sup>2</sup> 3<i>x</i>² d<i>x</i> = −<i>x</i>³ |<sub>0</sub><sup>2</sup> = −8 V</div>

沿 <b>E</b> 移动时，<i>V</i> 会下降，因此答案为负。`E(2) × 2 m = 24 V` 把最大电场错误地当成了全程保持不变的电场。

## 第 4 页

### 7. 电势为 90 V 处的场强

**题目：** 在本页的山丘（`+1 nC`）上，<i>V</i> = `90 V` 的点处，电场的大小为

**选项：**

1. `90 N/C`
2. `901 N/C`
3. `451 N/C`
4. `1802 N/C`

**正确答案：** 2. `901 N/C`

**解析：** 先求距离：

<div class="eq"><i>r</i> = <i>kQ</i>/<i>V</i> = 8.99/90 = 9.99 cm</div>

然后求斜率：

<div class="eq"><i>E</i> = −d<i>V</i>/d<i>r</i> = <i>kQ</i>/<i>r</i>² = <i>V</i>/<i>r</i> = 901 N/C</div>

<i>V</i> 和 <i>E</i> 的单位和数量级不同：`90 V` 是山丘的高度，`901 N/C` 是它的陡峭程度。

### 8. 由电势函数求电场

**题目：** 在某区域，<i>V</i>(<i>x</i>, <i>y</i>) = 3<i>x</i>²<i>y</i> − <i>y</i>³（单位：伏特，米）。在 `(1 m, 2 m)` 处，<b>E</b> 的大小为

**选项：**

1. `21.0 N/C`
2. `12.0 N/C`
3. `15.0 N/C`
4. `9.0 N/C`

**正确答案：** 3. `15.0 N/C`

**解析：** <b>E</b> = −∇<i>V</i>，逐个分量计算：

<div class="eq"><i>E<sub>x</sub></i> = −∂<i>V</i>/∂<i>x</i> = −6<i>xy</i> = −12 N/C, &nbsp;<i>E<sub>y</sub></i> = −(3<i>x</i>² − 3<i>y</i>²) = +9 N/C</div>

<div class="eq">|<b>E</b>| = √(144 + 81) = 15.0 N/C</div>

各分量要像向量一样相加，而不是直接作为数字相加（`21.0`）。

## 第 5 页

### 9. 偶极子轴线上点 P 的电势

**题目：** 对于本页的偶极子（<i>x</i> = `−10 cm` 处有 `+1 nC`，<i>x</i> = `+10 cm` 处有 `−1 nC`），轴线上 <i>x</i> = `20 cm` 的 P 点电势为

**选项：**

1. `+59.9 V`
2. `0 V`
3. `−59.9 V`
4. `−44.9 V`

**正确答案：** 3. `−59.9 V`

**解析：** 将两个带符号的 <i>kq</i>/<i>r</i> 相加：

<div class="eq"><i>V</i> = <i>kq</i>/0.30 − <i>kq</i>/0.10 = 30.0 − 89.9 = −59.9 V</div>

P 点离负电荷更近，所以 <i>V</i> < 0。<i>V</i> = 0 位于垂直平分线上，而不在此处；远场近似 −2<i>akq</i>/<i>x</i>²（`−44.9 V`）要求 <i>x</i> ≫ <i>a</i>。

### 10. 偶极子的远场

**题目：** 在该偶极子轴线的很远处、负电荷一侧，<i>V</i> ≈ −2<i>akq</i>/<i>x</i>²。那里的电场为

**选项：**

1. 4<i>akq</i>/<i>x</i>³，方向背离偶极子
2. 2<i>akq</i>/<i>x</i>³，方向指向偶极子
3. 4<i>akq</i>/<i>x</i>³，方向指向偶极子
4. 2<i>akq</i>/<i>x</i>²，方向背离偶极子

**正确答案：** 3. 4<i>akq</i>/<i>x</i>³，方向指向偶极子

**解析：**

<div class="eq"><i>E<sub>x</sub></i> = −d<i>V</i>/d<i>x</i> = −d/d<i>x</i>(−2<i>akq x</i><sup>−2</sup>) = −4<i>akq</i>/<i>x</i>³</div>

负号表示沿 −<i>x</i> 方向，即朝向偶极子。直观上，距离较近的 −<i>q</i> 对正试探电荷的吸引强于距离较远的 +<i>q</i> 对它的排斥。<b>E</b> 从高电势指向低电势，而越靠近内部，<i>V</i> 越低（更负）。

## 第 6 页

### 11. 带电细杆轴线上的电势

**题目：** 本页的细杆带有 `+3 nC` 电荷，长度为 `30 cm`。在越过一端 `10 cm` 的轴线上，电势为

**选项：**

1. `269.7 V`
2. `107.9 V`
3. `54.1 V`
4. `124.6 V`

**正确答案：** 4. `124.6 V`

**解析：**

<div class="eq"><i>V</i> = ∫<sub><i>a</i></sub><sup><i>a</i>+<i>L</i></sup> <i>k</i>λ d<i>x</i>/<i>x</i> = <i>k</i>λ ln((<i>a</i> + <i>L</i>)/<i>a</i>) = 89.9 × ln 4 = 124.6 V</div>

`1/x` 的积分是自然对数；使用 `log₁₀` 会得到 `54.1 V`。把全部电荷集中在中点（`107.9 V`）只适用于很远的距离。

### 12. 由细杆电势求电场

**题目：** 对于该轴线上距细杆一端 `10 cm` 处的 <i>V</i>(<i>a</i>)，电场为

**选项：**

1. `674 N/C`
2. `1246 N/C`
3. `2697 N/C`
4. `899 N/C`

**正确答案：** 1. `674 N/C`

**解析：**

<div class="eq"><i>E</i> = −d<i>V</i>/d<i>a</i> = −<i>k</i>λ[1/(<i>a</i> + <i>L</i>) − 1/<i>a</i>] = <i>kQ</i>/(<i>a</i>(<i>a</i> + <i>L</i>)) = 674 N/C</div>

方向背离细杆。`V/a`（`1246 N/C`）只有在 <i>V</i> ∝ 1/<i>a</i> 时才正确；这里应当求导。

## 第 7 页

### 13. 均匀带电圆环轴线上的电势

**题目：** 本页的圆环带有 `+2 nC` 电荷，<i>R</i> = `15 cm`。在距圆心 `20 cm` 的轴线上，电势为

**选项：**

1. `89.9 V`
2. `71.9 V`
3. `230.1 V`
4. `119.9 V`

**正确答案：** 2. `71.9 V`

**解析：** 每个 d<i>q</i> 到该点的距离都是 √(<i>R</i>² + <i>z</i>²) = `25 cm`，而 <i>V</i> 是标量，因此不需要分解分量：

<div class="eq"><i>V</i> = <i>kQ</i>/√(<i>R</i>² + <i>z</i>²) = 17.98/0.25 = 71.9 V</div>

`230.1` 是电场 <i>kQz</i>/(<i>R</i>² + <i>z</i>²)<sup>3/2</sup> 的数值（单位 N/C）；余弦因子属于 <b>E</b>，不属于 <i>V</i>。

### 14. 半圆环中心的电场

**题目：** 本页的半圆环带有 `+2 nC` 电荷，<i>R</i> = `15 cm`，其圆心处的 <i>V</i> = <i>kQ</i>/<i>R</i>。该处**电场**的大小为

**选项：**

1. `799 N/C`
2. `254 N/C`
3. `509 N/C`
4. `0 N/C`

**正确答案：** 3. `509 N/C`

**解析：** 令 λ = <i>Q</i>/π<i>R</i>，每个 d<i>q</i> = λ<i>R</i> dθ，因此贡献为 <i>k</i>λ dθ/<i>R</i>。以对称轴为 θ 的测量方向；横向分量相互抵消，其余分量相加：

<div class="eq"><i>E</i> = ∫<sub>−π/2</sub><sup>π/2</sup> (<i>k</i>λ/<i>R</i>) cos θ dθ = 2<i>k</i>λ/<i>R</i> = 2<i>kQ</i>/π<i>R</i>² = 509 N/C</div>

不同于 <i>V</i>，<b>E</b> 不能简单写成 <i>kQ</i>/<i>R</i>²（`799 N/C`）：各部分的方向不同。只有完整圆环的电场才为零。

## 第 8 页

### 15. 绝缘实心球内部的电势

**题目：** 本页的绝缘球均匀分布着 `+2 nC` 电荷，<i>R</i> = `10 cm`。距其球心 `5 cm` 处的电势为

**选项：**

1. `359.6 V`
2. `247.2 V`
3. `179.8 V`
4. `269.7 V`

**正确答案：** 2. `247.2 V`

**解析：** 从无穷远向内移动：在球外，−∫<i>E</i> d<i>r</i> 给出 <i>kQ</i>/<i>R</i>；在球内，<i>E</i> = <i>kQr</i>/<i>R</i>³，还会增加以下贡献：

<div class="eq"><i>V</i>(<i>r</i>) = <i>kQ</i>/<i>R</i> + ∫<sub><i>r</i></sub><sup><i>R</i></sup> <i>kQr</i>′/<i>R</i>³ d<i>r</i>′ = (<i>kQ</i>/<i>R</i>)(3/2 − <i>r</i>²/2<i>R</i>²) = 247.2 V</div>

`kQ/r`（`359.6 V`）相当于假设所有电荷都在 <i>r</i> 内；`179.8 V` 是金属球的情形，因为金属球内部 <i>E</i> = 0。

### 16. 两个相连金属球的表面电荷密度

**题目：** 两个金属球的半径满足 <i>R</i><sub>1</sub> = 3<i>R</i><sub>2</sub>。它们相距很远，用细导线相连，然后充电。表面电荷密度之比 σ<sub>1</sub>/σ<sub>2</sub> 为

**选项：**

1. `1/3`
2. `3`
3. `1`
4. `1/9`

**正确答案：** 1. `1/3`

**解析：** 相连后，它们是处于同一电势的一个导体：

<div class="eq"><i>kQ</i><sub>1</sub>/<i>R</i><sub>1</sub> = <i>kQ</i><sub>2</sub>/<i>R</i><sub>2</sub></div>

所以 <i>Q</i><sub>1</sub>/<i>Q</i><sub>2</sub> = <i>R</i><sub>1</sub>/<i>R</i><sub>2</sub> = 3。于是

<div class="eq">σ<sub>1</sub>/σ<sub>2</sub> = (<i>Q</i><sub>1</sub>/<i>R</i><sub>1</sub>²)/(<i>Q</i><sub>2</sub>/<i>R</i><sub>2</sub>²) = 3 × (1/3)² = 1/3</div>

大球携带的电荷更多，但电荷分布得更稀疏：电荷会集中在曲率较大的导体部位。

## 第 9 页

### 17. 质子穿过电势差后的速度

**题目：** 本页的质子从 `7 V` 极板处由静止开始，穿过到 `1 V` 极板。它到达时的速度为

**选项：**

1. `24.0 km/s`
2. `36.6 km/s`
3. `33.9 km/s`
4. `1451.7 km/s`

**正确答案：** 3. `33.9 km/s`

**解析：**

<div class="eq"><i>e</i>Δ<i>V</i> = ½<i>mv</i>² &nbsp;→&nbsp; <i>v</i> = √(2<i>e</i>Δ<i>V</i>/<i>m</i><sub>p</sub>) = √(2 × 1.60 × 10<sup>−19</sup> × 6/1.67 × 10<sup>−27</sup>) = 33.9 km/s</div>

起作用的只有**电势差** `6 V`，而不是起始极板的 `7 V`。对于同样的 `6 eV`，电子的速度是 `1452 km/s`。

### 18. 电子落向正电荷时的速度

**题目：** 一个电子从固定的 `+1 nC` 电荷 `10 cm` 处由静止开始，被吸引着向内运动。它到达距该电荷 `5 cm` 处时的速度为

**选项：**

1. `7.95 × 10<sup>6</sup> m/s`
2. `5.62 × 10<sup>6</sup> m/s`
3. `3.97 × 10<sup>6</sup> m/s`
4. `0.13 × 10<sup>6</sup> m/s`

**正确答案：** 2. `5.62 × 10<sup>6</sup> m/s`

**解析：** 电子落入时力会增大，因此应使用已经包含 ∫<i>F</i> d<i>r</i> 积分的能量方法：

<div class="eq">Δ<i>V</i> = <i>kQ</i>(1/<i>r</i><sub>b</sub> − 1/<i>r</i><sub>a</sub>) = 89.9 V, &nbsp;<i>v</i> = √(2<i>e</i>Δ<i>V</i>/<i>m</i><sub>e</sub>) = 5.62 × 10<sup>6</sup> m/s</div>

只使用 `5 cm` 处的电势（`180 V`）会忽略它开始时位于 `10 cm` 处、初始电势为 `89.9 V` 这一事实，而错误地把初始电势当成了 0。
