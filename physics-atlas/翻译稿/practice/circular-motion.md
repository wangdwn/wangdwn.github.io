## 第 0 页

### 0.1

小球以恒定速率做圆周运动。它的加速度指向哪里？

1. 沿其速度方向，即圆的切线方向
2. 指向圆心
3. 背离圆心
4. 哪儿也不指向：恒定速率意味着加速度为零

**正确答案：** 2. 指向圆心

**解析：** 速度是矢量；它的方向持续转向圆心，因此 Δ<i>v</i>（以及 <i>a</i>）指向圆心，并且与 <i>v</i> 垂直。恒定的**速率**意味着 <i>a</i> 沿 <i>v</i> 的分量为零，而不是 <i>a</i> 本身为零。

### 0.2

小球以 4.0 m/s 而不是 2.0 m/s 的速度，沿同一个半径为 0.80 m 的圆运动。它的向心加速度是多少？

1. 10.0 m/s²
2. 5.00 m/s²
3. 20.0 m/s²
4. 2.50 m/s²

**正确答案：** 3. 20.0 m/s²

**解析：**

<div class="eq"><i>a</i><sub>c</sub> = <i>v</i>²/<i>r</i> = (4.0)² / 0.80 = 20.0 m/s²</div>

速率要平方：速度变为两倍会得到 5.00 m/s² 的四倍，而不是两倍。

## 第 1 页

### 1.1

质量为 0.20 kg 的小球仍以 2.0 m/s 运动，但所用细绳长度减半，为 0.40 m。张力是多少？

1. 2.00 N
2. 0.500 N
3. 4.00 N
4. 1.00 N

**正确答案：** 1. 2.00 N

**解析：** 在光滑桌面上，张力是唯一的水平力，因此它就是全部向心力：

<div class="eq"><i>T</i> = <i>mv</i>²/<i>r</i> = 0.20 × (2.0)² / 0.40 = 2.00 N</div>

在速率不变时将 <i>r</i> 减半，会使 <i>T</i> 加倍（从 1.00 N 变为 2.00 N）。

### 1.2

从上方看，细绳在小球绕圈时断裂。断裂后，小球立即沿什么方向运动？

1. 沿向外的螺旋线
2. 从圆心沿原细绳方向直冲出去
3. 沿该点处切线方向做直线运动
4. 仍在同一个圆上运动，但速率逐渐减小

**正确答案：** 3. 沿该点处切线方向做直线运动

**解析：** 细绳消失后，没有水平力，因此根据牛顿第一定律，小球保持原有速度：沿圆的切线方向做直线运动。不存在把它沿径向甩出去的向外力。

## 第 2 页

### 2.1

下雨天轮胎的静摩擦因数 μ<sub>s</sub> 降至 0.40。汽车通过水平的 10 m 弯道时所能达到的最大速度是多少？

1. 8.85 m/s
2. 4.43 m/s
3. 39.2 m/s
4. 6.26 m/s

**正确答案：** 4. 6.26 m/s

**解析：** 在极限情况下，最大静摩擦力恰好等于所需向心力：μ<sub>s</sub><i>mg</i> = <i>mv</i>²/<i>r</i>。

<div class="eq"><i>v</i><sub>max</sub> = √(μ<sub>s</sub><i>gr</i>) = √(0.40 × 9.80 × 10) = 6.26 m/s</div>

将 μ<sub>s</sub> 减半，会使 <i>v</i><sub>max</sub> 除以 √2，而不是除以 2。

### 2.2

一辆质量为汽车两倍的卡车，使用相同的轮胎并在同一个水平弯道上行驶，也以它所能达到的最大速度通过弯道。与汽车的最高速度相比，卡车的最高速度是：

1. 一半
2. 1/√2
3. 相同
4. √2 倍

**正确答案：** 3. 相同

**解析：** μ<sub>s</sub><i>mg</i> = <i>mv</i>²/<i>r</i>：质量在等式两边约去，<i>v</i><sub>max</sub> = √(μ<sub>s</sub><i>gr</i>)。卡车需要两倍的摩擦力，但它加倍的重量也使路面能够提供两倍的摩擦力。

## 第 3 页

### 3.1

质量为 0.20 kg 的小球系在 1.0 m 长的细绳上，被加速旋转，直到细绳与竖直方向成 60°。小球的速度是多少？

1. 4.12 m/s
2. 2.21 m/s
3. 3.83 m/s
4. 3.13 m/s

**正确答案：** 3. 3.83 m/s

**解析：** 半径是水平伸出距离 <i>r</i> = <i>L</i> sin θ = 0.866 m，而不是 <i>L</i>。由 <i>g</i> tan θ = <i>v</i>²/<i>r</i>：

<div class="eq"><i>v</i> = √(<i>rg</i> tan θ) = √(0.866 × 9.80 × 1.732) = 3.83 m/s</div>

2.21 m/s 使用的是相对于水平方向的角的正切。

### 3.2

同一个小球，细绳与竖直方向成 60°。细绳中的张力是多少？

1. 3.92 N
2. 0.980 N
3. 2.26 N
4. 1.96 N

**正确答案：** 1. 3.92 N

**解析：** 竖直方向没有加速度，因此细绳的竖直分量支撑重力：

<div class="eq"><i>T</i> cos θ = <i>mg</i> &nbsp;→ <i>T</i> = 1.96 / cos 60° = 3.92 N</div>

张力必须**大于** <i>mg</i>，因为张力只有一部分指向上方；<i>mg</i> cos θ 的方向是错误的。

## 第 4 页

### 4.1

质量为 500 kg 的小车在半径为 6.0 m 的环形轨道顶端倒置通过，速度为 9.0 m/s。轨道对它的推力有多大？

1. 11.7 kN
2. 1.85 kN
3. 6.75 kN
4. 4.90 kN

**正确答案：** 2. 1.85 kN

**解析：** 在顶端，两个力都向下、都指向圆心，并且共同提供 <i>mv</i>²/<i>r</i>：

<div class="eq"><i>F</i><sub>N</sub> + <i>mg</i> = <i>mv</i>²/<i>r</i> &nbsp;→ <i>F</i><sub>N</sub> = 500(13.50 − 9.80) = 1850 N = 1.85 kN</div>

加上 <i>mg</i> 是**环底**的方程，而不是这里的方程。

### 4.2

小车以多慢的速度通过半径为 6.0 m 的环形轨道顶端，才能保持在轨道上？

1. 10.8 m/s
2. 58.8 m/s
3. 5.42 m/s
4. 7.67 m/s

**正确答案：** 4. 7.67 m/s

**解析：** 速度越慢，轨道的推力越小。极限是 <i>F</i><sub>N</sub> = 0，此时仅由重力提供向心力：

<div class="eq"><i>mg</i> = <i>mv</i>²/<i>r</i> &nbsp;→ <i>v</i><sub>min</sub> = √(<i>gr</i>) = √(9.80 × 6.0) = 7.67 m/s</div>

质量约去；如果速度低于这个值，重力会把小车拉向圆内，小车就会离开轨道。

## 第 5 页

### 5.1

一条半径为 40 m 的弯道倾斜角同样为 20°。汽车在完全没有摩擦力的情况下，以多大速度通过它？

1. 5.97 m/s
2. 19.8 m/s
3. 143 m/s
4. 11.9 m/s

**正确答案：** 4. 11.9 m/s

**解析：** 竖直方向：<i>F</i><sub>N</sub> cos θ = <i>mg</i>。水平方向：<i>F</i><sub>N</sub> sin θ = <i>mv</i>²/<i>r</i>。两式相除：

<div class="eq">tan θ = <i>v</i>²/(<i>rg</i>) &nbsp;→ <i>v</i> = √(40 × 9.80 × tan 20°) = 11.9 m/s</div>

半径是 10 m 的弯道上速度为 5.97 m/s；半径变为四倍，速度变为两倍。

### 5.2

在结冰（无摩擦）的倾斜弯道上，汽车比该倾角对应的合适速度更快。会发生什么？

1. 汽车沿倾斜面向上、朝弯道外侧漂移。
2. 汽车沿倾斜面向下、朝弯道内侧滑动。
3. 汽车会沿弯道行驶，因为法向力会增大以匹配需要。
4. 汽车停止转弯，沿斜面直线向下运动。

**正确答案：** 1. 汽车沿倾斜面向上、朝弯道外侧漂移。

**解析：** 没有摩擦力时，法向力必须同时托住汽车（<i>F</i><sub>N</sub> cos θ = <i>mg</i>）并使它转弯，因此其水平分量固定为 <i>mg</i> tan θ。速度更快的汽车需要更大的水平力，所以它无法沿该圆周运动，会移向更大的半径并沿倾斜面向上漂移。

## 第 6 页

### 6.1

一个转盘以 33⅓ rpm 的转速转动。距中心 0.15 m 处的一小粒尘埃移动得有多快？

1. 0.0833 m/s
2. 0.524 m/s
3. 5.00 m/s
4. 1.05 m/s

**正确答案：** 2. 0.524 m/s

**解析：** 先转换为 rad/s：ω = 33⅓ × 2π/60 = 3.491 rad/s。然后

<div class="eq"><i>v</i> = <i>r</i>ω = 0.15 × 3.491 = 0.524 m/s</div>

只有当 ω 的单位为 rad/s 时，<i>v</i> = <i>r</i>ω 才成立；5.00 直接使用 rpm，0.0833 使用 rev/s 而忘记乘以 2π。

### 6.2

两个方块分别位于距旋转圆盘中心 0.40 m 和 0.80 m 处。与内侧方块相比，外侧方块的向心加速度是：

1. 一半
2. 相同
3. 两倍
4. 四倍

**正确答案：** 3. 两倍

**解析：** 两者共享同一个 ω，因此 <i>a</i><sub>c</sub> = <i>v</i>²/<i>r</i> = <i>r</i>ω²，与 <i>r</i> 成正比。（使用 <i>v</i>²/<i>r</i> 时，<i>v</i> 加倍而 <i>r</i> 也加倍：4/2 = 2，而不是 4。）

## 第 7 页

### 7.1

两个球以力 <i>F</i> 相互吸引。将其中一个球的质量变为原来的三倍，并将两球球心之间的距离变为原来的两倍。力变为：

1. 0.750 <i>F</i>
2. 1.50 <i>F</i>
3. 0.375 <i>F</i>
4. 12.0 <i>F</i>

**正确答案：** 1. 0.750 <i>F</i>

**解析：** <i>F</i> ∝ <i>m</i><sub>1</sub><i>m</i><sub>2</sub>/<i>r</i>²：将各因素相乘，3 × 1 / 2² = ¾。忘记将 <i>r</i> 平方会得到 1.5 <i>F</i>。

### 7.2

在距地球表面一个地球半径的高度处，引力场强（自由落体加速度）是多少？（地表处 <i>g</i> = 9.80 m/s²）

1. 4.90 m/s²
2. 2.45 m/s²
3. 1.09 m/s²
4. 9.80 m/s²

**正确答案：** 2. 2.45 m/s²

**解析：** “距地表上方一个半径”意味着距地心为 2<i>R</i><sub>E</sub>，而 <i>g</i> = <i>GM</i>/<i>r</i>²，随 1/<i>r</i>² 衰减：

<div class="eq"><i>g</i>′ = 9.80 / 2² = 2.45 m/s²</div>

把它减半，是把引力误当作按 1/<i>r</i> 变化。

## 第 8 页

### 8.1

卫星 B 的轨道半径是卫星 A 的两倍（两者都绕同一颗行星做圆轨道运动）。B 的周期是 A 的多少倍？

1. 1.41
2. 2.00
3. 4.00
4. 2.83

**正确答案：** 4. 2.83

**解析：** 开普勒第三定律 <i>T</i>² ∝ <i>r</i>³，因此 <i>T</i> ∝ <i>r</i><sup>3/2</sup>：2<sup>3/2</sup> = 2.83。（对照表中 2 <i>R</i><sub>E</sub> 和 4 <i>R</i><sub>E</sub> 的数据：3.98 h 和 11.27 h。）

### 8.2

卫星在半径为 3 <i>R</i><sub>E</sub> 的圆轨道上运行时，速度有多大？（<i>GM</i><sub>E</sub> = 3.99 × 10<sup>14</sup> m³/s²，<i>R</i><sub>E</sub> = 6.38 × 10<sup>6</sup> m）

1. 2.64 km/s
2. 6.46 km/s
3. 4.57 km/s
4. 7.91 km/s

**正确答案：** 3. 4.57 km/s

**解析：** 引力就是向心力：<i>GMm</i>/<i>r</i>² = <i>mv</i>²/<i>r</i>，因此

<div class="eq"><i>v</i> = √(<i>GM</i>/<i>r</i>) = √(3.99 × 10<sup>14</sup> / 1.914 × 10<sup>7</sup>) = 4.57 km/s</div>

<i>v</i> ∝ 1/√<i>r</i>，而不是 1/<i>r</i>；带 √2 的选项是逃逸速度。

## 第 9 页

### 9.1

一颗卫星的轨道从近地点 2 <i>R</i><sub>E</sub> 延伸到远地点 4 <i>R</i><sub>E</sub>。它在近地点的速度为 6.46 km/s。在远地点的速度是多少？

1. 1.61 km/s
2. 3.23 km/s
3. 4.57 km/s
4. 12.9 km/s

**正确答案：** 2. 3.23 km/s

**解析：** 关于地球的角动量守恒（引力关于地球不产生力矩），并且在两个端点处 <i>v</i> ⟂ <i>r</i>：

<div class="eq"><i>r</i><sub>p</sub><i>v</i><sub>p</sub> = <i>r</i><sub>a</sub><i>v</i><sub>a</sub> &nbsp;→ <i>v</i><sub>a</sub> = 6.46 × 2/4 = 3.23 km/s</div>

√(<i>GM</i>/<i>r</i>) 的标度关系（4.57 km/s）只适用于两个**圆**轨道之间的比较。

### 9.2

对于沿椭圆轨道运动的卫星，在近地点和远地点哪个量相同？

1. 它的速率
2. 它的动能
3. 它关于地心的角动量
4. 作用在它身上的引力

**正确答案：** 3. 它关于地心的角动量

**解析：** 引力指向地心，因此关于地心不产生力矩，<i>L</i> = <i>mvr</i><sub>⊥</sub> 保持不变。速率和动能在近地点最大；引力在近地点也最大（因为 <i>r</i> 更小）。

## 第 10 页

### 10.1

在本页的轨道中，质量为 1000 kg 的卫星在近地点的 <i>K</i> = 23.44 GJ、<i>U</i> = −31.26 GJ。在远地点 <i>U</i> = −10.42 GJ。远地点的 <i>K</i> 是多少？

1. 23.4 GJ
2. 7.81 GJ
3. 2.60 GJ
4. 44.3 GJ

**正确答案：** 3. 2.60 GJ

**解析：** 只有引力做功，而且引力是保守力，因此两端的 <i>K</i> + <i>U</i> 相同：

<div class="eq"><i>K</i><sub>a</sub> = <i>K</i><sub>p</sub> + <i>U</i><sub>p</sub> − <i>U</i><sub>a</sub> = 23.44 + (−31.26) − (−10.42) = 2.60 GJ</div>

检查：速度变为三分之一，因此动能变为九分之一。44.3 GJ 是把负的 <i>U</i> 项符号弄错造成的。

### 10.2

卫星从近地点爬升到远地点时，卫星—地球系统的能量发生了什么变化？

1. K 减小，U 增大（变得不那么负），E 保持不变
2. K 减小，U 减小，E 减小
3. K 保持不变，U 增大，E 增大
4. K 和 U 都增大，因此 E 增大

**正确答案：** 1. K 减小，U 增大（变得不那么负），E 保持不变

**解析：** 向外爬升时，引力有一部分与 <i>v</i> 反向并做负功，因此 <i>K</i> 减小。<i>U</i> = −<i>GMm</i>/<i>r</i> 向零增大，增大的量恰好相同。没有外力做功，因此 <i>E</i> = <i>K</i> + <i>U</i> 保持不变。

## 第 11 页

### 11.1

一颗质量为 1000 kg 的卫星从 <i>r</i> = 4 <i>R</i><sub>E</sub> 落到 2 <i>R</i><sub>E</sub> 时，重力做了多少功？（<i>GM</i><sub>E</sub> = 3.99 × 10<sup>14</sup> m³/s²）

1. −15.6 GJ
2. 15.6 GJ
3. 125 GJ
4. 31.3 GJ

**正确答案：** 2. 15.6 GJ

**解析：** 力随 <i>r</i> 变化，因此要积分。重力指向内，<i>F</i><sub>r</sub> = −<i>GMm</i>/<i>r</i>²：

<div class="eq"><i>W</i> = ∫<sub>4<i>R</i></sub><sup>2<i>R</i></sup> (−<i>GMm</i>/<i>r</i>²) d<i>r</i> = <i>GMm</i>[1/<i>r</i>]<sub>4<i>R</i></sub><sup>2<i>R</i></sup> = <i>GMm</i>/4<i>R</i> = 15.6 GJ</div>

结果为正：力和位移都指向内。使用 <i>mgh</i> 且取 <i>h</i> = 2<i>R</i><sub>E</sub>（125 GJ），相当于假定整个上升过程中 <i>g</i> 始终保持 9.80 m/s²。

### 11.2

求质量为 1000 kg 的物体从地面升高到 <i>h</i> = 100 km 时势能的精确变化量，并将其与 <i>mgh</i> 比较，说明分数差约为 <i>h</i>/<i>R</i><sub>E</sub>。

**解答：**

1. Δ<i>U</i> = −∫<sub><i>R</i></sub><sup><i>R</i>+<i>h</i></sup> <i>F</i><sub>r</sub> d<i>r</i> = ∫<sub><i>R</i></sub><sup><i>R</i>+<i>h</i></sup> <i>GMm</i>/<i>r</i>² d<i>r</i> = <i>GMm</i>(1/<i>R</i> − 1/(<i>R</i> + <i>h</i>)) = <i>GMmh</i> / [<i>R</i>(<i>R</i> + <i>h</i>)]。

<div class="eq">Δ<i>U</i> = 0.9648 GJ</div>

2. 取 <i>g</i> = <i>GM</i>/<i>R</i>² = 9.80 m/s²：<i>mgh</i> = <i>GMmh</i>/<i>R</i>² = 0.9799 GJ。

3. 比值：<i>mgh</i>/Δ<i>U</i> = (<i>R</i> + <i>h</i>)/<i>R</i> = 1 + <i>h</i>/<i>R</i> = 1 + 100/6380 = 1.0157。因此 <i>mgh</i> 偏高 1.6%，因为它把 <i>g</i> 在整个上升过程中都保持为地表值。

## 第 12 页

### 12.1

从距地心 4 <i>R</i><sub>E</sub> 处逃逸所需的速度是多少？（<i>GM</i><sub>E</sub> = 3.99 × 10<sup>14</sup> m³/s²，<i>R</i><sub>E</sub> = 6.38 × 10<sup>6</sup> m）

1. 3.95 km/s
2. 5.59 km/s
3. 2.80 km/s
4. 7.91 km/s

**正确答案：** 2. 5.59 km/s

**解析：** 要恰好到达无穷远处，<i>E</i> = ½<i>mv</i>² − <i>GMm</i>/<i>r</i> = 0：

<div class="eq"><i>v</i><sub>esc</sub> = √(2<i>GM</i>/<i>r</i>) = √(2 × 3.99 × 10<sup>14</sup> / 2.552 × 10<sup>7</sup>) = 5.59 km/s</div>

它是该处圆轨道速度 3.95 km/s 的 √2 倍，而不是 2 倍；并且它随 1/√<i>r</i> 变化，而不是随 1/<i>r</i> 变化。

### 12.2

质量为 1000 kg 的卫星在 <i>r</i> = 2 <i>R</i><sub>E</sub> 处做圆轨道运动。证明 <i>K</i> = −<i>U</i>/2，然后求使其逃逸所需加入的最小能量，以及通过一次侧向点火实现逃逸所需的速度增量。

**解答：**

1. 圆轨道：<i>GMm</i>/<i>r</i>² = <i>mv</i>²/<i>r</i>，所以 <i>K</i> = ½<i>mv</i>² = <i>GMm</i>/2<i>r</i> = −<i>U</i>/2，并且 <i>E</i> = <i>K</i> + <i>U</i> = −<i>GMm</i>/2<i>r</i>。

<div class="eq"><i>E</i> = −3.99 × 10<sup>14</sup> × 1000 / (2 × 1.276 × 10<sup>7</sup>) = −15.63 GJ</div>

2. 逃逸需要 <i>E</i> ≥ 0（等价地，需要足够大的 <i>K</i> 来提供克服引力所需的功 ∫<sub><i>r</i></sub><sup>∞</sup> <i>GMm</i>/<i>r</i>′² d<i>r</i>′ = <i>GMm</i>/<i>r</i>）。因此至少要加入 15.63 GJ。

3. 速度：<i>v</i><sub>c</sub> = √(<i>GM</i>/<i>r</i>) = 5.59 km/s，<i>v</i><sub>esc</sub> = √(2<i>GM</i>/<i>r</i>) = 7.91 km/s，因此沿 <i>v</i> 方向增加 2.32 km/s 的速度即可。
