# 练习：振荡

## 第 1 页

### 题目 1

物块以振幅 <i>A</i> = 0.50 m 振荡。一个完整周期内它行进多远？

**选项**

1. 0 m
2. 0.50 m
3. 1.00 m
4. 2.00 m

**正确答案：** 4. 2.00 m

**解析：** 从 +<i>A</i> 到 −<i>A</i> 是 2<i>A</i>，再返回又是 2<i>A</i>：4<i>A</i> = 2.00 m。它在一个周期内的<strong>位移</strong>为 0，因为它最终回到了出发位置。

### 题目 2

周期为 1.571 s。频率是多少？

**选项**

1. 1.57 Hz
2. 0.637 Hz
3. 4.00 Hz
4. 0.250 Hz

**正确答案：** 2. 0.637 Hz

**解析：**

<div class="eq"><i>f</i> = 1/<i>T</i> = 1/1.571 = 0.637 Hz</div>

4.00 是 ω = 2π<i>f</i>（单位为 rad/s），即角频率，而不是每秒的周期数。

## 第 2 页

### 题目 1

取平衡位置右侧为正方向。物块（<i>k</i> = 16 N/m）位于 <i>x</i> = −0.20 m 处。弹簧对它的作用力是多少？

**选项**

1. +3.20 N
2. −3.20 N
3. +80.0 N
4. +1.60 N

**正确答案：** 1. +3.20 N

**解析：**

<div class="eq"><i>F</i><sub>s</sub> = −<i>k</i>Δ<i>x</i> = −16 × (−0.20) = +3.20 N</div>

弹簧被压向左侧，因此它把物块向右、也就是朝向平衡位置推。−3.20 N 漏掉了负号。

### 题目 2

1.0 kg 物块在 <i>x</i> = +0.25 m 处的加速度是多少？

**选项**

1. +4.00 m/s²
2. −1.00 m/s²
3. −8.00 m/s²
4. −4.00 m/s²

**正确答案：** 4. −4.00 m/s²

**解析：**

<div class="eq"><i>a</i> = −(<i>k</i>/<i>m</i>)<i>x</i> = −(16/1.0) × 0.25 = −4.00 m/s²</div>

加速度并非常量：−8.00 m/s² 只有在 <i>x</i> = +<i>A</i> 处才是它的值。−ω<i>x</i> 忘记了要将 ω 平方。

## 第 3 页

### 题目 1

在物块位于 <i>x</i> = +<i>A</i> 的瞬间，

**选项**

1. <i>v</i> = 0 且 <i>a</i> = 0
2. <i>v</i> 最大且 <i>a</i> = 0
3. <i>v</i> = 0 且 <i>a</i> 最大，方向指向 −<i>x</i>
4. <i>v</i> = 0 且 <i>a</i> 最大，方向指向 +<i>x</i>

**正确答案：** 3. <i>v</i> = 0 且 <i>a</i> 最大，方向指向 −<i>x</i>

**解析：** <i>x</i>–<i>t</i> 图像在这里达到峰值：斜率为零，因此 <i>v</i> = 0。并且 <i>a</i> = −ω²<i>x</i> 的大小最大，方向指回平衡位置，即 −<i>x</i> 方向。

### 题目 2

已知 <i>A</i> = 0.50 m、ω = 4.0 rad/s，物块在 <i>x</i> = 0.30 m 处运动得多快？

**选项**

1. 2.00 m/s
2. 1.20 m/s
3. 1.60 m/s
4. 0.80 m/s

**正确答案：** 3. 1.60 m/s

**解析：** 根据能量关系，½<i>mv</i>² = ½<i>k</i>(<i>A</i>² − <i>x</i>²)，所以

<div class="eq"><i>v</i> = ω√(<i>A</i>² − <i>x</i>²) = 4.0 × √(0.25 − 0.09) = 1.60 m/s</div>

2.00 m/s 只有在 <i>x</i> = 0 处才是速度。

## 第 4 页

### 题目 1

总能量 ½<i>kA</i>² = 2.00 J。物块在 <i>x</i> = <i>A</i>/2 处的动能是多少？

**选项**

1. 1.00 J
2. 1.50 J
3. 0.50 J
4. 2.00 J

**正确答案：** 2. 1.50 J

**解析：**

<div class="eq"><i>U</i> = ½<i>k</i>(<i>A</i>/2)² = ¼ × ½<i>kA</i>² = 0.50 J &nbsp;⇒&nbsp; <i>K</i> = 2.00 − 0.50 = 1.50 J</div>

离开平衡位置一半并不意味着能量的一半：<i>U</i> 随 <i>x</i>² 增长。0.50 J 是弹簧势能所占的部分。

### 题目 2

振幅加倍。总能量和最大速度将变为

**选项**

1. 能量 ×2，最大速度 ×2
2. 能量 ×4，最大速度 ×2
3. 能量 ×4，最大速度 ×4
4. 能量 ×2，最大速度 ×√2

**正确答案：** 2. 能量 ×4，最大速度 ×2

**解析：** <i>E</i> = ½<i>kA</i>² 增加为 4 倍。<i>v</i><sub>max</sub> = ω<i>A</i>，而 ω = √(<i>k</i>/<i>m</i>) 不变，因此最大速度加倍（动能变为 4 倍 ⇒ 速度变为 2 倍）。

## 第 5 页

### 题目 1

一个 0.50 kg 的物块悬挂在同一根 16 N/m 的弹簧上。弹簧伸长多远才能达到新的平衡位置？

**选项**

1. 0.0313 m
2. 0.613 m
3. 3.27 m
4. 0.306 m

**正确答案：** 4. 0.306 m

**解析：**

<div class="eq"><i>kd</i> = <i>mg</i> &nbsp;⇒&nbsp; <i>d</i> = 0.50 × 9.80 / 16 = 0.306 m</div>

质量减半，下垂量也减半（0.613 m 是 1.0 kg 物块对应的下垂量）。0.0313 m 忘记了 <i>g</i>：它用的是质量，而不是重力；3.27 m 则把公式颠倒了。

### 题目 2

1.0 kg 的物块围绕平衡位置上下振动，振幅为 0.30 m（下垂量为 0.613 m）。在最低点，弹簧对它的作用力是多少？

**选项**

1. 9.80 N
2. 14.60 N
3. 4.80 N
4. 5.00 N

**正确答案：** 2. 14.60 N

**解析：** 在最低点，弹簧伸长了 <i>d</i> + <i>A</i> = 0.9125 m：

<div class="eq"><i>F</i><sub>s</sub> = <i>k</i>(<i>d</i> + <i>A</i>) = 16 × 0.9125 = 14.60 N</div>

这比重力大 4.80 N：因此合力为向上的 4.80 N，方向指回平衡位置。5.00 N 是最高点的力。

## 第 6 页

### 题目 1

1.5 m 长的摆（在地球上的周期为 2.46 s）被带到月球，月球上的 <i>g</i> = 1.62 m/s²。它在那里的周期是多少？

**选项**

1. 6.05 s
2. 2.46 s
3. 14.9 s
4. 0.999 s

**正确答案：** 1. 6.05 s

**解析：**

<div class="eq"><i>T</i> = 2π√(<i>L</i>/<i>g</i>) = 2π√(1.5/1.62) = 6.05 s</div>

重力较弱，摆动较慢，但只慢了 √(9.80/1.62) = 2.46 倍，而不是完整的比值 9.80/1.62 = 6.05 倍；后者会得到 14.9 s。

### 题目 2

同一个摆从静止状态释放，释放角为 8°。摆锤在最低点运动得多快？

**选项**

1. 2.02 m/s
2. 5.42 m/s
3. 0.378 m/s
4. 0.535 m/s

**正确答案：** 4. 0.535 m/s

**解析：** 它下降的高度为 Δ<i>y</i> = <i>L</i>(1 − cos θ<sub>0</sub>) = 1.46 cm。

<div class="eq"><i>v</i> = √(2<i>g</i>Δ<i>y</i>) = 0.535 m/s</div>

√(2<i>gL</i>) 要求下降整根摆线的长度；sin θ<sub>0</sub> 给出的是侧向距离，而不是高度。

## 第 7 页

### 题目 1

1.0 kg 的物块连接在 16 N/m 的弹簧上，周期为 1.57 s。哪一个弹簧劲度系数会使周期加倍？

**选项**

1. 8.0 N/m
2. 32.0 N/m
3. 4.0 N/m
4. 64.0 N/m

**正确答案：** 3. 4.0 N/m

**解析：** <i>T</i> ∝ 1/√<i>k</i>。要使 2<i>T</i>，√(<i>k</i><sub>new</sub>) 必须是 √<i>k</i> 的一半，因此 <i>k</i><sub>new</sub> = <i>k</i>/4 = 4.0 N/m。将 <i>k</i> 减半只会使周期变为 √2 倍；更硬的弹簧会使周期变短。

### 题目 2

一个 0.75 m 长的摆周期为 1.74 s。若要周期为 3.0 s，摆长应是多少？

**选项**

1. 1.29 m
2. 4.68 m
3. 22.1 m
4. 2.23 m

**正确答案：** 4. 2.23 m

**解析：**

<div class="eq"><i>L</i> = <i>g</i>(<i>T</i>/2π)² = 9.80 × (3.0/2π)² = 2.23 m</div>

或者按比例计算：<i>L</i> ∝ <i>T</i>²，所以 0.75 × (3.0/1.74)² = 2.23 m。若按时间比本身缩放 <i>L</i>，会得到 1.29 m。

## 第 8 页

### 题目 1

水平弹簧上的物块在释放前被拉出原来两倍的距离。与原来相比，它的周期和最大速度是

**选项**

1. 周期相同，最大速度加倍
2. 周期加倍，最大速度相同
3. 两者都相同
4. 周期 ×√2，最大速度加倍

**正确答案：** 1. 周期相同，最大速度加倍

**解析：** <i>T</i> = 2π√(<i>m</i>/<i>k</i>) 中没有 <i>A</i>。距离加倍，力加倍，加速度加倍：它在相同时间内走过两倍路程，因此 <i>v</i><sub>max</sub> = ω<i>A</i> 加倍。

### 题目 2

以下哪种变化会改变简谐摆钟的周期？

**选项**

1. 摆锤质量变为四倍
2. 摆幅从 8° 变为 4°
3. 把它移到月球
4. 用推力启动，而不是从静止状态启动

**正确答案：** 3. 把它移到月球

**解析：** <i>T</i> = 2π√(<i>L</i>/<i>g</i>) 只取决于 <i>L</i> 和 <i>g</i>。质量会约去（<i>ma</i> = −<i>mg</i> sin θ），小振幅都给出相同的周期，而推力只会改变振幅。

## 第 9 页

### 题目 1

1.0 kg 的物块连接在 16 N/m 的弹簧上，初始位置为 <i>x</i><sub>0</sub> = 0.30 m，初速度为 <i>v</i><sub>0</sub> = −1.6 m/s。它的振幅是多少？

**选项**

1. 0.500 m
2. 0.300 m
3. 0.700 m
4. 1.628 m

**正确答案：** 1. 0.500 m

**解析：** ω = √(<i>k</i>/<i>m</i>) = 4.0 rad/s。根据能量关系，½<i>kA</i>² = ½<i>kx</i><sub>0</sub>² + ½<i>mv</i><sub>0</sub>²：

<div class="eq"><i>A</i> = √(<i>x</i><sub>0</sub>² + (<i>v</i><sub>0</sub>/ω)²) = √(0.30² + 0.40²) = 0.500 m</div>

推力增加了能量，所以 <i>A</i> &gt; <i>x</i><sub>0</sub>。两部分要按平方相加，而不是直接相加；√(<i>x</i><sub>0</sub>² + <i>v</i><sub>0</sub>²) 把米和米每秒混在了一起。

### 题目 2（开放作答）

证明 <i>x</i> = <i>A</i> cos(ω<i>t</i> + φ) 能够满足 <i>m</i> d²<i>x</i>/d<i>t</i>² = −<i>kx</i>。对于上题中受到推动的物块，求 φ 以及它第一次经过 <i>x</i> = 0 的时刻。

**参考解答：** 对表达式求两次导数：d<i>x</i>/d<i>t</i> = −<i>A</i>ω sin(ω<i>t</i> + φ)，d²<i>x</i>/d<i>t</i>² = −<i>A</i>ω² cos(ω<i>t</i> + φ) = −ω²<i>x</i>。当 ω = √(<i>k</i>/<i>m</i>) = 4.0 rad/s 时，对任意 <i>t</i>，这都等于 −(<i>k</i>/<i>m</i>)<i>x</i>。

在 <i>t</i> = 0 时：<i>A</i> cos φ = 0.30 m，且 −<i>A</i>ω sin φ = −1.6 m/s，因此 tan φ = −<i>v</i><sub>0</sub>/ω<i>x</i><sub>0</sub> = 1.333，并且 cos φ &gt; 0：

<div class="eq">φ = 53.1° = 0.927 rad，&nbsp; <i>A</i> = 0.500 m</div>

它第一次达到 <i>x</i> = 0 时，ω<i>t</i> + φ = π/2：

<div class="eq"><i>t</i> = (π/2 − φ)/ω = (1.571 − 0.927)/4.0 = 0.161 s</div>

这比四分之一周期（0.393 s）更早，因为它从更靠近平衡位置处出发，并且已经在向平衡位置运动。

## 第 10 页

### 题目 1

一根长 1.5 m 的均匀细杆绕一端摆动。小幅摆动时它的周期是多少？

**选项**

1. 2.46 s
2. 1.74 s
3. 2.01 s
4. 1.00 s

**正确答案：** 3. 2.01 s

**解析：** 绕端点的转动惯量为 <i>I</i> = <i>I</i><sub>cm</sub> + <i>m</i>(<i>L</i>/2)² = <i>mL</i>²/12 + <i>mL</i>²/4 = <i>mL</i>²/3，并且 <i>d</i> = <i>L</i>/2：

<div class="eq"><i>T</i> = 2π√(<i>I</i>/<i>mgd</i>) = 2π√(2<i>L</i>/3<i>g</i>) = 2.01 s</div>

1.74 s 把它当作位于质心处的质点摆；1.00 s 使用的是绕质心的 <i>I</i><sub>cm</sub>，而不是绕支点的转动惯量。

### 题目 2（开放作答）

一根半径 <i>R</i> = 0.40 m 的细圆环通过边缘挂在钉子上。求它绕钉子的转动惯量，写出它在自身平面内小幅摆动时的运动方程，并求周期。

**参考解答：** 关于圆环中心，圆环的每一小部分到中心的距离都是 <i>R</i>：<i>I</i><sub>cm</sub> = ∫<i>R</i>² d<i>m</i> = <i>mR</i>²。钉子到中心的距离为 <i>d</i> = <i>R</i>，所以根据平行轴定理，<i>I</i> = <i>mR</i>² + <i>mR</i>² = 2<i>mR</i>²。

重力作用在圆心：τ = −<i>mgR</i> sin θ ≈ −<i>mgR</i>θ。由 τ = <i>I</i>α：

<div class="eq">d²θ/d<i>t</i>² = −(<i>mgR</i>/2<i>mR</i>²)θ = −(<i>g</i>/2<i>R</i>)θ</div>

这是简谐运动，ω = √(<i>g</i>/2<i>R</i>)，且与质量无关：

<div class="eq"><i>T</i> = 2π√(2<i>R</i>/<i>g</i>) = 2π√(0.80/9.80) = 1.80 s</div>

这与简单摆相同，只要简单摆的摆长等于圆环的宽度（0.80 m）。

## 第 11 页

### 题目 1

绕线上的圆盘质量为 2.0 kg，周期为 3.77 s。将它替换成质量相同但半径加倍的圆盘。新周期是多少？

**选项**

1. 3.77 s
2. 5.33 s
3. 7.54 s
4. 15.1 s

**正确答案：** 3. 7.54 s

**解析：** <i>I</i> = ½<i>MR</i>²；半径加倍时转动惯量变为 4 倍，而 <i>T</i> = 2π√(<i>I</i>/κ) 增长 √4 = 2 倍：7.54 s。导线相同，κ 相同。

### 题目 2（开放作答）

圆盘（<i>I</i> = 0.090 kg·m²，κ = 0.25 N·m/rad）被扭转 60° 后从静止释放。写出 θ(<i>t</i>)，并求最大力矩和最大角速度。

**参考解答：**

<i>I</i> d²θ/d<i>t</i>² = −κθ，因此 θ = θ<sub>0</sub> cos(ω<i>t</i>)，其中 ω = √(κ/<i>I</i>) = √(0.25/0.090) = 1.667 rad/s，且 θ<sub>0</sub> = 60° = 1.047 rad（从静止释放，因此 φ = 0）。这里不需要小角近似：τ = −κθ 在任意扭转角下都成立。

<div class="eq">|τ|<sub>max</sub> = κθ<sub>0</sub> = 0.25 × 1.047 = 0.262 N·m &nbsp;（在两端处）</div>

<div class="eq">|dθ/d<i>t</i>|<sub>max</sub> = θ<sub>0</sub>ω = 1.047 × 1.667 = 1.75 rad/s &nbsp;（通过 θ = 0 时）</div>

θ 必须用弧度表示：力矩定律和 ω 的表达式都以此为前提。

## 第 12 页

### 题目 1

质量为 1200 kg 的汽车在弹簧上以 0.889 s 的周期颠簸（减震器关闭）。总质量为 300 kg 的乘客上车后，新周期是多少？

**选项**

1. 0.889 s
2. 1.111 s
3. 0.795 s
4. 0.993 s

**正确答案：** 4. 0.993 s

**解析：**

<div class="eq"><i>T</i> = 2π√(<i>m</i>/<i>k</i>) = 2π√(1500/60000) = 0.993 s</div>

汽车更重，颠簸更慢，周期增加的倍数是 √(1500/1200) = 1.118，而不是质量比本身。

### 题目 2

要让一个坐在长 2.4 m 秋千上的孩子每摆动一次接受一次推动（每个完整周期一次），两次推动之间应等待多久？

**选项**

1. 1.55 s
2. 3.11 s
3. 12.7 s
4. 0.495 s

**正确答案：** 2. 3.11 s

**解析：**

<div class="eq"><i>T</i> = 2π√(<i>L</i>/<i>g</i>) = 2π√(2.4/9.80) = 3.11 s</div>

孩子每经过一个完整周期就会回到你的手边。半个周期 1.55 s 时，孩子位于远端。孩子的质量和（小）振幅都无关紧要。
