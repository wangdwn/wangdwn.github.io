# 练习：高斯定律

> 本文件是 Atlas of Physics《高斯定律》练习模块的完整简体中文译本。公式、符号、数值、单位和变量均以实际运行数据为准。

## 第 1 页

### 1.1

**题目**

页面中的 20 cm 正方形位于均匀的 2.0 kN/C 电场中，其面积矢量与 <b>E</b> 的夹角为 60°。穿过它的电通量为

**选项**

1. 69.3 N·m²/C
2. 40.0 N·m²/C
3. 80.0 N·m²/C
4. 200.0 N·m²/C

**正确答案：** 2. 40.0 N·m²/C

**解析**

<div class="eq">Φ = <i>EA</i> cos θ = 2000 × 0.040 m² × cos 60° = 40.0 N·m²/C</div>

θ 是从<b>面积矢量</b>（即法线）量起的，因此应使用 cos，而不是 sin；只有当 θ 是相对于表面的夹角时，使用 sin 才是正确的。

### 1.2

**题目**

一个电场 <b>E</b> = <i>by</i> <b>x̂</b>，其中 <i>b</i> = 3.0 × 10<sup>4</sup> N/C 每米，穿过 <i>yz</i> 平面内的一个 20 cm 正方形，且 0 ≤ <i>y</i> ≤ 0.20 m。穿过该正方形（法向为 +<b>x̂</b>）的电通量为

**选项**

1. 240 N·m²/C
2. 80.0 N·m²/C
3. 600 N·m²/C
4. 120 N·m²/C

**正确答案：** 4. 120 N·m²/C

**解析**

<p><i>E</i> 在正方形上各处不同，因此把它切成宽度为 d<i>y</i>、长度为 <i>s</i> 的条带；每条带的电通量为 <i>E</i>(<i>y</i>) <i>s</i> d<i>y</i>：</p>

<div class="eq">Φ = ∫<sub>0</sub><sup><i>s</i></sup> <i>by</i> · <i>s</i> d<i>y</i> = <i>bs</i>³/2 = 120 N·m²/C</div>

<p>如果用远端边缘处的电场代表整个正方形，得到的结果会是它的两倍，即 240。</p>

## 第 2 页

### 2.1

**题目**

页面中的 1.0 nC 点电荷位于一个立方体的中心。穿过立方体<b>一个</b>面的电通量为

**选项**

1. 18.8 N·m²/C
2. 113.0 N·m²/C
3. 9.0 N·m²/C
4. 56.5 N·m²/C

**正确答案：** 1. 18.8 N·m²/C

**解析**

高斯定律表明，整个立方体的电通量为 <i>q</i>/ε<sub>0</sub> = 113 N·m²/C。根据对称性，六个面均分电通量：

<div class="eq">Φ<sub>face</sub> = <i>q</i>/6ε<sub>0</sub> = 18.8 N·m²/C</div>

<p><i>kq</i> = 8.99 的单位同样是 N·m²/C，但它是 <i>q</i>/4πε<sub>0</sub>，并不是穿过任何物体的电通量。</p>

### 2.2

**题目**

在某个区域内，电场沿径向，且 <i>E</i> = <i>cr</i>，其中 <i>c</i> = 5.0 × 10<sup>4</sup> N/C 每米。以原点为中心、半径为 10 cm 的球内包含多少电荷？

**选项**

1. 0.443 nC
2. 55.6 nC
3. 1.85 nC
4. 5.56 nC

**正确答案：** 4. 5.56 nC

**解析**

在球面上 <b>E</b> ∥ d<b>A</b>，且处处有 <i>E</i> = <i>cR</i>，所以

<div class="eq">∮<b>E</b> · d<b>A</b> = <i>cR</i> · 4π<i>R</i>² = <i>q</i><sub>enc</sub>/ε<sub>0</sub> &nbsp;→&nbsp; <i>q</i><sub>enc</sub> = 4πε<sub>0</sub><i>cR</i>³ = 5.56 nC</div>

<p>这里使用的是表面积 4π<i>R</i>²，而不是体积 ⁴⁄₃π<i>R</i>³：电通量是面积积分。</p>

## 第 3 页

### 3.1

**题目**

页面中的无限长直线带有线电荷密度 λ = 2.0 nC/m。距它 5 cm 处的电场为

**选项**

1. 360 N/C
2. 719 N/C
3. 14387 N/C
4. 2260 N/C

**正确答案：** 2. 719 N/C

**解析**

<p>取一段与直线同轴的圆柱面；两个端盖没有电通量，因此 <i>E</i> · 2π<i>rL</i> = λ<i>L</i>/ε<sub>0</sub>，所以</p>

<div class="eq"><i>E</i> = λ/2πε<sub>0</sub><i>r</i> = 2<i>k</i>λ/<i>r</i> = 719 N/C</div>

<p>直线电荷的电场按 1/<i>r</i> 衰减，而不是按 1/<i>r</i>² 衰减（14387 N/C）。</p>

### 3.2

**题目**

距这条直线 5 cm 处的电势比距它 20 cm 处高多少？

**选项**

1. 539.5 V
2. 107.9 V
3. 49.9 V
4. 27.0 V

**正确答案：** 3. 49.9 V

**解析**

<div class="eq"><i>V</i>(<i>r</i><sub>1</sub>) − <i>V</i>(<i>r</i><sub>2</sub>) = ∫<sub><i>r</i><sub>1</sub></sub><sup><i>r</i><sub>2</sub></sup> (2<i>k</i>λ/<i>r</i>) d<i>r</i> = 2<i>k</i>λ ln(<i>r</i><sub>2</sub>/<i>r</i><sub>1</sub>) = 35.97 × ln 4 = 49.9 V</div>

<p>1/<i>r</i> 的积分结果是对数。把点电荷公式 1/<i>r</i><sub>1</sub> − 1/<i>r</i><sub>2</sub> 套用过来会得到 539.5 V；用近处电场乘以距离得到 107.9 V，则忽略了电场会随距离减小这一事实。</p>

## 第 4 页

### 3.1

**题目**

两张很大的平行非导体薄板分别带有 +σ 和 −σ 电荷，其中 σ = 4.0 nC/m²。电场为

**选项**

1. 两板之间为 452 N/C，板外为 0
2. 两板之间及板外均为 226 N/C
3. 两板之间为 0，板外为 452 N/C
4. 两板之间为 904 N/C，板外为 0

**正确答案：** 1. 两板之间为 452 N/C，板外为 0

**解析**

每张薄板单独产生的电场在两侧均为 σ/2ε<sub>0</sub> = 226 N/C；电场方向背离正电荷、指向负电荷。在两板之间，两电场方向相同并相加；在板外，两电场方向相反并相互抵消：

<div class="eq"><i>E</i> = σ/2ε<sub>0</sub> + σ/2ε<sub>0</sub> = σ/ε<sub>0</sub> = 452 N/C（两板之间）</div>

### 3.2

**题目**

一块厚的非导体板充满 −<i>d</i> ≤ <i>x</i> ≤ <i>d</i>（<i>d</i> = 5 cm），其电荷密度为 ρ = ρ<sub>0</sub>|<i>x</i>|/<i>d</i>，其中 ρ<sub>0</sub> = 4.0 × 10<sup>−7</sup> C/m³。在 <i>x</i> = 2 cm 处的电场为

**选项**

1. 362 N/C
2. 181 N/C
3. 452 N/C
4. 90.4 N/C

**正确答案：** 2. 181 N/C

**解析**

取一个端面面积为 <i>A</i>、从 −<i>x</i> 延伸到 <i>x</i> 的药丸盒。根据对称性，电场从<b>两个</b>端面流出：

<div class="eq">2<i>EA</i> = (1/ε<sub>0</sub>) · 2<i>A</i>∫<sub>0</sub><sup><i>x</i></sup> ρ<sub>0</sub><i>x</i>′/<i>d</i> d<i>x</i>′ = <i>A</i>ρ<sub>0</sub><i>x</i>²/ε<sub>0</sub><i>d</i> &nbsp;→&nbsp; <i>E</i> = ρ<sub>0</sub><i>x</i>²/2ε<sub>0</sub><i>d</i> = 181 N/C</div>

<p>只计算一个端面会使结果加倍，得到 362 N/C。</p>

## 第 5 页

### 4.1

**题目**

一个带电量为 +<i>Q</i> 的金属球位于一个厚的同心金属壳中心；金属壳的净电荷为 −3<i>Q</i>。金属壳<b>外</b>表面的电荷为

**选项**

1. −3<i>Q</i>
2. −<i>Q</i>
3. +<i>Q</i>
4. −2<i>Q</i>

**正确答案：** 4. −2<i>Q</i>

**解析**

位于金属壳内部金属中的高斯面上 <i>E</i> = 0，因此它包围的总电荷为零：内表面必须带有 −<i>Q</i>，以抵消金属球的 +<i>Q</i>。金属壳剩余的 −3<i>Q</i> 电荷全部位于外表面：−3<i>Q</i> − (−<i>Q</i>) = −2<i>Q</i>。

### 4.2

**题目**

页面中的金属球外部电场储存了多少能量（<i>Q</i> = 2.0 nC，<i>R</i> = 10 cm）？（能量密度为 ε<sub>0</sub><i>E</i>²/2。）

**选项**

1. 0.360 μJ
2. 0.0899 μJ
3. 0.0599 μJ
4. 0.180 μJ

**正确答案：** 4. 0.180 μJ

**解析**

<p>金属内部 <i>E</i> = 0。在外部，将体积为 4π<i>r</i>² d<i>r</i> 的球壳相加：</p>

<div class="eq"><i>U</i> = ∫<sub><i>R</i></sub><sup>∞</sup> (ε<sub>0</sub>/2)(<i>kQ</i>/<i>r</i>²)² 4π<i>r</i>² d<i>r</i> = <i>kQ</i>²/2<i>R</i> = 0.180 μJ</div>

<p>积分只到 2<i>R</i> 时只能得到一半，即 0.0899 μJ：远处的电场仍然储存着能量。用表面能量密度乘以球的体积（0.0599 μJ）会把能量放在错误的位置：金属内部没有电场，因此那里没有能量。</p>

## 第 6 页

### 5.1

**题目**

页面中的绝缘球（<i>Q</i> = 2.0 nC，电荷均匀分布，<i>R</i> = 10 cm）。距其中心 5 cm 处的电场为

**选项**

1. 7193 N/C
2. 899 N/C
3. 0 N/C
4. 2698 N/C

**正确答案：** 2. 899 N/C

**解析**

半径为 <i>r</i> 的高斯球包含的电荷为 <i>Q</i>(<i>r</i>/<i>R</i>)³ = <i>Q</i>/8：

<div class="eq"><i>E</i> · 4π<i>r</i>² = <i>Q</i>(<i>r</i>/<i>R</i>)³/ε<sub>0</sub> &nbsp;→&nbsp; <i>E</i> = <i>kQr</i>/<i>R</i>³ = 899 N/C</div>

<p>电场为零对应的是<b>金属</b>球；<i>kQ</i>/<i>r</i>² 计算的是位于高斯球外部的电荷，因此不适用。</p>

### 5.2

**题目**

一个绝缘球壳的内半径为 <i>a</i>、外半径为 <i>b</i>，电荷密度为均匀的 ρ。求三个区域内的 <i>E</i>(<i>r</i>)。

**参考答案**

<p>球对称性：在半径为 <i>r</i> 的高斯球面上，<i>E</i> · 4π<i>r</i>² = <i>q</i><sub>enc</sub>/ε<sub>0</sub>，其中 <i>q</i><sub>enc</sub> = ∫ ρ 4π<i>r</i>′² d<i>r</i>′，积分范围是内部带电部分。</p>

<div class="eq"><i>r</i> &lt; <i>a</i>：&nbsp;<i>q</i><sub>enc</sub> = 0，&nbsp;<i>E</i> = 0</div>

<div class="eq"><i>a</i> &lt; <i>r</i> &lt; <i>b</i>：&nbsp;<i>q</i><sub>enc</sub> = ∫<sub><i>a</i></sub><sup><i>r</i></sup> ρ4π<i>r</i>′² d<i>r</i>′ = ⁴⁄₃πρ(<i>r</i>³ − <i>a</i>³)，&nbsp;<i>E</i> = ρ(<i>r</i>³ − <i>a</i>³)/3ε<sub>0</sub><i>r</i>²</div>

<div class="eq"><i>r</i> &gt; <i>b</i>：&nbsp;<i>E</i> = ρ(<i>b</i>³ − <i>a</i>³)/3ε<sub>0</sub><i>r</i>² = <i>kQ</i>/<i>r</i>²</div>

<p>检查：在 <i>r</i> = <i>a</i> 处，中间形式为 0；在 <i>r</i> = <i>b</i> 处，中间形式与外部形式相接，因此 <i>E</i> 是连续的。当 <i>a</i> = 0 时，它变为实心球的 ρ<i>r</i>/3ε<sub>0</sub>。</p>

## 第 7 页

### 6.1

**题目**

页面中的绝缘圆柱（λ = 2.0 nC/m，电荷均匀分布，<i>R</i> = 5 cm）。距其轴线 2.5 cm 处的电场为

**选项**

1. 0 N/C
2. 1439 N/C
3. 360 N/C
4. 1130 N/C

**正确答案：** 3. 360 N/C

**解析**

<p>半径为 <i>r</i>、长度为 <i>L</i> 的同轴圆柱包含 λ<i>L</i>(<i>r</i>/<i>R</i>)² 的电荷：</p>

<div class="eq"><i>E</i> · 2π<i>rL</i> = λ<i>L</i><i>r</i>²/<i>R</i>²ε<sub>0</sub> &nbsp;→&nbsp; <i>E</i> = 2<i>k</i>λ<i>r</i>/<i>R</i>² = 360 N/C</div>

<p>2<i>k</i>λ/<i>r</i>（1439 N/C）只在外部成立，因为在那里高斯面包围了全部 λ；0 对应的是金属圆柱。</p>

### 6.2

**题目**

一个半径为 <i>R</i> 的长绝缘圆柱具有 ρ = ρ<sub>0</sub><i>r</i>/<i>R</i>。在其内部（<i>r</i> &lt; <i>R</i>），电场为

**选项**

1. ρ<sub>0</sub><i>r</i>/2ε<sub>0</sub>
2. ρ<sub>0</sub><i>r</i>²/3ε<sub>0</sub><i>R</i>
3. ρ<sub>0</sub><i>r</i>²/2ε<sub>0</sub><i>R</i>
4. ρ<sub>0</sub><i>r</i>³/3ε<sub>0</sub><i>R</i>²

**正确答案：** 2. ρ<sub>0</sub><i>r</i>²/3ε<sub>0</sub><i>R</i>

**解析**

将电荷分解为薄的圆柱壳，每个圆柱壳的体积为 2π<i>r</i>′<i>L</i> d<i>r</i>′：

<div class="eq"><i>q</i><sub>enc</sub> = ∫<sub>0</sub><sup><i>r</i></sup> (ρ<sub>0</sub><i>r</i>′/<i>R</i>) 2π<i>r</i>′<i>L</i> d<i>r</i>′ = 2πρ<sub>0</sub><i>Lr</i>³/3<i>R</i></div>

<div class="eq"><i>E</i> · 2π<i>rL</i> = <i>q</i><sub>enc</sub>/ε<sub>0</sub> &nbsp;→&nbsp; <i>E</i> = ρ<sub>0</sub><i>r</i>²/3ε<sub>0</sub><i>R</i></div>

<p>ρ<sub>0</sub><i>r</i>²/2ε<sub>0</sub><i>R</i> 是把局部的 ρ(<i>r</i>) 代入均匀圆柱的结果，而没有进行积分。</p>

## 第 8 页

### 7.1

**题目**

页面中的球具有 ρ = <i>br</i>（<i>Q</i> = 2.0 nC，<i>R</i> = 10 cm，<i>b</i> = 6.37 μC/m⁴）。距球心 5 cm 处的电场为

**选项**

1. 599 N/C
2. 899 N/C
3. 450 N/C
4. 1798 N/C

**正确答案：** 3. 450 N/C

**解析**

<div class="eq"><i>q</i><sub>enc</sub> = ∫<sub>0</sub><sup><i>r</i></sup> <i>br</i>′ 4π<i>r</i>′² d<i>r</i>′ = π<i>br</i>⁴，&nbsp;<i>E</i> = π<i>br</i>⁴/(4πε<sub>0</sub><i>r</i>²) = <i>br</i>²/4ε<sub>0</sub> = 450 N/C</div>

<p>由于电荷向外部聚集，只有 <i>Q</i>/16 位于 <i>R</i>/2 以内。具有相同 <i>Q</i> 的均匀球给出 899 N/C；把 ρ(<i>r</i>) 代入 ρ<i>r</i>/3ε<sub>0</sub> 则给出 599 N/C。</p>

### 7.2

**题目**

一个半径为 <i>R</i> 的球具有 ρ = <i>br</i>²。其总电荷中有多少比例位于 <i>r</i> = <i>R</i>/2 以内？

**选项**

1. 1/8
2. 1/32
3. 1/16
4. 1/4

**正确答案：** 2. 1/32

**解析**

<div class="eq"><i>q</i>(<i>r</i>) = ∫<sub>0</sub><sup><i>r</i></sup> <i>br</i>′² 4π<i>r</i>′² d<i>r</i>′ = ⁴⁄₅π<i>br</i>⁵ &nbsp;→&nbsp; <i>q</i>(<i>R</i>/2)/<i>q</i>(<i>R</i>) = (½)⁵ = 1/32</div>

<p>1/8 是均匀球的 (½)³；1/16 是 ρ = <i>br</i> 时的 (½)⁴。</p>

## 第 9 页

### 8.1

**题目**

一个点电荷 +<i>q</i> 偏离中心，位于一个中性、厚的球形金属壳的空腔内。在金属壳外部，电场为

**选项**

1. 0
2. <i>kq</i>/<i>r</i>²，其中 <i>r</i> 从点电荷量起
3. <i>kq</i>/<i>r</i>²，其中 <i>r</i> 从金属壳中心量起
4. 靠近点电荷的一侧更强

**正确答案：** 3. <i>kq</i>/<i>r</i>²，其中 <i>r</i> 从金属壳中心量起

**解析**

<p>−<i>q</i> 聚集在内表面上，而且分布不均匀，从而使金属内部的电场为零。这会屏蔽点电荷所在位置对外部的影响。外表面上剩余的 +<i>q</i> 不受内部电荷产生的电场影响，因此会像孤立球上的电荷一样均匀分布。在外部，以同心球为高斯面，由高斯定律得到电场为 <i>kq</i>/<i>r</i>²，其中 <i>r</i> 从<b>金属壳的中心</b>量起。</p>

### 8.2

**题目**

页面中的不带电球壳（<i>R</i> = 14 cm）处于 1.0 kN/C 的电场中，且 σ = 3ε<sub>0</sub><i>E</i><sub>0</sub> cos θ。下游半部（cos θ &gt; 0）上的总电荷为

**选项**

1. 0 nC
2. 1.63 nC
3. 3.27 nC
4. 0.545 nC

**正确答案：** 2. 1.63 nC

**解析**

<p>宽度为 <i>R</i> dθ 的环带面积为 2π<i>R</i>² sin θ dθ：</p>

<div class="eq"><i>q</i> = ∫<sub>0</sub><sup>π/2</sup> 3ε<sub>0</sub><i>E</i><sub>0</sub> cos θ · 2π<i>R</i>² sin θ dθ = 3πε<sub>0</sub><i>E</i><sub>0</sub><i>R</i>² = 1.63 nC</div>

<p>另一半带有 −1.63 nC，因此球壳保持电中性；用 σ<sub>max</sub> 乘以下游半部面积（3.27 nC）会忽略 σ 在边缘处降为 0。</p>
