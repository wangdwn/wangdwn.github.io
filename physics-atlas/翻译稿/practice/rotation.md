# 练习：转动

> 本页为 Atlas of Physics《转动》练习模块的简体中文译本。题目、选项、解析和数值均依据运行时导出的 PRACTICE 数据翻译。

## 练习 0：角运动学

### 题目 0.1
轮子从静止开始，以 1.5 rad/s² 的角加速度加速 2.4 s。在这段时间内它转过多少圈？

**选项**
1. 1.38 rev
2. 4.32 rev
3. 0.688 rev
4. 27.1 rev

**正确答案：** 3. 0.688 rev

**解析：**
从静止开始做恒定角加速度运动：Δθ = ½αt²，结果单位为弧度。然后除以每转一圈对应的 2π rad。

<div class="eq">Δθ = ½ × 1.5 × 2.4² = 4.32 rad = 4.32 / 2π = 0.688 rev</div>

4.32 rev 忘记了 ½αt² 得到的是弧度；1.38 rev 则漏掉了 ½。

### 题目 0.2
规定逆时针为正。轮子在刹车时逆时针转动。ω 和 α 的符号是：

**选项**
1. ω > 0，α > 0
2. ω < 0，α < 0
3. ω < 0，α > 0
4. ω > 0，α < 0

**正确答案：** 4. ω > 0，α < 0

**解析：**
轮子逆时针转动，所以 ω > 0。它正在减速，所以 α 与 ω 方向相反：α < 0。ω 的符号表示转动方向；α 只表示 ω 正在向哪个方向变化。

## 练习 1：圆周运动中的加速度

### 题目 1.1
旋转木马以恒定的 ω 转动。位于 1.2 m 处的乘客，其向心加速度是位于 0.6 m 处乘客的多少倍？

**选项**
1. 1（ω 相同，加速度相同）
2. 4
3. 2
4. ½

**正确答案：** 3. 2

**解析：**
两人共享同一个 ω，且 <i>a</i><sub>c</sub> = <i>v</i>²/<i>r</i> = <i>r</i>ω²。在 ω 固定时，它与 <i>r</i> 成正比：半径加倍，加速度也加倍。

4 来自 <i>v</i>²/<i>r</i> 中速度加倍，却忘记了分母中的 <i>r</i>。

### 题目 1.2
乘坐设施从静止开始，以 α = 0.8 rad/s² 加速。当 <i>t</i> = 1.6 s 时，位于 1.2 m 处乘客的总加速度大小是多少？

**选项**
1. 0.960 m/s²
2. 1.97 m/s²
3. 2.19 m/s²
4. 2.93 m/s²

**正确答案：** 3. 2.19 m/s²

**解析：**
ω = αt = 1.28 rad/s。有两个相互垂直的分量：

<div class="eq"><i>a</i><sub>t</sub> = rα = 0.96 m/s²，<i>a</i><sub>c</sub> = rω² = 1.97 m/s²</div>
<div class="eq"><i>a</i> = √(0.96² + 1.97²) = 2.19 m/s²</div>

它们互相垂直，因此要像向量一样相加，而不是直接把数值相加（2.93）。

## 练习 2：转矩

### 题目 2.1
10 N 的推力作用在把手上。把手距铰链 0.85 m，推力与门成 30° 角。它绕铰链产生的转矩是多少？

**选项**
1. 8.50 N·m
2. 4.25 N·m
3. 7.36 N·m
4. 0 N·m

**正确答案：** 2. 4.25 N·m

**解析：**
φ 是 <b>r</b>（沿门的方向）与 <b>F</b> 之间的夹角，这里为 30°。

<div class="eq">τ = rF sin φ = 0.85 × 10 × sin 30° = 4.25 N·m</div>

7.36 N·m 使用了 cos：这表示 <b>F</b> 沿门方向的分量，它会把力推向铰链。

### 题目 2.2
门（12 kg，宽 0.9 m，I = ⅓MW²）在把手处受到正向推力，τ = 8.5 N·m。它的角加速度是：

**选项**
1. 0.874 rad/s²
2. 1.75 rad/s²
3. 10.5 rad/s²
4. 2.62 rad/s²

**正确答案：** 4. 2.62 rad/s²

**解析：**
<div class="eq">I = ⅓MW² = ⅓ × 12 × 0.9² = 3.24 kg·m²</div>
<div class="eq">α = τ/I = 8.5 / 3.24 = 2.62 rad/s²</div>

门绕边缘而不是绕中部转动，因此 <sup>1</sup>⁄<sub>12</sub>MW²（绕中心）会得到大得多的 α。

## 练习 3：静力平衡

### 题目 3.1
30 kg 的箱子放在一根长 4.0 m、质量 20 kg 的木板上，距支点 A 1.0 m。支点 B 施加的力是多少？

**选项**
1. 319 N
2. 245 N
3. 73.5 N
4. 172 N

**正确答案：** 4. 172 N

**解析：**
取 A 点的转矩；<i>F</i><sub>A</sub> 的力臂为零：

<div class="eq">4.0·<i>F</i><sub>B</sub> = 2.0 × 196 + 1.0 × 294 → <i>F</i><sub>B</sub> = 172 N</div>

箱子更靠近 A，所以 A 承担的力更大（319 N），B 承担的力更小。73.5 N 忘记了木板自身的重量。

### 题目 3.2
箱子从 A 缓慢滑向 B。支点的支持力会发生什么变化？

**选项**
1. <i>F</i><sub>A</sub> 减小，<i>F</i><sub>B</sub> 增大，两者之和保持不变
2. <i>F</i><sub>A</sub> 增大，<i>F</i><sub>B</sub> 减小
3. 两者都不变：总重量没有改变
4. <i>F</i><sub>A</sub> 减小，<i>F</i><sub>B</sub> 增大，两者之和也增大

**正确答案：** 1. <i>F</i><sub>A</sub> 减小，<i>F</i><sub>B</sub> 增大，两者之和保持不变

**解析：**
Σ<i>F</i> = 0 将两力之和固定为 (M + m)g。对 A 取转矩，Στ = 0，得到 <i>F</i><sub>B</sub> = [(L/2)Mg + x·mg]/L；它随 x 增大。因此 <i>F</i><sub>B</sub> 增大，<i>F</i><sub>A</sub> 则减少相同的量。

## 练习 4：梯子与摩擦

### 题目 4.1
质量 20 kg 的梯子与地面成 60° 角，靠在光滑墙上。地面必须提供多大的摩擦力？

**选项**
1. 113 N
2. 56.6 N
3. 78.4 N
4. 170 N

**正确答案：** 2. 56.6 N

**解析：**
取梯脚处的转矩：(L sin θ)<i>F</i><sub>w</sub> = (½L cos θ)mg，所以 <i>F</i><sub>w</sub> = mg / (2 tan θ)。ΣF<sub>x</sub> = 0，因此摩擦力等于 <i>F</i><sub>w</sub>：

<div class="eq"><i>f</i> = 196 / (2 tan 60°) = 56.6 N</div>

78.4 N 是静摩擦力能够提供的<b>最大值</b>，而不是实际提供的力。

### 题目 4.2
如果把梯子换成质量两倍、长度相同、放在同一地面上的梯子，它能够保持直立的最小角度是：

**选项**
1. 更大
2. 更小
3. 相同
4. 只有在它也更长时才更大

**正确答案：** 3. 相同

**解析：**
所需摩擦力 mg/(2 tan θ) 和可提供的摩擦力 μ<sub>s</sub>mg 都与 m 成正比。令二者相等，得到 tan θ<sub>min</sub> = 1/(2μ<sub>s</sub>)：其中没有 m，也没有 L。

## 练习 5：转动惯量

### 题目 5.1
一个圆环、一个圆盘和一个实心球具有相同的质量和半径，并受到相同的转矩。按角加速度从大到小排序。

**选项**
1. 圆环、圆盘、球
2. 球、圆盘、圆环
3. 圆盘、球、圆环
4. 全部相等

**正确答案：** 2. 球、圆盘、圆环

**解析：**
α = τ/I，其中 I 分别为圆环的 MR²、圆盘的 ½MR²、球的 ⅖MR²。球的质量离转轴最近，I 最小，因此 α 最大。

### 题目 5.2
圆盘（2.0 kg，0.4 m）从静止开始，绳子绕在边缘上，受到 1.0 N 的拉力。2.0 s 后它的 ω 是：

**选项**
1. 12.5 rad/s
2. 2.50 rad/s
3. 6.25 rad/s
4. 5.00 rad/s

**正确答案：** 4. 5.00 rad/s

**解析：**
<div class="eq">τ = FR = 0.40 N·m，I = ½MR² = 0.16 kg·m²</div>
<div class="eq">α = τ/I = 2.50 rad/s²，ω = αt = 5.00 rad/s</div>

12.5 rad/s 把力当成了转矩。

## 练习 6：连续质量分布

### 题目 6.1
一根质量 1.5 kg、长度 1.2 m 的杆，越靠近一端密度越大：λ = Cx，其中 x 从较轻的一端 O 起算。它绕 O 点的垂直轴的转动惯量是：

**选项**
1. 0.720 kg·m²
2. 1.08 kg·m²
3. 0.540 kg·m²
4. 2.16 kg·m²

**正确答案：** 2. 1.08 kg·m²

**解析：**
先由质量确定 C，再用 dm = Cx dx 对 r² dm 积分：

<div class="eq">M = ∫<sub>0</sub><sup>L</sup> Cx dx = ½CL² → C = 2M/L²</div>
<div class="eq">I = ∫<sub>0</sub><sup>L</sup> x²·Cx dx = ¼CL⁴ = ½ML² = 1.08 kg·m²</div>

它大于均匀杆的 ⅓ML²（0.720）：因为质量分布得更靠外。¼ML² 的错误在于没有将 C 替换为 2M/L²。

### 题目 6.2
一块质量为 M 的平垫圈（环形圆盘）内半径为 R/2、外半径为 R。利用 I = ∫r² dm，证明它绕中心的转动惯量 I = ⅝MR²，并在 M = 2.0 kg、R = 0.4 m 时求其数值。

**解答：**
单位面积质量 σ = M / [π(R² − R²/4)] = 4M / (3πR²)。半径为 r、宽度为 dr 的圆环，其 dm = σ·2πr dr。

<div class="eq">I = ∫<sub>R/2</sub><sup>R</sup> r²·σ2πr dr = 2πσ [r⁴/4]<sub>R/2</sub><sup>R</sup> = 2πσ · (15/64)R⁴</div>
<div class="eq">I = 2π · 4M/(3πR²) · 15R⁴/64 = (120/192)MR² = ⅝MR²</div>
<div class="eq">I = ⅝ × 2.0 × 0.4² = 0.200 kg·m²</div>

结果应当介于圆盘（½MR²）和圆环（MR²）之间：孔洞把质量移到了更外侧。

## 练习 7：平行轴定理

### 题目 7.1
质量 1.5 kg、长度 1.2 m 的杆（I<sub>cm</sub> = 0.18 kg·m²）绕一条垂直轴转动，该轴距一端 0.30 m。它的转动惯量是：

**选项**
1. 0.630 kg·m²
2. 0.135 kg·m²
3. 0.855 kg·m²
4. 0.315 kg·m²

**正确答案：** 4. 0.315 kg·m²

**解析：**
该定理从质心轴出发，所以 d 要从质心量起：d = 0.60 − 0.30 = 0.30 m。

<div class="eq">I = I<sub>cm</sub> + Md² = 0.18 + 1.5 × 0.30² = 0.315 kg·m²</div>

0.855 把 Md² 加到了端点转动惯量上，但杆端并不是质心。

### 题目 7.2
一根杆在一端用铰链固定，从水平静止状态释放。利用平行轴定理求 I，写出 Στ = Iα 关于杆相对水平线向下的角度 θ 的微分方程，并积分求出它摆过最低点时的 ω。

**解答：**
<div class="eq">I = <sup>1</sup>⁄<sub>12</sub>ML² + M(L/2)² = ⅓ML²</div>

重力作用在质心处，质心距铰链 L/2，力臂为 (L/2)cos θ：

<div class="eq">⅓ML² · d²θ/dt² = Mg(L/2) cos θ</div>
<div class="eq">d²θ/dt² = (3g / 2L) cos θ</div>

写成 d²θ/dt² = ω dω/dθ，并从 θ = 0、ω = 0 积分：

<div class="eq">∫<sub>0</sub><sup>ω</sup> ω dω = (3g/2L) ∫<sub>0</sub><sup>θ</sup> cos θ dθ → ω² = (3g/L) sin θ</div>
<div class="eq">在最低点，θ = 90°：ω = √(3g/L) = √(3 × 9.80 / 1.2) = 4.95 rad/s</div>

用能量也可以检查：质心下降 L/2，因此 Mg(L/2) = ½(⅓ML²)ω²，得到相同结果。α 不是常量，所以不能使用 ω² = 2αΔθ。

## 练习 8：转动功

### 题目 8.1
50 N 的推力垂直作用在半径 0.40 m 的扳手上，使螺母转过一次 120° 的行程。所做的功是：

**选项**
1. 20.0 J
2. 105 J
3. 41.9 J
4. 2400 J

**正确答案：** 3. 41.9 J

**解析：**
<div class="eq">W = τΔθ = (0.40 × 50) × 2π/3 = 20 × 2.094 = 41.9 J</div>

Δθ 必须使用弧度。2400 J 把角度按 120° 直接相乘了。

### 题目 8.2
同一个螺母需要相同的转矩。若扳手长度加倍，所需推力和每次 120° 行程所做的功分别是：

**选项**
1. 推力减半，功减半
2. 推力减半，功相同
3. 推力相同，功加倍
4. 推力减半，功加倍

**正确答案：** 2. 推力减半，功相同

**解析：**
τ = rF：r 加倍，F 减半。W = τΔθ：τ 相同、角度相同，所以功相同。手在移动两倍距离，但使用了一半的力。

## 练习 9：滚动

### 题目 9.1
圆盘（I = ½mR²）从静止开始，在长 3.0 m、倾角 25° 的斜坡上无滑动地滚下。它在坡底的速度是：

**选项**
1. 4.98 m/s
2. 4.21 m/s
3. 3.52 m/s
4. 4.07 m/s

**正确答案：** 4. 4.07 m/s

**解析：**
h = 3.0 sin 25° = 1.268 m。又因为 ω = v/R：

<div class="eq">mgh = ½mv² + ½(½mR²)(v/R)² = ¾mv² → v = √(4gh/3) = 4.07 m/s</div>

4.98 m/s 是滑动箱子的速度，它没有把能量花在自转上。

### 题目 9.2
一个实心球（⅖MR²）、一个空心球（⅔MR²）和一个圆环（MR²）从静止开始沿同一斜坡滚下。它们到达坡底的顺序是什么？

**选项**
1. 圆环、空心球、实心球
2. 同时到达
3. 实心球、空心球、圆环
4. 空心球、实心球、圆环

**正确答案：** 3. 实心球、空心球、圆环

**解析：**
a = g sin θ / (1 + f)，其中 I = fMR²。f 最小意味着花在自转上的能量最少、速度最快：先是实心球（0.4），然后是空心球（0.67），最后是圆环（1）。质量和半径会约掉。

## 练习 10：滑动到滚动

### 题目 10.1
保龄球以 2.4 m/s 的速度离手，且没有自转；它滑动直到开始滚动。当它开始滚动时，速度是多少？

**选项**
1. 2.40 m/s
2. 1.71 m/s
3. 2.03 m/s
4. 0.686 m/s

**正确答案：** 2. 1.71 m/s

**解析：**
接触线处的摩擦力没有转矩，因此 mvR + Iω 保持为 mv<sub>0</sub>R。开始滚动时 ω = v/R：

<div class="eq">mv<sub>0</sub>R = mvR + ⅖mR²(v/R) → v = ⁵⁄₇v<sub>0</sub> = 1.71 m/s</div>

2.03 m/s 假设动能守恒，但动摩擦使球滑动时的一部分能量转化为热。

### 题目 10.2
写出球滑动期间的 v(t) 和 ω(t)（μ<sub>k</sub> = 0.2），求 v = Rω 时的时刻 t*，并对 v(t) 积分求球滑动的距离。

**解答：**
底部的动摩擦力 μ<sub>k</sub>mg 向后：

<div class="eq">m dv/dt = −μ<sub>k</sub>mg → v = v<sub>0</sub> − μ<sub>k</sub>g t</div>
<div class="eq">⅖mR² dω/dt = μ<sub>k</sub>mgR → ω = (5μ<sub>k</sub>g / 2R) t</div>
<div class="eq">v<sub>0</sub> − μ<sub>k</sub>g t* = ⁵⁄₂μ<sub>k</sub>g t* → t* = 2v<sub>0</sub> / 7μ<sub>k</sub>g = 0.350 s</div>
<div class="eq">x* = ∫<sub>0</sub><sup>t*</sup> (v<sub>0</sub> − μ<sub>k</sub>g t) dt = v<sub>0</sub>t* − ½μ<sub>k</sub>g t*²</div>
<div class="eq">x* = 12v<sub>0</sub>² / 49μ<sub>k</sub>g = 0.720 m</div>

上述两个结果都不依赖于 R 或 m。

## 练习 11：带轮与角动量

### 题目 11.1
2.0 kg 的桶从静止开始下落，使 8.0 kg 的鼓轮（实心圆柱）解开绳子。下落 2.0 m 后桶的速度是：

**选项**
1. 6.26 m/s
2. 2.80 m/s
3. 3.61 m/s
4. 2.56 m/s

**正确答案：** 3. 3.61 m/s

**解析：**
<div class="eq">a = mg / (m + ½M) = 19.6 / 6.0 = 3.27 m/s²</div>
<div class="eq">v = √(2ah) = √(2 × 3.27 × 2.0) = 3.61 m/s</div>

6.26 m/s 是自由落体速度，忽略了鼓轮吸收的能量；2.80 m/s 把鼓轮当成了薄环（I = MR²）。

### 题目 11.2
桶下落时，绳子的张力是：

**选项**
1. 等于桶的重力
2. 大于桶的重力
3. 小于桶的重力但大于零
4. 为零，因为桶正在下落

**正确答案：** 3. 小于桶的重力但大于零

**解析：**
桶向下加速，所以 mg − T = ma > 0，即 T < mg。但绳子必须拉动鼓轮使其转起来（rT = Iα），所以 T > 0。这里 T = 13.07 N，而 mg = 19.6 N。

## 练习 12：角动量冲量

### 题目 12.1
旋转木马（I = 108 kg·m²，R = 1.2 m）从静止开始。沿边缘切向施加 100 N 的推力，持续 0.90 s。它最终的 ω 是：

**选项**
1. 0.833 rad/s
2. 1.00 rad/s
3. 0.500 rad/s
4. 1.11 rad/s

**正确答案：** 2. 1.00 rad/s

**解析：**
<div class="eq">ΔL = τΔt = (100 × 1.2) × 0.90 = 108 kg·m²/s</div>
<div class="eq">ω = ΔL / I = 108 / 108 = 1.00 rad/s</div>

0.833 rad/s 使用了 FΔt（线冲量）而不是 τΔt；1.11 是 τ/I，即角加速度，不是 ω。

### 题目 12.2
一个轮子所受的转矩在 0.6 s 内从 0 稳定增加到 200 N·m，随后在 1.2 s 时又稳定降回 0。轮子角动量的变化量是：

**选项**
1. 200 kg·m²/s
2. 240 kg·m²/s
3. 167 kg·m²/s
4. 120 kg·m²/s

**正确答案：** 4. 120 kg·m²/s

**解析：**
ΔL 是转矩—时间图像下的面积；这里图形是三角形：

<div class="eq">ΔL = ½ × 1.2 s × 200 N·m = 120 kg·m²/s</div>

240 把它当成了矩形面积；167 是斜率而不是面积。

## 练习 13：角动量守恒

### 题目 13.1
滑冰者（I<sub>身体</sub> = 1.0 kg·m²）以 1.5 rad/s 转动，双手各握一个 2.0 kg 的重物，重物距转轴 0.80 m；她将重物收至 0.18 m。她新的 ω 是：

**选项**
1. 6.67 rad/s
2. 29.6 rad/s
3. 4.73 rad/s
4. 1.50 rad/s

**正确答案：** 3. 4.73 rad/s

**解析：**
<div class="eq">I<sub>0</sub> = 1.0 + 2 × 2.0 × 0.80² = 3.56 kg·m²，I<sub>f</sub> = 1.0 + 2 × 2.0 × 0.18² = 1.130 kg·m²</div>
<div class="eq">ω<sub>f</sub> = I<sub>0</sub>ω<sub>0</sub> / I<sub>f</sub> = 4.73 rad/s</div>

29.6 rad/s 漏掉了她自身不变的 1.0 kg·m²。

### 题目 13.2
当她把重物收进来时，她的转动动能：

**选项**
1. 保持不变，因为 L 守恒
2. 减小，因为 I 减小
3. 增大，因为冰面施加了转矩
4. 增大，因为她的手臂对重物做了功

**正确答案：** 4. 增大，因为她的手臂对重物做了功

**解析：**
<p>K = L²/2I。L 固定而 I 减小，所以 K 增大：这里从 4.01 J 增加到 12.62 J。能量来自她的肌肉向内拉重物，这一动作抵抗了重物向外飞离的趋势。冰面几乎不施加转矩，这正是 L 保持不变的原因。</p>

## 练习 14：碰撞与角动量

### 题目 14.1
一个质量 0.3 kg、速度 3.0 m/s 的球撞上杆（I = ⅓ML² = 0.48 kg·m²），撞击点距铰点 O 为 1.0 m，并且<b>黏</b>在杆上。碰撞刚结束时杆的 ω 是：

**选项**
1. 1.87 rad/s
2. 1.15 rad/s
3. 2.14 rad/s
4. 0.692 rad/s

**正确答案：** 2. 1.15 rad/s

**解析：**
铰点会施加力，所以线动量不守恒；但铰点关于 O 的转矩为零，因此关于 O 的角动量守恒：

<div class="eq">mv<sub>0</sub>d = (I + md²)ω → ω = 0.90 / (0.48 + 0.30) = 1.15 rad/s</div>

1.87 忘记了球现在也随杆转动；0.692 保持了线动量，而铰点会破坏线动量守恒。

### 题目 14.2
一个质量 0.3 kg 的球从静止开始下落，初始位置在 O 侧方 1.0 m 处，且与 O 位于同一竖直平面内。下落过程中，它关于 O 的角动量变化率的大小是多少？

**选项**
1. 1.47 kg·m²/s²
2. 5.88 kg·m²/s²
3. 2.94 kg·m²/s²
4. 0：它沿直线运动

**正确答案：** 3. 2.94 kg·m²/s²

**解析：**
令 O 为原点，球位于 (d, y)，则 p = (0, −mgt)。于是

<div class="eq">L = xp<sub>y</sub> − yp<sub>x</sub> = −d·mgt → |dL/dt| = mgd = 0.3 × 9.80 × 1.0 = 2.94 kg·m²/s²</div>

这就是重力关于 O 的转矩 d·mg。只有在没有力作用时，直线运动才会使 L 保持不变；这里球的速度正在增大。
