# 练习：电磁感应

## 第 0 页

### 题目 0.1

一个有 200 匝、面积为 50 cm² 的线圈平放在均匀磁场中，磁场垂直于线圈。磁场在 0.20 s 内从 0.10 T 匀速增大到 0.50 T。感应电动势的大小为：

1. 0.010 V
2. 2.000 V
3. 2.500 V
4. 0.080 V

**正确答案：** 2. 2.000 V

**解析：**

每一匝的磁通量为 Φ = <i>BA</i>，200 匝产生的磁通链相加：

> |ε| = <i>NA</i> Δ<i>B</i>/Δ<i>t</i> = 200 × 0.005 m² × 0.40 T / 0.2 s = 2.000 V

只有 <b>磁场的变化量</b> Δ<i>B</i> 计入结果：只使用 0.5 T 会得到 2.500 V，而漏掉 <i>N</i> 只会得到单匝的 0.010 V。

### 题目 0.2

穿过一个线圈的磁通量为 Φ<sub><i>B</i></sub>(<i>t</i>) = 4.0<i>t</i><sup>3</sup> − 6.0<i>t</i>（单位为 mWb，<i>t</i> 以 s 为单位）。在什么时刻 <i>t</i> > 0，感应电动势为零？

1. 1.22 s
2. 0.50 s
3. 1.41 s
4. 0.71 s

**正确答案：** 4. 0.71 s

**解析：**

电动势是 Φ 的<b>斜率的负值</b>，而不是 Φ 本身：

> ε = −<i>d</i>Φ/<i>dt</i> = −(12<i>t</i><sup>2</sup> − 6) = 0  →  <i>t</i> = √(6/12) = 0.71 s

在 1.22 s 时磁通量为零，但它仍在变化，因此电动势不为零。

## 第 1 页

### 题目 1.1

一根条形磁铁的 N 极沿轴线径直远离一个线圈。由磁铁方向看，线圈中的感应电流为：

1. 逆时针，且线圈排斥磁铁
2. 顺时针，且线圈排斥磁铁
3. 逆时针，且线圈吸引磁铁
4. 顺时针，且线圈吸引磁铁

**正确答案：** 4. 顺时针，且线圈吸引磁铁

**解析：**

N 极的磁场穿过线圈，方向背离观察者，并且正在减弱。感应磁场应指向同一方向，即背离观察者，以补偿磁通量的损失；根据右手定则，从磁铁方向看这是<b>顺时针</b>电流。磁力线进入线圈靠近磁铁的一面，因此该面是 S 极，会把 N 极拉回去：线圈阻碍磁铁的运动。

### 题目 1.2

在本页的线圈中（<i>R</i> = 10 mΩ），当 N 极在 2.6 s 内靠近时，磁通量从 0.59 µWb 增大到 26.32 µWb。绕线圈流过的总电荷量为：

1. 1.29 mC
2. 0.99 mC
3. 6.69 mC
4. 2.57 mC

**正确答案：** 4. 2.57 mC

**解析：**

对电流积分；时间因素会消去：

> <i>Q</i> = ∫<i>I dt</i> = ∫(ε/<i>R</i>) <i>dt</i> = (1/<i>R</i>)∫|<i>d</i>Φ| = ΔΦ/<i>R</i> = 25.73 µWb / 0.01 Ω = 2.57 mC

磁铁移动得多快并不重要。0.99 是以 mA 为单位的平均电流，不是电荷量。

## 第 2 页

### 题目 2.1

两个线圈共用一个铁芯。如果将<b>副线圈</b>的匝数加倍，互感 <i>M</i> 将：

1. 加倍
2. 不变
3. 变为四倍
4. 减半

**正确答案：** 1. 加倍

**解析：**

<i>M</i> = <i>N</i><sub>2</sub>Φ<sub>2</sub>/<i>I</i><sub>1</sub>。由原线圈的电流和匝数决定的每匝磁通量不变；副线圈匝数加倍，就有两倍的磁通链。<i>M</i> = μ<sub>r</sub>μ<sub>0</sub><i>N</i><sub>1</sub><i>N</i><sub>2</sub><i>A</i>/ℓ 对每一个 <i>N</i> 都是线性的；而自感则与 <i>N</i><sup>2</sup> 成正比。

### 题目 2.2

在本页的铁芯中（<i>M</i> = 59.2 mH，<i>L</i><sub>1</sub> = 118.4 mH），原线圈中的电流为 <i>I</i><sub>1</sub> = 2.0<i>t</i><sup>2</sup>（A，<i>t</i> 以 s 为单位）。在 <i>t</i> = 0.50 s 时，副线圈电动势的大小为：

1. 29.6 mV
2. 118.4 mV
3. 236.9 mV
4. 59.2 mV

**正确答案：** 2. 118.4 mV

**解析：**

> ε<sub>2</sub> = −<i>M dI</i><sub>1</sub>/<i>dt</i> = −<i>M</i>(4.0<i>t</i>) = −59.2 mH × 2.00 A/s = −118.4 mV

需要使用电流的变化率，而不是 <i>I</i><sub>1</sub> 本身（29.6 mV）；副线圈看到的是 <i>M</i>，而不是原线圈自己的 <i>L</i><sub>1</sub>。

## 第 3 页

### 题目 3.1

一个矩形线圈的两条边长为 <i>b</i>，且与一根载有电流 <i>I</i> 的长直导线平行；它的近边距导线为 <i>r</i>，远边距导线为 <i>r</i> + <i>a</i>。穿过线圈的磁通量为：

1. (μ<sub>0</sub><i>Ib</i>/2π<i>r</i>)<i>a</i>
2. (μ<sub>0</sub><i>Ib</i>/2π) ln((<i>r</i> + <i>a</i>)/<i>r</i>)
3. (μ<sub>0</sub><i>Ia</i>/2π) ln((<i>r</i> + <i>b</i>)/<i>r</i>)
4. (μ<sub>0</sub><i>Ib</i>/2π)(1/<i>r</i> − 1/(<i>r</i> + <i>a</i>))

**正确答案：** 2. (μ<sub>0</sub><i>Ib</i>/2π) ln((<i>r</i> + <i>a</i>)/<i>r</i>)

**解析：**

<i>B</i> = μ<sub>0</sub><i>I</i>/2π<i>s</i> 随距离 <i>s</i> 变化，因此把线圈切成与导线平行、宽度为 <i>b ds</i> 的条带：

> Φ = ∫<sub><i>r</i></sub><sup><i>r</i>+<i>a</i></sup> (μ<sub>0</sub><i>I</i>/2π<i>s</i>) <i>b ds</i> = (μ<sub>0</sub><i>Ib</i>/2π) ln((<i>r</i> + <i>a</i>)/<i>r</i>)

选项 1 把 <i>B</i> 当作近边处的均匀磁场；选项 4 是导数的形式，而不是积分的形式。

### 题目 3.2

本页的线圈（沿导线方向的 <i>b</i> = 10 cm，横向的 <i>a</i> = 6 cm）以 5 cm/s 的速度径直远离一根 50 A 导线。当线圈近边距导线 2 cm 时，|ε| 为：

1. 2.500 µV
2. 3.125 µV
3. 1.125 µV
4. 1.875 µV

**正确答案：** 4. 1.875 µV

**解析：**

只有与导线平行的两条边切割磁力线。每条边都有 <i>Bbv</i> 的运动电动势，并且它们在绕线圈一周时方向相反：

> ε = (<i>B</i><sub>近</sub> − <i>B</i><sub>远</sub>)<i>bv</i> = μ<sub>0</sub><i>Iabv</i> / 2π<i>r</i>(<i>r</i> + <i>a</i>) = 1.875 µV

这与对上述对数表达式求 −<i>d</i>Φ/<i>dt</i> 得到的结果相同。只计入近边得到 2.500 µV；把两条边相加得到 3.125 µV。

## 第 4 页

### 题目 4.1

一根竖直金属棒向右运动，穿过一个指向纸面内的均匀磁场，且没有接入电路。一段时间后：

1. 上端电势较高，且没有电流流过
2. 下端电势较高，且有电流流过
3. 下端电势较高，且没有电流流过
4. 上端电势较高，且电流沿金属棒向下流动

**正确答案：** 1. 上端电势较高，且没有电流流过

**解析：**

<i>F</i> = <i>qv</i>×<i>B</i>：向右 × 指向纸内 = 向上，因此正电荷聚集在上端。其产生的电场会向后抵消，直到 <i>qE</i> = <i>qvB</i>；此时没有电荷沿金属棒继续移动。没有闭合路径时存在 <i>BLv</i> 的电动势，但没有稳恒电流。

### 题目 4.2

一根 50 cm 长的金属棒以 20 rad/s 的角速度绕一端转动，转动平面垂直于均匀的 0.40 T 磁场。棒两端之间的电动势为：

1. 2.00 V
2. 1.00 V
3. 4.00 V
4. 0.50 V

**正确答案：** 2. 1.00 V

**解析：**

每一小段 <i>dr</i> 的速度为 <i>v</i> = ω<i>r</i>，因此其电动势为 <i>B</i>ω<i>r dr</i>。沿金属棒积分：

> ε = ∫<sub>0</sub><sup>ℓ</sup> <i>B</i>ω<i>r dr</i> = ½<i>B</i>ωℓ<sup>2</sup> = ½ × 0.4 × 20 × 0.5<sup>2</sup> = 1.00 V

如果把整个金属棒都使用端点速度 ωℓ，会得到 2.00 V，恰好大一倍：平均速度是端点速度的一半。

## 第 5 页

### 题目 5.1

线圈（高度 <i>h</i> = 25 cm，宽度 30 cm，<i>R</i> = 0.5 Ω）以恒定 0.5 m/s 的速度被拉入 0.4 T 磁场。当线圈前边已经进入磁场、后边仍在磁场外时，所需的拉力为：

1. 12.0 mN
2. 20.0 mN
3. 10.0 mN
4. 25.0 mN

**正确答案：** 3. 10.0 mN

**解析：**

> <i>I</i> = <i>Bhv</i>/<i>R</i>，&nbsp;<i>F</i> = <i>IhB</i> = <i>B</i><sup>2</sup><i>h</i><sup>2</sup><i>v</i>/<i>R</i> = 10.0 mN

只有前边在磁场中承载电流（上、下两边的力相互抵消），并且只有高度 <i>h</i> 的边切割磁力线。检验：<i>Fv</i> = 5.0 mW = ε<sup>2</sup>/<i>R</i>。

### 题目 5.2

一个质量为 <i>m</i>、电阻为 <i>R</i>、高度为 <i>h</i> 的线圈，以初速度 <i>v</i><sub>0</sub> 在没有拉力的情况下<b>自由</b>滑入均匀磁场 <i>B</i>。求在线圈后边仍位于磁场外时，线圈前边进入磁场的距离 <i>x</i> 与速度的函数关系。

**解答：**

只有前边在磁场中时，电流为 <i>Bhv</i>/<i>R</i>，磁场对它施加大小为 <i>IhB</i>、方向向后的力：

> <i>m dv</i>/<i>dt</i> = −<i>B</i><sup>2</sup><i>h</i><sup>2</sup><i>v</i>/<i>R</i>

写成 <i>dv</i>/<i>dt</i> = <i>v dv</i>/<i>dx</i> 并约去 <i>v</i>：

> <i>m dv</i>/<i>dx</i> = −<i>B</i><sup>2</sup><i>h</i><sup>2</sup>/<i>R</i> &nbsp;→&nbsp; <i>v</i>(<i>x</i>) = <i>v</i><sub>0</sub> − <i>B</i><sup>2</sup><i>h</i><sup>2</sup><i>x</i>/<i>mR</i>

速度随<b>距离线性</b>下降（随时间呈指数下降）。如果 <i>v</i> 在线圈宽度对应的 <i>x</i> 之前就会降到 0，线圈会在进入途中停下。

## 第 6 页

### 题目 6.1

本页的金属棒（τ = <i>mR</i>/<i>B</i><sup>2</sup><i>L</i><sup>2</sup> = 1.00 s）以 1.00 m/s 的速度被释放，之后没有任何东西推动它。它在停止前移动多远？

1. 0.50 m
2. 0.63 m
3. 它永远不会停止，因此距离无限增长
4. 1.00 m

**正确答案：** 4. 1.00 m

**解析：**

速度呈指数衰减，但它的积分是有限的：

> <i>x</i> = ∫<sub>0</sub><sup>∞</sup> <i>v</i><sub>0</sub><i>e</i><sup>−<i>t</i>/τ</sup> <i>dt</i> = <i>v</i><sub>0</sub>τ = 1.00 m

0.63 m 只是它在 <i>t</i> = τ 时走过的距离；0.50 m 则是假设减速度恒定时的结果。

### 题目 6.2

把连接两条导轨的电阻换成原来两倍的电阻，并以相同的速度发射金属棒。当它停下来时产生的总热量：

1. 加倍
2. 减半
3. 不变
4. 变为四倍

**正确答案：** 3. 不变

**解析：**

无论 <i>R</i> 取何值，金属棒全部的动能 ½<i>mv</i><sub>0</sub><sup>2</sup> 最终都变成热量。较大的 <i>R</i> 意味着较小的电流和较弱的制动，因此 τ 加倍、金属棒滑行距离加倍，但总热量不变。

## 第 7 页

### 题目 7.1

一个螺线管长 25 cm，共有 500 匝，半径为 1.0 cm。它的电感约为：

1. 0.395 mH
2. 1.579 mH
3. 0.79 µH
4. 0.126 mH

**正确答案：** 1. 0.395 mH

**解析：**

每匝中的磁场为 <i>B</i> = μ<sub>0</sub><i>nI</i>，因此 <i>N</i>Φ = <i>N</i>(μ<sub>0</sub><i>NI</i>/ℓ)π<i>r</i><sup>2</sup>，从而：

> <i>L</i> = μ<sub>0</sub><i>N</i><sup>2</sup>π<i>r</i><sup>2</sup>/ℓ = 0.395 mH

如果用直径代替 <i>r</i>，结果会大 4 倍；使用 <i>N</i> 而不是 <i>N</i><sup>2</sup>，忽略了更多匝数既会产生更强磁场，也会捕获更多磁通。

### 题目 7.2

本页的螺线管（<i>L</i> = 2.37 mH）中的电流为 <i>I</i>(<i>t</i>) = (2.0 A) sin(50<i>t</i>)。其反电动势的最大绝对值为：

1. 4.74 mV
2. 0.095 mV
3. 236.9 mV
4. 11.8 V

**正确答案：** 3. 236.9 mV

**解析：**

> ε<sub><i>L</i></sub> = −<i>L dI</i>/<i>dt</i> = −<i>LI</i><sub>0</sub>ω cos ω<i>t</i>，&nbsp;最大值 <i>LI</i><sub>0</sub>ω = 2.37 mH × 2 A × 50 s<sup>−1</sup> = 236.9 mV

峰值出现在 <i>I</i> = 0 且变化最快时；<i>LI</i><sub>0</sub> = 4.74 mV 是以 mWb 表示的磁通链，而不是电动势。

## 第 8 页

### 题目 8.1

在本页的电路中（ε = 12 V，<i>R</i> = 4 Ω，<i>L</i> = 2 H），从 <i>I</i> = 0 开始，电流达到 2.0 A 需要多长时间？

1. 0.500 s
2. 0.549 s
3. 0.203 s
4. 0.333 s

**正确答案：** 2. 0.549 s

**解析：**

从 <i>I</i> = 0 出发，解方程 <i>L dI</i>/<i>dt</i> = ε − <i>IR</i>：<i>I</i> = (ε/<i>R</i>)(1 − <i>e</i><sup>−<i>t</i>/τ</sup>)，τ = <i>L</i>/<i>R</i> = 0.50 s。

> <i>t</i> = −τ ln(1 − <i>IR</i>/ε) = −0.50 ln(1 − 2.0/3.0) = 0.549 s

2.0 A 是 3 A 的 67%，高于在 τ 时达到的 63%，所以所需时间长于 τ。

### 题目 8.2

一个带电池的 RL 电路已经接通很长时间，此时电池突然从回路中取出（回路仍通过电阻保持闭合）。紧接着：

1. 电流为 ε/<i>R</i>，正在减小，且电感充当电源
2. 电流为零
3. 电流为 ε/<i>R</i> 且保持不变
4. 电流反向

**正确答案：** 1. 电流为 ε/<i>R</i>，正在减小，且电感充当电源

**解析：**

电感不允许电流突然跳变，因此 <i>I</i> 一开始仍为 ε/<i>R</i>，方向也相同。没有电池时，<i>L dI</i>/<i>dt</i> = −<i>IR</i>：电感的电动势现在驱动电流通过 <i>R</i>，电流按 <i>e</i><sup>−<i>t</i>/τ</sup> 衰减，并把 ½<i>LI</i><sup>2</sup> 转化为热量。

## 第 9 页

### 题目 9.1

本页的电容器（25 µF，100 µC）在 <i>t</i> = 0 时接入 40 mH 的线圈。电流第一次达到最大值是在：

1. <i>t</i> = 3.14 ms，100 mA
2. <i>t</i> = 1.57 ms，15.9 mA
3. <i>t</i> = 1.57 ms，100 mA
4. <i>t</i> = 0，100 mA

**正确答案：** 3. <i>t</i> = 1.57 ms，100 mA

**解析：**

ω = 1/√(<i>LC</i>) = 1000 rad/s，<i>T</i> = 2π/ω = 6.28 ms。令 <i>q</i> = <i>Q</i> cos ω<i>t</i>，则 <i>I</i> = −ω<i>Q</i> sin ω<i>t</i>；电流第一次达到最大值是在 ω<i>t</i> = π/2，即经过四分之一周期、极板上的电荷耗尽时：

> <i>t</i> = <i>T</i>/4 = 1.57 ms，&nbsp;|<i>I</i>| = ω<i>Q</i> = 100 mA

在 <i>t</i> = 0 时电流为零：线圈不允许电流突然跳变。15.9 mA 是把 <i>f</i> 错当成 ω 使用的结果。

### 题目 9.2

对于没有电阻的 LC 电路，证明 <i>U</i> = <i>q</i><sup>2</sup>/2<i>C</i> + ½<i>LI</i><sup>2</sup> 为常量，并利用能量求出电容器上的电荷为 <i>Q</i>/2 时的电流（其最大电荷为 <i>Q</i>）。

**解答：**

使用 <i>I</i> = <i>dq</i>/<i>dt</i> 对其求导：

> <i>dU</i>/<i>dt</i> = (<i>q</i>/<i>C</i>)<i>I</i> + <i>LI dI</i>/<i>dt</i> = <i>I</i>(<i>q</i>/<i>C</i> + <i>L dI</i>/<i>dt</i>)

括号内正是回路方程，在每个时刻都等于零，因此始终有 <i>U</i> = <i>Q</i><sup>2</sup>/2<i>C</i>。当 <i>q</i> = <i>Q</i>/2 时：

> ½<i>LI</i><sup>2</sup> = <i>Q</i><sup>2</sup>/2<i>C</i> − <i>Q</i><sup>2</sup>/8<i>C</i> = 3<i>Q</i><sup>2</sup>/8<i>C</i> &nbsp;→&nbsp; |<i>I</i>| = (√3/2) <i>Q</i>/√(<i>LC</i>) = (√3/2)ω<i>Q</i>

对于本页电路，结果为 86.6 mA。当只有一半电荷离开电容器时，四分之三的能量位于线圈中。
