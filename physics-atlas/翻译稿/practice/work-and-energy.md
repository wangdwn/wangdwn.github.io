# 练习：功与能

> 本练习对应 Atlas of Physics《功与能》章节的独立练习模块。题目、选项、提示、答案、解析及公式均按实际运行时内容翻译；物理符号、数值、单位与题目顺序保持不变。

## 第 1 页：拉力与功

### 1.1

绳子以高于水平线 `30°` 的方向对质量为 `4.0 kg` 的箱子施加 `20 N` 的拉力，箱子沿无摩擦地面滑行 `3.0 m`。绳子做了多少功？

1. `30.0 J`
2. `60.0 J`
3. `52.0 J` **（正确答案）**
4. `69.3 J`

**解析：** 只有沿位移方向的分量做功：

\[
W=F\Delta x\cos\theta=20\times3.0\times\cos30°=52.0\text{ J}
\]

`30.0 J` 使用了 `sin θ`，这是横向于运动的分量；`60.0 J` 忽略了角度。

### 1.2

在同一次拉动过程中，地面对箱子的支持力做了多少功？

1. 负功，因为支持力小于 `mg`
2. 零，因为它垂直于位移 **（正确答案）**
3. 正功，因为它指向上方
4. 等于绳子所做的功的相反数

**解析：** 支持力竖直向上，而箱子水平移动：`θ = 90°`，`cos 90° = 0`，所以 `W = 0`。支持力的大小（由于绳子略微向上拉而小于 `mg`）并不重要。

## 第 2 页：向上抛球

### 2.1

质量为 `0.50 kg` 的球以 `6.0 m/s` 的速度竖直向上离开手。重力从手到最高点对它做了多少功？

1. `9.00 J`
2. `0.00 J`
3. `−18.00 J`
4. `−9.00 J` **（正确答案）**

**解析：** 重力方向与运动方向相反（`θ = 180°`），因此重力做负功；根据功—能定理，它移除了全部动能：

\[
W_g=\Delta K=0-\frac12\times0.50\times6.0^2=-9.00\text{ J}
\]

`−18.00 J` 忘记了 `1/2`；`+9.00 J` 的符号错误。

### 2.2

在整个运动过程中，从球离开手直到它回到同一高度，重力对球所做的总功是：

1. 正功
2. 负功
3. 零 **（正确答案）**
4. 等于 `mgh`，其中 `h` 是最高高度

**解析：** 上升途中重力做负功，下降途中做等量的正功：总功为零。这就是为什么在没有空气阻力时，球会以发射时的速度回到手中。

## 第 3 页：匀速圆周运动

### 3.1

绳子对绕圈运动的球施加的张力为 `4.5 N`，圆的半径为 `1.0 m`。绕半圈的过程中，张力做了多少功？

1. `14.1 J`
2. `9.0 J`
3. `−14.1 J`
4. `0 J` **（正确答案）**

**解析：** 在每一瞬间，张力都指向圆心，而速度沿圆周方向；二者夹角为 `90°`，所以每一小段位移贡献的功为 `T ds cos 90° = 0`。总功为 `0 J`，速度始终不变。

`14.1 J` 把力乘以弧长，仿佛二者平行；`9.0 J` 使用了直径（即净位移），但在每个瞬间位移方向仍不沿力的方向。

### 3.2

现在让球在同一根绳子上以两倍速度绕圈。张力和球的动能分别改变了多少倍？

1. 张力 ×2，动能 ×4
2. 张力 ×4，动能 ×4 **（正确答案）**
3. 张力 ×4，动能 ×2
4. 张力 ×2，动能 ×2

**解析：** `T = mv²/r`，`K = ½mv²` 都与 `v²` 成正比，因此二者都增大为原来的 `4` 倍。张力仍然不做功：增大的动能来自使球加速的其他因素。

## 第 4 页：净力与速度

### 4.1

一个大小为 `3.0 kN` 的净力推动质量为 `1200 kg` 的汽车，使它从静止开始通过 `12 m`。此时汽车的速度是多少？

1. `5.48 m/s`
2. `7.75 m/s` **（正确答案）**
3. `30.0 m/s`
4. `60.0 m/s`

**解析：**

\[
W_{\rm net}=F\Delta x=36.0\text{ kJ}=\frac12mv^2
\quad\Rightarrow\quad
v=\sqrt{\frac{2\times36000}{1200}}=7.75\text{ m/s}
\]

`5.48 m/s` 丢掉了 `1/2`；另外两个选项忘记了开平方根。

### 4.2

同一个净力先使汽车从静止达到速度 `v`，再使它从 `v` 达到 `2v`。第二阶段的净功是第一阶段的多少倍？

1. `1`
2. `2`
3. `4`
4. `3` **（正确答案）**

**解析：** 从 `0` 到 `v` 时，`ΔK = ½mv²`。从 `v` 到 `2v` 时，

\[
\Delta K=\frac12m(4v^2-v^2)=3\times\frac12mv^2
\]

动能与 `v²` 成正比，因此速度的相等增量需要越来越多的功（也需要越来越长的距离）。

## 第 5 页：重力势能

### 5.1

取距地面 `1.0 m` 高的桌面为 `U_g = 0`。质量为 `0.50 kg`、被托在距地面 `3.0 m` 高处的球，其 `U_g` 是多少？

1. `14.70 J`
2. `4.90 J`
3. `9.80 J` **（正确答案）**
4. `19.60 J`

**解析：** 从选定的零点测量 `Δy`：`3.0 − 1.0 = 2.0 m`。

\[
U_g=mg\Delta y=0.50\times9.80\times2.0=9.80\text{ J}
\]

只有在把地面作为零点时，`14.70 J` 才是正确的。

### 5.2

球从 `3.0 m` 高处落下。当它位于距地面 `1.0 m` 高处时，速度有多大？

1. `4.43 m/s`
2. `7.67 m/s`
3. `39.2 m/s`
4. `6.26 m/s` **（正确答案）**

**解析：** 它下落了 `2.0 m`，损失的 `U_g` 现在转化为 `K`：

\[
mg\Delta y=\frac12mv^2
\quad\Rightarrow\quad
v=\sqrt{2\times9.80\times2.0}=6.26\text{ m/s}
\]

`4.43 m/s` 使用的是它距地面的高度，而不是已经下落的距离。

## 第 6 页：弹簧

### 6.1

质量为 `2.0 kg` 的木块以 `2.0 m/s` 的速度撞上劲度系数为 `50 N/m` 的弹簧。当木块速度减慢到 `1.0 m/s` 时，弹簧被压缩了多远？

1. `0.346 m` **（正确答案）**
2. `0.200 m`
3. `0.120 m`
4. `0.245 m`

**解析：**

\[
\frac12mv_0^2=\frac12mv^2+\frac12k\Delta x^2
\quad\Rightarrow\quad
\Delta x=\sqrt{\frac{m(v_0^2-v^2)}{k}}
=\sqrt{\frac{2.0\times3.0}{50}}=0.346\text{ m}
\]

速度减半并不意味着压缩量减半：四分之三的动能已经被储存起来，因此 `Δx` 是 `0.400 m` 的 `√¾`。

### 6.2

如果木块进入时的速度加倍，弹簧的最大压缩量将会：

1. 保持不变
2. 变为原来的 `√2` 倍
3. 变为原来的两倍 **（正确答案）**
4. 变为原来的四倍

**解析：**

\[
\frac12kx_{\max}^2=\frac12mv_0^2
\]

所以 `x_max = v_0√(m/k)`，与 `v_0` 成正比。能量变为四倍，但能量与 `x²` 成正比，因此压缩量变为两倍。

## 第 7 页：变化的推力

### 7.1

推力

\[
F(x)=F_0(1-x/L)(1+2x/L)
\]

其中 `F_0 = 16 N`、`L = 3.0 m`。该推力作用于质量为 `5.0 kg`、从静止开始的箱子。当 `x = L` 时，箱子的速度是多少？

1. `4.38 m/s`
2. `2.83 m/s`
3. `3.10 m/s`
4. `4.00 m/s` **（正确答案）**

**解析：** 展开并积分：

\[
W=\int_0^L F_0(1+x/L-2x^2/L^2)\,dx
=F_0L(1+1/2-2/3)=\frac56F_0L=40.0\text{ J}
\]

\[
v=\sqrt{2W/m}=\sqrt{2\times40.0/5.0}=4.00\text{ m/s}
\]

`4.38 m/s` 把推力当作恒定的 `16 N`；`3.10 m/s` 只取两个端点值的平均值，遗漏了中间的隆起部分。

### 7.2

**自由作答。** 求同一推力在其作用范围的前半段，即从 `x = 0` 到 `x = L/2`，所做的功。它比总功 `40.0 J` 的一半多还是少？为什么？

**参考解答：** 展开：

\[
F=F_0(1+x/L-2x^2/L^2)
\]

逐项积分：

\[
W=F_0[x+x^2/(2L)-2x^3/(3L^2)]_0^{L/2}
=F_0L(1/2+1/8-1/12)=\frac{13}{24}F_0L
\]

\[
W=\frac{13}{24}\times16\times3.0=26.0\text{ J}
\]

它多于 `40.0 J` 的一半：推力在 `x = L/4` 处达到峰值，所以 `F(x)` 曲线下的面积集中在前半段，后半段只有逐渐衰减的尾部。

## 第 8 页：单摆

### 8.1

质量为 `1.0 kg`、长度为 `2.0 m` 的摆球从偏离竖直方向 `40°` 的位置由静止释放。当绳子与竖直方向成 `20°` 时，摆球的速度有多大？

1. `2.61 m/s` **（正确答案）**
2. `1.54 m/s`
3. `3.03 m/s`
4. `2.14 m/s`

**解析：** 只有两个角度之间的高度下降量计入：`Δy = L(cos 20° − cos 40°) = 0.347 m`。

\[
v=\sqrt{2g\Delta y}=\sqrt{2\times9.80\times0.347}=2.61\text{ m/s}
\]

`1.54 m/s` 使用的是摆球在 `20°` 处相对于最低点的高度，而不是从 `40°` 下降的高度。角度减半并不意味着能量减半。

### 8.2

摆球经过最低点时，绳中的张力是多少？

1. `7.51 N`
2. `9.80 N`
3. `14.39 N` **（正确答案）**
4. `5.21 N`

**解析：** 摆球在最低点以 `3.03 m/s` 的速度沿圆周运动，因此合力指向上方、朝向支点：

\[
T-mg=mv^2/L\quad\Rightarrow\quad T=9.80+4.59=14.39\text{ N}
\]

只有在摆球在那里静止时，`T = mg` 才成立。

## 第 9 页：单粒子势能

### 9.1

一个粒子沿 `x` 方向运动，其势能为 `U(x) = 3x² − 2x³`（`U` 的单位为 `J`，`x` 的单位为 `m`）。当 `x = 2.0 m` 时，粒子所受的力是多少？

1. `4.0 N`
2. `−12.0 N`
3. `−4.0 N`
4. `+12.0 N` **（正确答案）**

**解析：**

\[
F_x=-dU/dx=-(6x-6x^2)=-(12-24)=+12.0\text{ N}
\]

此处 `U` 的斜率为负（`U` 朝 `+x` 方向下降），所以力指向 `+x`，即沿“下坡”方向。`−12.0 N` 忘记了负号；`±4.0 N` 使用的是 `U` 本身，而不是它的斜率。

### 9.2

对于同一个 `U(x) = 3x² − 2x³`，粒子可以在 `x = 0` 和 `x = 1 m` 处处于平衡。两者分别是哪一种平衡？

1. 二者都稳定
2. `x = 0` 不稳定，`x = 1 m` 稳定
3. `x = 0` 稳定，`x = 1 m` 不稳定 **（正确答案）**
4. 二者都不稳定

**解析：**

\[
dU/dx=6x-6x^2=0
\]

在 `x = 0` 和 `x = 1` 处都成立。由二阶导数决定稳定性：`U″ = 6 − 12x` 在 `x = 0` 处为 `+6`（谷底，稳定），在 `x = 1 m` 处为 `−6`（峰顶，不稳定）。

## 第 10 页：化学键

### 10.1

**自由作答。** 对于该化学键，

\[
U(r)=\varepsilon[(r_0/r)^{12}-2(r_0/r)^6]
\]

其中 `ε = 1.0 eV`，`r_0 = 0.15 nm`。证明 `r_0` 是一个平衡位置，求弹簧常数 `k = U″(r_0)`，以及质量为 `1.0 u` 的原子的小振动周期。

**参考解答：** 求导：

\[
U'=\varepsilon[-12r_0^{12}/r^{13}+12r_0^6/r^7]
\]

当 `r = r_0` 时，中括号内为 `−12/r_0 + 12/r_0 = 0`：没有力，处于平衡状态。

\[
U″=\varepsilon[156r_0^{12}/r^{14}-84r_0^6/r^8]
\quad\Rightarrow\quad
U″(r_0)=72\varepsilon/r_0^2
\]

该值为正，因此这是一个稳定极小值。取 `ε = 1.602×10⁻¹⁹ J`，`r_0 = 0.15×10⁻⁹ m`：

\[
k=72\times1.602\times10^{-19}/(0.15\times10^{-9})^2=513\text{ N/m}
\]

\[
T=2\pi\sqrt{m/k}=2\pi\sqrt{1.661\times10^{-27}/513}=11.3\text{ fs}
\]

### 10.2

一个处于势阱中的粒子，其总能量 `E` 低于阱口。在任一转向点处：

1. 它的速度为零，且所受的力为零
2. 它的速度最大，且所受的力为零
3. 它的势能为零
4. 它的速度为零，且所受的力指向势阱内部 **（正确答案）**

**解析：** 在转向点，`U = E`，所以 `K = 0`，粒子停下。但此处 `U` 有斜率（这是势阱的墙，而不是底部），因此 `F = −dU/dx ≠ 0`，并且力沿下坡方向、指回极小值所在的势阱内部。这就是粒子转向的原因。

## 第 11 页：摩擦与热能

### 11.1

木块现在以 `8.0 m/s` 而不是 `4.0 m/s` 的速度滑上同一地面（`μ_k = 0.40`）。它会滑多远？

1. `4.08 m`
2. `8.16 m` **（正确答案）**
3. `2.04 m`
4. `16.3 m`

**解析：**

\[
\frac12mv_0^2=\mu_kmgd
\quad\Rightarrow\quad
d=\frac{v_0^2}{2\mu_kg}=\frac{8.0^2}{2\times0.40\times9.80}=8.16\text{ m}
\]

速度加倍，动能变为四倍，距离也变为四倍（此前滑行了 `2.04 m`）。`4.08 m` 把距离加倍，当作 `d∝v`。

### 11.2

回到 `4.0 m/s`（动能为 `16.0 J`）：滑行最初 `1.0 m` 后，摩擦产生了多少热能？

1. `8.00 J`
2. `3.92 J`
3. `7.84 J` **（正确答案）**
4. `16.00 J`

**解析：**

\[
E_{\rm th}=fd=\mu_kmg\times d=0.40\times2.0\times9.80\times1.0=7.84\text{ J}
\]

木块仍有 `8.16 J` 的 `K`。`3.92 J` 漏掉了质量这一因素。

## 第 12 页：功率

### 12.1

一名质量为 `70 kg` 的学生以恒定速度跑上高度为 `3.0 m` 的楼梯，用时 `4.2 s`。她把自己提升上去的平均功率是多少？

1. `50.0 W`
2. `490 W` **（正确答案）**
3. `2058 W`
4. `8644 W`

**解析：**

\[
P=W/t=mgh/t=70\times9.80\times3.0/4.2=490\text{ W}
\]

`2058` 是以焦耳为单位的功，而不是功率；`50.0 W` 使用了质量而不是重量。

### 12.2

一台起重机以恒定的 `0.5 m/s` 将一个箱子提升高度 `h`，然后以恒定的 `1.0 m/s` 将一个相同的箱子提升相同高度。与较慢的提升相比，较快的提升需要：

1. 两倍的功和两倍的功率
2. 相同的功和相同的功率
3. 相同的功和两倍的功率 **（正确答案）**
4. 一半的功和两倍的功率

**解析：** 在恒定速度下，两种情况下缆绳的拉力都是 `mg`，所以功 `mgh` 相同。快速提升所需时间减半，因此 `P = W/t = Fv` 加倍。
