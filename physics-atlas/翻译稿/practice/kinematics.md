# 练习：运动学

> 本文件完整翻译 Atlas of Physics《运动学》练习模块中的用户可见题目、选项、正确答案和解析。公式、符号、数值与单位以练习模块运行时数据为准。

## 第 0 页

### 题目 0.1

球以 `19.6 m/s` 的速度竖直向上抛出，而不是 `9.80 m/s`。它上升的高度是多少？（不计空气阻力。）

**选项：**

1. `9.80 m`
2. `6.93 m`
3. `19.6 m`
4. `39.2 m`

**正确答案：** 3. `19.6 m`

**解析：**

在最高点，<i>v</i> = 0，因此 <i>h</i> = <i>v</i><sub>0</sub>²/2<i>g</i>。高度与发射速度的**平方**成正比：将 <i>v</i><sub>0</sub> 加倍，就得到 4 × `4.90 m`。

<div class="eq"><i>h</i> = (19.6)² / (2 × 9.80) = 19.6 m</div>

`9.80 m` 的结果假定高度与速度成正比。

### 题目 0.2

在球处于最高点的瞬间，它的加速度是

1. 零
2. `9.80 m/s²`，方向向下
3. `9.80 m/s²`，方向向上
4. 未定义，因为它正在改变方向

**正确答案：** 2. `9.80 m/s²`，方向向下

**解析：**

在每一个瞬间，重力都是唯一的力，因此整个飞行过程中 <i>a</i> = <i>g</i> = `9.80 m/s²`，方向始终向下。在最高点，**速度**为零，但速度仍在改变：片刻之后它就指向下方。

## 第 1 页

### 题目 1.1

一个球以 `9.80 m/s` 的速度从悬崖边竖直向上抛出，并在下落途中、位于抛出点**下方** `1.50 m` 处被接住。它总共运动了多远？

**选项：**

1. `1.50 m`
2. `8.30 m`
3. `6.40 m`
4. `11.3 m`

**正确答案：** 4. `11.3 m`

**解析：**

路径的每一段都要计入距离。它先上升 <i>h</i> = <i>v</i><sub>0</sub>²/2<i>g</i> = `4.90 m`，再下落 `4.90 m` 回到抛出点，然后继续下落 `1.50 m`：

<div class="eq">4.90 + 4.90 + 1.50 = 11.3 m</div>

`1.50 m` 是**位移**的大小（取向上为正时位移为 −`1.50 m`），而不是距离。

### 题目 1.2

对于沿直线运动的物体，它的位移大小与运动距离相比如何？

1. 它们总是相等。
2. 位移可能大于距离。
3. 位移从不大于距离；只有物体从不反向时，两者才相等。
4. 位移总是小于距离。

**正确答案：** 3. 位移从不大于距离；只有物体从不反向时，两者才相等。

**解析：**

距离统计路径上的每一米；位移只统计净变化。任何反向运动都会抵消一部分位移，却会增加距离（往返运动中，位移为 `0 m`，而距离为 `9.80 m`）。没有反向时两者相等，所以“总是更小”也不对。

## 第 2 页

### 题目 2.1

从抛出到 <i>t</i> = `1.50 s` 时，球的平均**速率**是多少？（球以 `9.80 m/s` 的速度向上抛出，在 `1.00 s` 时于 `4.90 m` 处达到最高点。）

**选项：**

1. `4.08 m/s`
2. `2.45 m/s`
3. `3.27 m/s`
4. `7.35 m/s`

**正确答案：** 1. `4.08 m/s`

**解析：**

平均速率 = 距离 / 时间。在 `1.50 s` 时，球位于 <i>y</i> = `9.80`(`1.50`) − ½(`9.80`)(`1.50`)² = `3.675 m`，此时正在下落。距离 = 向上 `4.90 m` + 向下 `1.225 m` = `6.125 m`。

<div class="eq">6.125 m / 1.50 s = 4.08 m/s</div>

`2.45 m/s` 是平均**速度**（位移 / 时间）。

### 题目 2.2

比较球刚离手后的速度与它返回到手中前一刻的速度。

1. 它们相同。
2. 着地速度更大，因为重力作用的时间更长。
3. 两者平均起来都为零，因此无法比较。
4. 速率相同，方向相反。

**正确答案：** 4. 速率相同，方向相反。

**解析：**

运动是对称的：抛出时为 +`9.80 m/s`，从同一高度下落时为 −`9.80 m/s`（由 <i>v</i>² = <i>v</i><sub>0</sub>² + 2<i>a</i>Δ<i>y</i>，且 Δ<i>y</i> = 0）。速率相等，但速度包含方向，所以两个速度不同。

## 第 3 页

### 题目 3.1

取向上为正。在飞行的哪一段球在加速（速率增加）？

1. 上升时，因为它的速度为正
2. 最高点，因为它的加速度在那里最大
3. 下落时，因为 <i>v</i> 和 <i>a</i> 符号相同
4. 从不加速：负加速度总会使物体减速

**正确答案：** 3. 下落时，因为 <i>v</i> 和 <i>a</i> 符号相同

**解析：**

加速意味着 <i>v</i> 和 <i>a</i> 指向同一方向。整个过程中 <i>a</i> = −`9.80 m/s²`；下落时 <i>v</i> 也为负，因此速率增加。只有当 <i>v</i> 为正时，负的 <i>a</i> 才会使球减速。

### 题目 3.2

频闪灯每隔 `0.200 s` 闪烁一次。在上升过程中，相邻图像之间的每个间隔相对于前一个间隔缩短多少？

**选项：**

1. `0.196 m`
2. `0.392 m`
3. `1.96 m`
4. `0.784 m`

**正确答案：** 2. `0.392 m`

**解析：**

每个间隔是在一个时间间隔内走过的距离，即 <i>v</i>τ − ½<i>g</i>τ²，其中 <i>v</i> 是该间隔开始时的速度。从一个间隔到下一个间隔，<i>v</i> 减少 <i>g</i>τ，因此间隔减少 (<i>g</i>τ)τ：

<div class="eq">Δ（间隔） = <i>g</i>τ² = 9.80 × (0.200)² = 0.392 m</div>

½ 属于单个间隔，不属于两个间隔之差。

## 第 4 页

### 题目 4.1

在球的 <i>v</i>–<i>t</i> 图像上（取向上为正，<i>v</i><sub>0</sub> = `9.80 m/s`），从 0 到 `1.50 s`，直线与时间轴之间的净面积是多少？

**选项：**

1. `6.13 m`
2. `14.7 m`
3. `4.90 m`
4. `3.68 m`

**正确答案：** 4. `3.68 m`

**解析：**

<i>v</i>–<i>t</i> 图像下的面积就是位移；时间轴下方的面积计为负值。在时间 `1.00 s` 之前，时间轴上方是一个三角形：+½(`9.80`)(`1.00`) = +`4.90 m`。从 `1.00 s` 到 `1.50 s`，时间轴下方的面积为 −½(`0.50`)(`4.90`) = −`1.225 m`。

<div class="eq">净面积 = 4.90 − 1.225 = 3.68 m</div>

`6.13 m` 把时间轴下方的部分加上了，而不是减去；那是距离。

### 题目 4.2

在球处于最高点的瞬间，以下哪一项为零？

1. <i>y</i>–<i>t</i> 图像的斜率
2. <i>v</i>–<i>t</i> 图像的斜率
3. 从 <i>a</i>–<i>t</i> 图像读出的值
4. 从抛出开始到此刻 <i>a</i>–<i>t</i> 图像下的面积

**正确答案：** 1. <i>y</i>–<i>t</i> 图像的斜率

**解析：**

<i>y</i>–<i>t</i> 图像的斜率就是速度，而速度在最高点为零。<i>v</i>–<i>t</i> 图像的斜率和 <i>a</i>–<i>t</i> 图像的值都为 −`9.80 m/s²`。从抛出开始到此刻，<i>a</i>–<i>t</i> 图像下的面积是 Δ<i>v</i> = −`9.80 m/s`，不是零。

## 第 5 页

### 题目 5.1

球位于抛出点上方 `3.00 m` 时运动得多快？（<i>v</i><sub>0</sub> = `9.80 m/s`，方向向上。）

**选项：**

1. `12.4 m/s`
2. `6.10 m/s`
3. `8.16 m/s`
4. `37.2 m/s`

**正确答案：** 2. `6.10 m/s`

**解析：**

题目没有给出时间，也不需要时间，因此使用不含 <i>t</i> 的方程，其中 <i>a</i> = −`9.80 m/s²`：

<div class="eq"><i>v</i>² = 9.80² + 2(−9.80)(3.00) = 37.24 m²/s²，&nbsp;<i>v</i> = 6.10 m/s</div>

`12.4 m/s` 是把 <i>a</i> 当作 +<i>g</i> 得出的：球在高处必须更慢，而不是更快。（它在上升和下落时都会两次经过 `3.00 m`，且两次速率相同。）

### 题目 5.2

你想求球第一次到达 `3.00 m` 所需的时间，并且只知道 <i>v</i><sub>0</sub>、<i>a</i> 和 Δ<i>y</i>。哪一个方程可以一步求出它？

**选项：**

1. <i>v</i> = <i>v</i><sub>0</sub> + <i>at</i>
2. <i>v</i>² = <i>v</i><sub>0</sub>² + 2<i>a</i>Δ<i>y</i>
3. Δ<i>y</i> = <i>v</i><sub>0</sub><i>t</i> + ½<i>at</i>²
4. Δ<i>y</i> = ½(<i>v</i><sub>0</sub> + <i>v</i>)<i>t</i>

**正确答案：** 3. Δ<i>y</i> = <i>v</i><sub>0</sub><i>t</i> + ½<i>at</i>²

**解析：**

不需要的未知量是末速度 <i>v</i>，所以应选择不含 <i>v</i> 的方程：Δ<i>y</i> = <i>v</i><sub>0</sub><i>t</i> + ½<i>at</i>²。它关于 <i>t</i> 是二次方程；较小的根对应上升过程。其余三个方程要么包含 <i>v</i>，要么不含 <i>t</i>。

## 第 6 页

### 题目 6.1

第二个球以 `6.00 m/s` 的水平速度和 `9.80 m/s` 的向上速度离手。在它的运动轨迹最高点，速率是多少？

**选项：**

1. `0 m/s`
2. `9.80 m/s`
3. `11.5 m/s`
4. `6.00 m/s`

**正确答案：** 4. `6.00 m/s`

**解析：**

在最高点，只有 <i>v</i><sub>y</sub> 为零。水平方向没有力作用，因此 <i>v</i><sub>x</sub> 保持为 `6.00 m/s`，速率为 √(<i>v</i><sub>x</sub>² + 0²) = `6.00 m/s`。“`0 m/s`”只适用于竖直向上抛出的球。

### 题目 6.2

再次抛出时，向上的速度仍为 `9.80 m/s`，但水平速度为原来的**两倍**，即 `12.00 m/s`，并且从水平地面抛出。它落地时距离多远？

**选项：**

1. `12.0 m`
2. `24.0 m`
3. `48.0 m`
4. `17.0 m`

**正确答案：** 2. `24.0 m`

**解析：**

空中的时间只取决于竖直运动：<i>t</i> = 2<i>v</i><sub>0y</sub>/<i>g</i> = `2.00 s`，没有改变。水平方向做匀速运动：

<div class="eq">Δ<i>x</i> = <i>v</i><sub>x</sub><i>t</i> = 12.00 × 2.00 = 24.0 m</div>

若将整个初速度加倍，空中时间也会加倍，才会得到 `48.0 m`。

## 第 7 页

### 题目 7.1

雨以 `7.0 m/s` 的速度竖直下落。汽车加速到 `20.0 m/s`。从车内观察，雨丝与竖直方向成多大角度倾斜？

**选项：**

1. `19.3°`
2. `55.0°`
3. `70.7°`
4. `35.0°`

**正确答案：** 3. `70.7°`

**解析：**

<i>v</i><sub>RC</sub> = <i>v</i><sub>RG</sub> + <i>v</i><sub>GC</sub>：向下 `7.0 m/s`，加上向后的 `20.0 m/s`，两者互相垂直。以竖直方向为基准，对边是水平分量：

<div class="eq">tan θ = 20.0 / 7.0，&nbsp;θ = 70.7°</div>

`19.3°` 是与**水平方向**的夹角。

### 题目 7.2

对于一名乘坐以 `10.0 m/s` 向前行驶的汽车的乘客，道路的速度是多少？

**选项：**

1. `10.0 m/s`，向后
2. `10.0 m/s`，向前
3. 零：道路是参考系
4. `12.21 m/s`，倾斜方向

**正确答案：** 1. `10.0 m/s`，向后

**解析：**

交换下标会使矢量反向：<i>v</i><sub>GC</sub> = −<i>v</i><sub>CG</sub>。相对于道路，汽车以 `10.0 m/s` 向前运动，因此相对于汽车，道路以 `10.0 m/s` 向后运动。选择哪个物体作为参考系是选择，而不是事实。

## 第 8 页

### 题目 8.1

水流速度增大到 `2.0 m/s`。船相对于水的速度仍为 `2.5 m/s`，船头正对着宽 `24 m` 的河流，方向笔直横渡。需要多长时间才能渡河？

**选项：**

1. `7.50 s`
2. `16.0 s`
3. `5.33 s`
4. `9.60 s`

**正确答案：** 4. `9.60 s`

**解析：**

只有速度的横向分量能把船带到对岸，而水流没有横向分量。因此

<div class="eq"><i>t</i> = <i>w</i> / <i>v</i><sub>b</sub> = 24 / 2.5 = 9.60 s</div>

这与之前相同；更强的水流只会使船向下游漂得更远（`19.2 m`）。用完整速度 `3.20 m/s` 去相除，是用斜线路径的速率来计算笔直横渡的距离。

### 题目 8.2

回到流速为 `1.5 m/s` 的河流：为了让一艘速度为 `2.5 m/s` 的船正好在正对岸登陆，它必须从笔直横渡方向向上游偏转多少度？

**选项：**

1. `31.0°`
2. `36.9°`
3. `53.1°`
4. `59.0°`

**正确答案：** 2. `36.9°`

**解析：**

船速的上游分量必须抵消水流。船自身的速度是斜边：

<div class="eq"><i>v</i><sub>b</sub> sin θ = <i>v</i><sub>w</sub> &nbsp;→ sin θ = 1.5 / 2.5，θ = 36.9°</div>

令 tan θ = `1.5`/`2.5`，相当于把 `2.5 m/s` 当成横向分量；但 `2.5 m/s` 是船相对于水的完整速度。

## 第 9 页

### 题目 9.1

汽车从静止开始，具有 <i>a</i> = `6.0` − `1.5`<i>t</i>（单位为 m/s²，<i>t</i> 以 s 计）的加速度。它在 <i>t</i> = `2.00 s` 时的速率是多少？

**选项：**

1. `6.00 m/s`
2. `12.0 m/s`
3. `9.00 m/s`
4. `3.00 m/s`

**正确答案：** 3. `9.00 m/s`

**解析：**

<i>a</i> 不是常量，因此要积分：

<div class="eq"><i>v</i>(<i>t</i>) = ∫<sub>0</sub><sup><i>t</i></sup> (6.0 − 1.5<i>t</i>′) d<i>t</i>′ = 6.0<i>t</i> − 0.75<i>t</i>²</div>

<div class="eq"><i>v</i>(2.00) = 12.0 − 3.0 = 9.00 m/s</div>

`6.00 m/s` 忘记了对 <i>t</i> 积分时产生的 ½；`12.0 m/s` 把 <i>a</i> 当成恒定的 `6.0 m/s²`。

### 题目 9.2

对于同一辆汽车（<i>a</i> = <i>a</i><sub>0</sub> − <i>kt</i>，直到加速度变为零，之后为 0；汽车从 <i>x</i> = 0 处静止开始），证明当加速度变为零时它已经走过 <i>x</i><sub>1</sub> = <i>a</i><sub>0</sub>³/3<i>k</i>²，并求它在 <i>t</i> = `5.00 s` 时的位置。

**解答：**

1. 当 <i>a</i> = 0 时，<i>t</i><sub>1</sub> = <i>a</i><sub>0</sub>/<i>k</i> = `4.00 s`。

2. <i>v</i> = ∫<sub>0</sub><sup><i>t</i></sup><i>a</i> d<i>t</i>′ = <i>a</i><sub>0</sub><i>t</i> − ½<i>kt</i>²，因此 <i>v</i><sub>1</sub> = <i>a</i><sub>0</sub>²/2<i>k</i> = `12.0 m/s`。

3. <i>x</i> = ∫<sub>0</sub><sup><i>t</i></sup><i>v</i> d<i>t</i>′ = ½<i>a</i><sub>0</sub><i>t</i>² − <i>kt</i>³/6。在 <i>t</i><sub>1</sub> 时：

<div class="eq"><i>x</i><sub>1</sub> = <i>a</i><sub>0</sub>³/2<i>k</i>² − <i>a</i><sub>0</sub>³/6<i>k</i>² = <i>a</i><sub>0</sub>³/3<i>k</i>² = 6.0³ / (3 × 1.5²) = 32.0 m</div>

4. 在 <i>t</i><sub>1</sub> 之后，<i>a</i> = 0，因此 <i>v</i> 保持为 `12.0 m/s`：

<div class="eq"><i>x</i>(5.00) = 32.0 + 12.0 × (5.00 − 4.00) = 44.0 m</div>

## 第 10 页

### 题目 10.1

一个粒子的运动为 <i>x</i> = <i>t</i>³ − 3<i>t</i>（单位为 m、s）。在其速度为零的瞬间（<i>t</i> &gt; 0），它的加速度是多少？

**选项：**

1. `6.00 m/s²`
2. `0 m/s²`
3. `−2.00 m/s²`
4. `3.00 m/s²`

**正确答案：** 1. `6.00 m/s²`

**解析：**

<i>v</i> = d<i>x</i>/d<i>t</i> = 3<i>t</i>² − 3 = 0，在 <i>t</i> = `1.00 s` 时成立。<i>a</i> = d<i>v</i>/d<i>t</i> = 6<i>t</i> = `6.00 m/s²`。

速度为零并不意味着加速度为零：粒子正在转向，因此它的速度正在改变。（−`2.00 m` 是它此时的位置。）

### 题目 10.2

一个粒子具有 <i>a</i> = 6<i>t</i>（单位为 m/s²），且 <i>v</i>(0) = −3 m/s、<i>x</i>(0) = 0。求 <i>x</i>(<i>t</i>)、它回到 <i>x</i> = 0 时的时间 <i>t</i> &gt; 0，以及此时的速度。

**解答：**

1. 积分一次：<i>v</i> = 3<i>t</i>² + <i>C</i><sub>1</sub>；由 <i>v</i>(0) = −3 得 <i>C</i><sub>1</sub> = −3。

2. 再积分一次：<i>x</i> = <i>t</i>³ − 3<i>t</i> + <i>C</i><sub>2</sub>；由 <i>x</i>(0) = 0 得 <i>C</i><sub>2</sub> = 0。

3. <i>x</i> = <i>t</i>(<i>t</i>² − 3) = 0，在 <i>t</i> = √3 = `1.73 s` 时（除去 <i>t</i> = 0）回到原点。

<div class="eq"><i>v</i>(√3) = 3(3) − 3 = 6.00 m/s</div>

它先向左运动，在 `1 s` 时到达 <i>x</i> = −`2 m`，随后向右返回，且速度比开始时更大。
