# 第 13 章：电路

> 以下是 Atlas of Physics **Circuits** 章节的非官方简体中文翻译。交互式图表和场景中的动态量会随时间或交互状态变化；本译文保留原公式、符号、变量名、单位和数值。

## 电流（Current）

*电荷的运动*

> 电池使两个端子保持固定的电势差。用导线将它们连接起来，金属内部的电场就会推动自由电荷沿导线运动：这就是**电流**。

\[
I = \frac{d q}{d t} = nqAv_d,\qquad J = \frac{I}{A} = nqv_d = \sigma E
\]

1 A = 1 C/s；这里把电流计数为仿佛**正**电荷在移动，而电子则向相反方向漂移。一块长度为 \(\Delta x = v_d\Delta t\) 的薄层中含有 \(nqA\Delta x\) 的电荷，这些电荷都会在 \(\Delta t\) 内穿过面积 \(A\)。一般来说，

\[
I = \int \mathbf{J}\cdot d\mathbf{A}.
\]

| 条目 | 数值 |
|---|---:|
| 铜中 1 mm² 截面上的 1 A：\(n\) | `8.5 × 10²⁸ m⁻³` |
| 漂移速度 \(v_d\) | `0.074 mm/s` |

每个电子都会加速，撞上离子后停止，然后重新开始（德鲁德模型），平均漂移速度为 \(v_d\)：每米需要 `3.8 h`。尽管如此，灯仍会立即亮起，因为电场会沿导线快速传播。

**图表：** 一个电子的锯齿形速度，平均值为漂移速度。横轴：时间（碰撞次数）；纵轴：一个电子的速度 / \(v_d\)。

> 点击导线，查看穿过 \(A\) 的薄层。绘制尺寸为实际尺寸的 `800×`；漂移速度为实际情况的 `10×`。

**图注：** 电子逆着电流方向漂移。

### 交互场景：导线

蓝色薄层是位于点 \(A\) 与上游距离 \(\Delta x = v_d\Delta t\) 之间的导线。薄层中的每个电子都会在 \(\Delta t\) 内穿过 \(A\)，因此通过 \(A\) 的电荷为 \(nqA\Delta x\)，电流为 \(nqAv_d\)。

| 量 | 数值 |
|---|---:|
| 薄层长度 \(\Delta x\) | `Δx = v_dΔt（图示长度 1.5 个单位）` |
| 穿过时间 \(\Delta t = \Delta x/v_d\) | `Δt（随所选薄层而变）` |
| 其中的电荷 \(nqA\Delta x\) | `Q = nqAΔx（随薄层而变）` |
| \(I = Q/\Delta t\) | `I = Q/Δt（由模型保持为 1.00 A）` |
| 碰撞之间的时间 | `约 25 fs` |

## 13.1 电阻（Resistance）

*越长越细，电阻越大*

> **电阻** \(R = \Delta V/I\)，单位为欧姆（V/A），表示推动电流通过某物有多困难。

\[
R = \rho\frac{L}{A} = \frac{L}{\sigma A}
\]

材料决定**电阻率** \(\rho = 1/\sigma\)（铜 `1.68 × 10⁻⁸`，镍铬 `1.10 × 10⁻⁶` Ω·m）；形状决定 \(L/A\)。长度加倍，相当于两个串联的部分，电阻加倍。直径加倍，相当于四股并排的导线，电阻变为四分之一。

直径为 `0.5` 和 `1.0` mm 的镍铬线两端各加 1.5 V。两根线中的载流子漂移速度相同（相同的 \(E = \Delta V/L\)）；粗线中的载流子数量是四倍。

**图表：** 两种直径的导线中，电阻随长度变化。横轴：长度 \(L\)（m）；纵轴：\(R\)（Ω）；曲线标为 \(d\) 和 \(2d\)。

> 点击，将粗导线分成四股。每米长度为 `200` cm；厚度经过放大。

**图注：** 同样的 1.5 V，不同的形状。

### 交互场景：导线

粗导线分解成四股细导线，每股都与细导线相同。四条相等的并行路径在相同电压下承载四倍电流，因此电阻为四分之一。

| 量 | 数值 |
|---|---:|
| 长度 \(L\) | `L（随动画状态变化，范围 0.5–2.0 m）` |
| 细线：\(R = \rho L/A\) | `R = ρL/A；I = 1.5/R（均随 L 变化）` |
| 粗线：\(R/4\) | `R/4；I = 1.5/R（均随 L 变化）` |
| \(\rho\)（镍铬） | `1.10 × 10⁻⁶ Ω·m` |

## 13.2 欧姆定律（Ohm’s law）

*\(V = IR\)*

对于欧姆导体，电流与其两端的电压成正比；这个比例就是它的电阻。

从金属中的欧姆定律 \(J = \sigma E\) 出发，其中沿导线方向的 \(E = \Delta V/L\)：

\[
I = JA = \sigma A\frac{\Delta V}{L}\quad\Longrightarrow\quad \Delta V = IR
\]

`6` V 加在 `3` Ω 两端，会驱动 `2.0` A 的电流。图中每一点的高度表示该点的电势：电池将电荷提升 `6` V，理想导线保持水平，而电阻则是一段向下的斜坡。沿电流方向通过电阻时，你会**损失**电势。

**图表：** 3 Ω 电阻中的电流随电压变化：一条直线。横轴：\(\Delta V\)（V）；纵轴：\(I\)（A）；斜率为 \(1/R\)。标记点：`6 V，2.0 A`。

> 点击查看电阻中的电场。`高度标尺：每格代表 5 V`

**图注：** 向上经过电池，向下经过电阻。

### 交互场景：欧姆电阻

蓝色箭头表示电阻中的电场，方向沿斜坡向下。在理想导线中没有斜坡，因此不需要电场：电阻为零，电压也为零。全部 `6` V 都消耗在电阻上。

| 绕一圈 | `0 V` |

## 13.3 功率（Power）

*\(P = I\Delta V\)*

> 每一库仑电荷在电池中获得 \(\Delta V\) 焦耳的能量，并在电阻中以热的形式释放；在灯泡中，还会以光的形式释放。

\[
P = \frac{dU}{dt} = I\Delta V = I^2R = \frac{\Delta V^2}{R}
\]

后两个表达式使用 \(\Delta V = IR\)：当你知道电流（串联）时使用 \(I^2R\)；当你知道电压（并联）时使用 \(\Delta V^2/R\)。单位是瓦特，J/s。

| 表达式 | 数值 |
|---|---:|
| \(I\Delta V\) | `0.50 A × 12 V = 6.0 W` |
| \(I^2R\) | `(0.50 A)² × 24 Ω = 6.0 W` |
| \(\Delta V^2/R\) | `(12 V)² / 24 Ω = 6.0 W` |

能量 \(E = Pt\)：每 `10` s 为 `60` J。

**图表：** 能量随时间增加：斜率为 \(P\) 的直线。横轴：时间（s）；纵轴：能量（J）；斜率 \(P = 6 W\)。

> 点击灯泡，移除玻璃。

**图注：** 六瓦特的热与光。

### 交互场景：灯泡

玻璃罩下是一圈细钨丝：这是一个会热到发光的电阻。电路中的灯泡不过就是 `24` Ω。

| 量 | 数值 |
|---|---:|
| \(P = I\Delta V\) | `6.0 W` |
| \(P = I^2R\) | `6.0 W` |
| \(P = \Delta V^2/R\) | `6.0 W` |
| 目前的能量 \(E = Pt\) | `E = Pt（随运行时间 t 增加）` |

## 13.4 电动势（Emf）

*一块真实的电池*

> **电动势** ℰ 是电池的化学反应给予每一库仑电荷的能量。尽管名称中有“力”，它并不是一种力。

真实电池具有**内电阻** \(r\)，电流在电池内部损失 \(Ir\)：

\[
\Delta V_{\text{terminal}} = \mathcal{E} - Ir,\qquad I = \frac{\mathcal{E}}{R+r}
\]

这里 ℰ = `12` V，\(r = 2\) Ω，灯泡的 \(R\) 在 `0.5`–`8` Ω 之间变化。电流越大，端电压越低，而 \(I^2r\) 会使电池发热。灯泡获得的功率为 \(\mathcal{E}^2R/(R+r)^2\)；在 \(R = r\) 时 \(dP/dR = 0\)，此时灯泡最亮：

\[
\frac{\mathcal{E}^2}{4r} = 18 W.
\]

**图表：** 负载功率随负载电阻变化，在 \(R = r\) 处达到峰值。横轴：负载 \(R\)（Ω）；纵轴：灯泡获得的功率（W）。

> 点击电池，将其打开。`高度标尺：每格代表 5 V`

**图注：** 电动势 12 V，内电阻 2 Ω。

### 交互场景：电池

内部包含一个理想的 `12` V 电动势和一个 `2` Ω 的串联电阻。将电池升起后，电池把电荷提升 `12` V；到达端子前，内电阻通过 \(Ir\) 将这部分电势降低回来。

| 量 | 数值 |
|---|---:|
| 负载 \(R\) | `R（随动画状态变化，范围 0.5–8 Ω）` |
| 电流 \(I = ℰ/(R + r)\) | `I = 12/(R + 2)（随 R 变化）` |
| 内部损失 \(Ir\) | `Ir（随 I 变化）` |
| 端电压 \(\Delta V = ℰ − Ir\) | `ΔV = 12 − Ir（随 I 变化）` |
| 灯泡功率 | `P = I²R（随 R 变化）` |
| 内部浪费的功率 \(I^2r\) | `I²r（随电流变化，单位 W）` |

## 13.5 串联与并联（Series and parallel）

*一条路径，或并排的路径*

> **串联**时，电流只有一条路径，因此通过每个电阻的电流相同，电压相加。**并联**时，每个支路都跨接在同两个点之间，因此电压相同，电流相加。

\[
R_s = R_1 + R_2,\qquad \frac{1}{R_p} = \frac{1}{R_1} + \frac{1}{R_2} + \dots
\]

| 串联，9 V | 并联，9 V |
|---|---|
| \(R_{eq} = 2 + 4 = 6\) Ω | \(R_{eq} = 1.091\) Ω |
| \(I = 9/6 = 1.5\) A | \(I_1 = 9/2 = 4.5\) A |
| \(\Delta V_1 = 1.5 × 2 = 3\) V | \(I_2 = 9/4 = 2.25\) A |
| \(\Delta V_2 = 1.5 × 4 = 6\) V | \(I_3 = 9/6 = 1.5\) A |
| \(3 + 6 = 9\) V ✓ | \(I = 8.25\) A ✓ |

串联更多电阻会提高 \(R_{eq}\)；并联更多电阻会降低 \(R_{eq}\)，使其低于最小的支路电阻。在并联电路中，小点会沿导轨加速，支路电流在那里汇合。

> 点击任一电路将其升起。点的速度 ∝ 电流（并联时每安培的速度是串联时的 `0.3×`）。

**图注：** 2 Ω 和 4 Ω；2 Ω、4 Ω 和 6 Ω。

### 交互场景：串联

电池升高后提供 9 V，电流依次沿两段斜坡下降：经过 2 Ω 电阻下降 3 V，经过 4 Ω 电阻下降 6 V。电阻越大，分到的电压越多。

| 量 | 数值 |
|---|---:|
| \(R_{eq}\) | `6 Ω` |
| \(I\)（处处相同） | `1.5 A` |
| \(\Delta V_1\) | `3.0 V` |
| \(\Delta V_2\) | `6.0 V` |
| 总和 | `9.0 V` |

### 交互场景：并联

升高后，左导轨处于 9 V，右导轨处于 0 V，因此每个支路都下降完整的 9 V。每个支路取走自己的电流，即 \(\Delta V/R\)；导轨承载电流总和。

| 量 | 数值 |
|---|---:|
| 每个支路上的 \(\Delta V\) | `9.0 V` |
| \(I_1\)（2 Ω） | `4.50 A` |
| \(I_2\)（4 Ω） | `2.25 A` |
| \(I_3\)（6 Ω） | `1.50 A` |
| 电池电流 | `8.25 A` |
| \(R_{eq}\) | `1.091 Ω` |

## 13.6 组合电路（Combinations）

*先化简，再反向求解*

> 一个由串联和并联部分组成的电路，可以逐步化简为一个等效电阻。然后对每个电压和电流反向求解。

1. \(R_2\)、\(R_4\)、\(R_5\) 中通过同一个电流：串联时，\(4 + 2 + 2 = 8\) Ω。
2. \(R_3\) 与那个 `8` Ω 电阻跨接在同两个点之间：并联时，\(1/(½ + ⅛) = 1.6\) Ω。
3. \(R_1\) 与其串联：\(R_{eq} = 2 + 1.6 = 3.6\) Ω，因此 \(I = 9/3.6 = 2.5\) A。

| 反向求解 | \(\Delta V\) | \(I\) |
|---|---:|---:|
| \(R_1\) | 2.5 × 2 = 5 V | 2.5 A |
| \(R_3\)（并联部分） | 9 − 5 = 4 V | 4/2 = 2.0 A |
| \(R_2\)、\(R_4\)、\(R_5\) | 2、1、1 V | 4/8 = 0.5 A |

每个阶段都取 2.5 A：这就是“等效”的含义。（学习组织者写的是 \(R_{245} = 10\) Ω 和 3.667 Ω；但按图中标注，\(4 + 2 + 2 = 8\) Ω。）

> 点击完整电路（1）将其升起。

**图注：** 五个电阻化为一个。

### 交互场景：组合电路

升高后，先在 \(R_1\) 上下降 5 V；剩余的 4 V 同时沿两条路径下降：要么一次性经过 \(R_3\)，要么分三步经过 \(R_2\)、\(R_4\)、\(R_5\)，分别下降 2、1 和 1 V。

| 量 | 数值 |
|---|---:|
| \(R_{eq}\) | `3.6 Ω` |
| 电池电流 | `2.5 A` |
| \(R_1\) 两端 | `5.0 V` |
| \(R_3\) 两端 | `4.0 V, 2.0 A` |
| \(R_2\)、\(R_4\)、\(R_5\) | `2.0、1.0、1.0 V，电流为 0.5 A` |

## 13.7 基尔霍夫定律（Kirchhoff’s rules）

*守恒的电荷与能量*

> 两个电池位于不同支路时，不能化简为一个电阻。基尔霍夫的两条定律始终适用。

- **节点定律**（电荷守恒）：流入 = 流出。在 A 点，\(I_1 = I_2 + I_3\)。
- **回路定律**（能量守恒）：沿任意回路，\(\Sigma\Delta V = 0\)。沿电流通过电阻时为 \(-IR\)；沿电池从 − 到 + 时为 \(+ℰ\)。

\[
1:\quad -10I_1 - 5I_2 - 10I_1 + 12 = 0
\]

\[
2:\quad -20I_3 + 6 - 20I_3 + 5I_2 = 0
\]

所以 \(I_1 = 0.52\) A，\(I_2 = 0.33\) A，\(I_3 = 0.19\) A，这就是学习组织者给出的答案。这里需要将 6 V 电池的正端置于底部，正如本图所示。学习组织者的图纸把正端画在顶部：这样，回路 2 中就是 −6，且 \(I_3 = −0.082\) A，电流方向相反。

> 点击将其升起，并沿每个回路走一遍。`高度标尺：每格代表 5 V`

**图注：** \(I_1 = I_2 + I_3\)；每个回路中 \(\Sigma\Delta V = 0\)。

### 交互场景：基尔霍夫电路

## 13.8 RC 电路（RC circuits）

*充电与放电*

> 在 **a** 状态，电池通过 \(R\) 给电容器充电；在 **b** 状态，电容器通过 \(R\) 将电流推回去，直到电容器放空。

\[
ℰ - IR - \frac{q}{C} = 0,\qquad I = \frac{dq}{dt}
\]

\[
q = ℰC\left(1 - e^{-t/RC}\right)
\]

（分离变量：\(\int dq/(ℰC - q) = \int dt/RC\)。）

\[
I = \frac{ℰ}{R}e^{-t/RC}
\]

\[
τ = RC = 2.0\ \text{s}
\]

经过一个 \(τ\) 后，\(q\) 达到 ℰ\(C\) 的 63.2%，即 `1.2` mC；\(I\) 降至 ℰ/\(R\) 的 36.8%，即 `0.6` mA。放电时，

\[
q = Q_{\max}e^{-t/RC}.
\]

电容器为空时表现得像导线；充满时表现得像断路。电池提供的 \(Qℰ = 14.4\) mJ 能量中，一半储存起来，另一半变成热。

**图表：** 充电和放电时，电荷与电流随时间的变化。横轴：时间（s）；纵轴：最大值的百分比；曲线标为 \(q\) 和 \(I\)，标记为 63.2% 和 36.8%。

> 点击将其升起：随着 \(\Delta V_C\) 增大，\(\Delta V_R\) 变小。

**图注：** 20 kΩ、100 µF：\(τ = 2.0\) s。

### 交互场景：RC 电路

升高后，电池提升 12 V；电阻的斜坡表示 \(IR\)，电容器的台阶表示 \(q/C\)。充电时，电阻分到的电压随着电容器分到的电压增加而减小；两者的和始终为 12 V。放电时，电池被切出，电容器的电压台阶推动电流反向流动。

| 量 | 数值 |
|---|---:|
| 开关 | `a: charging` 或 `b: discharging` |
| 切换后的时间 | `s（切换后的经过时间，随动画变化）` |
| \(q\) | `q = Q(t)（随时间变化，单位 mC；百分比为 100q/Q_max）` |
| \(I\) | `I(t)（随时间变化，单位 mA）` |
| \(\Delta V_R\) | `|ΔV_R|（随时间变化）` |
| \(\Delta V_C\) | `ΔV_C = q/C（随时间变化）` |
| 储存的 \(q^2/2C\) | `q²/(2C)（随时间变化，单位 mJ）` |
