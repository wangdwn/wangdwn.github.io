# 第 12 章：电容器

> **非官方简体中文翻译**。本译文依据 [Atlas of Physics 原始源文件](https://raw.githubusercontent.com/nathanliow/atlas-of-physics/main/capacitors/pages.js) 制作，仅供学习参考。

## 电容器

### 分开存放的电荷

**电容器**是彼此分开的两个导体。电池把电荷从一个导体移到另一个导体上，使两者分别留下 `+Q` 和 `−Q`，中间形成电场。

电压加倍，电荷也加倍。它们的比值——**电容**——保持不变：

\[
C = Q / \Delta V
\]

单位是法拉（`1 F = 1 C/V`），且绝不会为负。它只取决于**几何形状**以及间隙中的材料。这两块极板是边长 `20 cm` 的正方形，相距 `5 cm`：`C = 7.1 pF`。

## 12.1 平行极板

### 先用高斯定律，再求 ΔV，最后求 C

每次都分三步：用高斯定律求 `E`，通过积分求 `ΔV`，再求 `C = Q/ΔV`。

| 方程 | 说明 |
|---|---|
| `EA = σA/ε₀` | 小药盒（pillbox） |
| `E = σ/ε₀ = Q/(ε₀A)` | 均匀 |
| `ΔV = −∫_d^0 E ds = Ed` | `E` 为常量 |
| `C = Q/ΔV = ε₀A/d` | `Q` 相消 |

间隙变化时 `Q` 保持不变：`E` 保持为 `2000 V/m`，`ΔV = Ed` 增大，而 `C` 按 `1/d` 减小。

**图表：** 电容—间隙；横轴 `gap d (cm)`，纵轴 `C (pF)`。

> 点击小药盒，把它拉出来。

*图注：电荷相同，间隙发生变化*

## 12.2 两个球

### 壳内的球

一个球（`a = 10 cm`，`+Q`）位于一个壳（`b = 20 cm`，`−Q`）内，壳被切成两半。

| 方程 | 说明 |
|---|---|
| `E·4πr² = Q/ε₀` | 高斯定律，`a < r < b` |
| `ΔV = −∫_b^a Q dr/(4πε₀r²)` | `E·ds = E dr` |
| `= Q(b − a)/(4πε₀ab)` |  |
| `C = 4πε₀ab/(b − a)` | `22.2 pF` |

当 `b → ∞` 时，`C → 4πε₀a`，这就是一个孤立球。阴影部分表示：`ΔV = 100 V`。

**图表：** 半径方向的电场，在间隙外为零；横轴 `r (cm)`，纵轴 `E (V/m)`。

> 点击以打开壳。箭头每 `kV/m` 对应 `2 cm`。

*图注：壳层之间 `E ∝ 1/r²`*

## 12.3 两个圆柱

### 管内的杆

一根杆（`a = 2 cm`）位于一根管（`b = 8 cm`）内，长度为 `L = 40 cm`：这是一段短同轴电缆。

| 方程 | 说明 |
|---|---|
| `E·2πrL = Q/ε₀` | 高斯定律，只取侧面 |
| `ΔV = −∫_b^a Q dr/(2πε₀rL)` | `E·ds = E dr` |
| `= (Q/2πε₀L) ln(b/a)` | `∫dr/r = ln r` |
| `C = 2πε₀L/ln(b/a)` | `16.0 pF` |

`E ∝ 1/r`，比 `1/r²` 更缓，因此出现对数。`C ∝` 长度：每米 `40 pF`。

**图表：** 同轴组合的电场—半径关系；横轴 `r (cm)`，纵轴 `E (V/m)`。

> 点击以把管滑开。箭头每 `kV/m` 对应 `1 cm`。

*图注：管内 `E ∝ 1/r`*

## 12.4 储存的能量

### 充电所做的功

每一小份 `dq` 都要逆着已经存在的电场，从 `−` 搬到 `+`，经过 `ΔV = q/C`。最初的几份电荷不花功；最后一份要付出全部 `100 V` 的电压代价。

\[
U = \int_0^Q \frac{q}{C}\,dq = \frac{Q^2}{2C}
\]

\[
= \frac12Q\Delta V = \frac12C\Delta V^2
\]

这是直线下方的三角形面积；在这里为 `35.4 nJ`。能量存在于电场中，形成能量密度（`J/m³`）：

\[
u = \frac12\varepsilon_0E^2
\]

**图表：** 电压—移动电荷；曲线下的面积就是储存的能量。横轴 `charge moved q (pC)`，纵轴 `ΔV (V)`。

> 间隙中的蓝色会随着 `u` 增大而变深。点击极板。

*图注：一次移动一小份电荷进行充电*

## 12.5 串联与并联

### 相同的 Q，或相同的 ΔV

`2 µF` 和 `4 µF` 接在 `9 V` 电源上。极板面积按 `C` 的比例绘制；一个刻度代表 `2 µC`。

| 串联 | 并联 |
|---|---|
| 每个电容器上的 `Q` 相同 | 每个电容器上的 `ΔV` 相同 |
| `ΔV = ΔV₁ + ΔV₂` | `Q = Q₁ + Q₂` |
| `1/C_eq = 1/C₁ + 1/C₂` | `C_eq = C₁ + C₂` |
| `1.33 µF：6 V + 3 V` | `6 µF：18 + 36 µC` |

串联时，连接它们的导线是一个中性孤岛：一端是 `+Q`，意味着另一端是 `−Q`。较小的电容器承担更多电压；并联时，较大的电容器承担更多电荷。

**图表：** 每个电容器上的电荷，比较串联和并联。串联：相同 `Q`；并联：`Q` 相加。

> 点击电路查看其电荷和电压。

*图注：`2 µF` 和 `4 µF` 接在 `9 V` 上*

## 12.6 电介质

### 间隙中的绝缘体

间隙中的绝缘体会发生**极化**：每个分子偶极子受到力矩 `τ = p×E = pE sin θ`，并朝向能量最低的方向 `U = −p·E` 转动。

排列整齐的两端会在表面留下**束缚电荷**；它产生的电场 `E_ind` 与极板的电场相反：

\[
E = E_0 - E_{ind} = E_0/\kappa
\]

在 `Q` 固定时，`ΔV` 降低 `κ` 倍，而 `C = κε₀A/d` 增大 `κ ≥ 1` 倍。

**图表：** 电场—电介质板插入间隙的程度；横轴 `fraction of the gap filled`，纵轴 `E (V/m)`；标记 `E₀/κ`。

*图注：`κ = 3` 的电介质板，极板彼此隔离*

## 12.7 是否连接

### 电池保持什么量不变

部分插入时，电介质板和旁边的空气相当于两个并联电容器：

\[
C = C_0(1 + (\kappa - 1)x)
\]

插入一半时：

\[
C_0/2 \cdot (1 + \kappa)
\]

| 电介质板完全插入 | 已连接 | 已断开 |
|---|---|---|
| 保持不变的量 | `ΔV = 100 V` | `Q = 708 pC` |
| `Q` | `κQ₀ = 2124 pC` | `Q₀` |
| `ΔV`、`E` | 不变 | 除以 `κ`（`33.3 V`） |
| `U` | 乘以 `κ`（`106.2 nJ`） | 除以 `κ`（`11.8 nJ`） |

已连接时，电荷会流到电介质板所在的一侧；电池做功 `ΔV·ΔQ`，这正好是储存能量增加量的两倍。无论哪种情况，极板都会把电介质板吸入。

**图表：** 储存能量—填充比例，比较已连接和已断开的情况；纵轴 `U/U₀`。

> 点击任意一个电容器。

*图注：电池接通（左），断开（右）*

## 12.8 导体

### 静电平衡中

一个中性金属球处在 `1000 V/m` 的电场中。它的自由电子漂移，直到电子自身产生的电场在金属内部抵消外部电场。此时：

- 金属内部处处 `E = 0`；
- 任何电荷都位于表面；
- 紧贴表面外侧，`E ⊥` 表面，且 `E = σ/ε₀`；
- 整个导体处于同一个电势。

这里 `σ = 3ε₀E₀ cos θ`，总和为零；在两极处 `E = 3E₀`。电容器中厚度为 `t` 的金属板会留下两个串联间隙：

\[
C = \frac{\varepsilon_0A}{d-t}
\]

**图表：** 沿穿过球的轴线的电场；横轴 `along the axis (cm)`，纵轴 `E (V/m)`。

> 点击球将其切开。电场线根据模型描绘。

*图注：处于电场中的中性金属球*

# 交互场景说明

以下文字对应源文件中点击各场景后显示的解释与数据标签；公式、符号、单位和变量名保持不变。

## 极板（`plates`）

每块极板单独产生大小为 `σ/2ε₀` 的电场：电场从 `+` 指向外，并指向 `−`（灰色）。在两极板之间，两者方向相同，相加为 `σ/ε₀`。在外部，两者方向相反并相互抵消。这就是为什么电场全部位于间隙中。

数据标签：

- `ΔV`：电压变量 `V(t)`，随充放电动画在 20–100 V 间变化；
- `Q = CΔV`：电荷变量 `Q(t)`，单位 pC，随 `V(t)` 变化；
- `each plate σ/2ε₀`：每块极板的场强为 `E(t)/2`，单位 V/m；
- `between: sum`：间隙中的总场强为 `E(t)`，单位 V/m；
- `outside: difference`：`0 V/m`。

## 小药盒（`pillbox`）

小药盒跨过 `+` 极板。它的外侧面处在零电场中，侧面沿着电场方向，因此唯一的通量是穿过间隙中那个面的 `E·A`。盒内的电荷是 `σA`。由高斯定律：`EA = σA/ε₀`。

数据标签：`face area A`、`flux E·A`、`q_enc/ε₀`、`gap d`、`ΔV = Ed`、`C = ε₀A/d`；数值随交互动画变化；分别表示高斯面面积、通量、包围电荷、间隙、ΔV 和 C，单位沿用图中标注。

## 球（`sphere`）

打开壳后，可以看到球以及位于两者之间的高斯球面。无论它的半径是多少，穿过它的通量都相同，均为 `Q/ε₀`，所以 `E` 按 `1/r²` 减小。

数据标签：`Gaussian radius r`、`E(r) = Q/4πε₀r²`、`flux E·4πr²`、`Q/ε₀`。

## 同轴结构（`coax`）

把管移到一旁，就能看到杆和高斯圆柱。通量只通过面积为 `2πrL` 的弯曲侧面流出，所以 `E = Q/2πε₀rL`，并按 `1/r` 减小。

数据标签：`Gaussian radius r`、`E(r)`、`flux E·2πrL`、`Q/ε₀`、`C`。

## 能量（`energy`）

能量分布在间隙的体积 `A × d` 中，能量密度为 `u = ½ε₀E²`。将两者相乘，就重新得到 `½CΔV²`。

数据标签：`E`、`u = ½ε₀E²`、`volume Ad`、`u·Ad`、`Q²/2C`。

## 串联（`series`）

电池让 `Q(t)`（以微库仑计，随串联动画变化） 的电荷沿回路移动。两个内侧极板以及它们之间的导线构成一个中性孤岛：一侧为 `−Q(t)`（以微库仑计），另一侧为 `+Q(t)`（以微库仑计）。每个电容器的电压都是 `Q/C`，两者相加得到 `9 V`。

数据标签：`C_eq`、`Q on each`、`ΔV₁ = Q/C₁`、`ΔV₂ = Q/C₂`、`energy ½C_eqV²`。

## 并联（`parallel`）

两个电容器都直接跨接在电池两端，因此每个电容器都承受完整的 `9 V`。每个电容器取得 `Q = CΔV`，而电池提供两者之和。

数据标签：`C_eq`、`ΔV on each`、`Q₁ = C₁ΔV`、`Q₂ = C₂ΔV`、`energy ½C_eqV²`。

## 电介质板（`slab`）

在电介质板内部，仅由极板上的自由电荷产生的电场为 `E₀`（右侧灰色）。电介质板表面的束缚电荷产生 `E_ind`（左侧灰色）。剩下的电场为 `E`（蓝色）；它在电介质板内和旁边的空气中相同，因为两者跨越相同的 `ΔV`。

数据标签：`slab in`、`E₀ = σ_free/ε₀ (slab part)`、`E_ind = σ_bound/ε₀`、`E = E₀ − E_ind`、`ΔV`、`C`。

## 电池（`battery`）

电池将 `ΔV` 保持在 `100 V`，因此 `E = ΔV/d` 不能改变。随着电介质板进入，电荷流到朝向电介质板的极板上，直到那里的电荷达到原来的 `κ` 倍。

数据标签：`C`、`Q`、`ΔV`、`E`、`U`。

## 隔离（`isolated`）

没有电荷能够流入或流出，因此 `Q` 保持不变。电荷向电介质板一侧重新分布，间隙中的电场处处减小，`ΔV` 也随之减小。

数据标签：`C`、`Q`、`ΔV`、`E`、`U`。

## 导体（`conductor`）

切开后可以看到：内部没有电荷，也没有电场，电荷只在表面。金属内部任意位置的高斯面上都有 `E = 0`，因此它包围的净电荷为零。中空壳也一样，这就是金属盒能够屏蔽内部物体的原因。

数据标签：`probe at`、`E there`、`E inside`、`σ at the poles`、`E at the poles = σ/ε₀`。
