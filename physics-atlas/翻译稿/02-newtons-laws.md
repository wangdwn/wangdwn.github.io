# 第 2 章：牛顿定律

## 改变运动的因素

运动学描述运动。动力学解释运动：**力**是推或拉，而力正是改变运动的因素。

力是一个矢量，从物体的中心画出箭头。1 牛顿是使 1 kg 物体获得 1 m/s² 加速度的力。这个 2.0 kg 方块受到两个力：

| 力 | 符号 | 此处的情况 |
|---|---|---|
| 重量（重力） | $F_g = mg$ | 19.6 N，向下 |
| 支持力（来自表面） | $F_N$ | 19.6 N，向上 |
| 张力（绳子） | $T$ | — |
| 摩擦力 | $f$ | — |
| 阻力（空气） | $F_d$ | — |

始终先画**受力图**：把物体画成一个点，把作用在它上的每个力画成箭头。点击方块查看。

## 2.1 张力

**张力** $T$ 是绳子或缆绳沿绳方向产生的拉力。绳子能拉，不能推。

左侧的 2.0 kg 方块悬挂在一根绳子上。它处于平衡状态，因此 $T = mg = 19.6\ \mathrm{N}$。

右侧两根绳子分担负载。只有它们的竖直分量托住方块，所以 $2T\sin\theta = mg$，并且

$$T = \frac{mg}{2\sin\theta}$$

绳子越趋于水平，$	heta$ 越小，张力越大：$
10.4\ \mathrm{N}$（70°）、$19.6\ \mathrm{N}$（30°）、$28.7\ \mathrm{N}$（20°）。这就是晾衣绳不可能被拉得完全笔直的原因。水平方向的分量彼此抵消。

## 2.2 第一定律

**惯性**

静止的物体保持静止，沿直线运动的物体保持同一速度运动，除非有非零的**合力**作用于它。

这个方块以 1.5 m/s 的速度在无摩擦表面上滑动。它的重量和支持力相互抵消，因此 $\Sigma F = 0$，没有任何东西改变它的运动。频闪图像之间的间距相等。

**平衡**意味着 $\Sigma F = 0$。这包括以恒定速度运动，而不只是静止。不需要任何东西来“维持”它的运动。

## 2.3 水平飞行

**运动着，但处于平衡状态**

一架质量为 1200 kg 的飞机以稳定的 55 m/s 速度水平、沿直线巡航。它的速度没有改变，因此根据第一定律，合力为零。

| 力 | 大小 |
|---|---:|
| 升力（向上，来自机翼） | 11.76 kN |
| 重量（向下） | 11.76 kN |
| 推力（向前，来自螺旋桨） | 1.80 kN |
| **阻力**（向后，来自空气） | 1.80 kN |

**阻力**是流体对穿过它运动的物体施加的力。它随速度增加，大致为 $F_d = ½D\rho Av^2$（$D$ 是阻力系数，$A$ 是迎流面积）。发动机不需要让飞机保持运动；它需要抵消阻力。

## 2.4 第二定律

**$\Sigma F = ma$**

合力会使物体沿合力方向产生加速度，其大小为 $\Sigma F/m$。

两个方块在无摩擦表面上都受到同样大小的 6.0 N 推力。2.0 kg 方块的加速度为 3.0 m/s²。质量为两倍的 4.0 kg 方块得到一半的加速度：1.5 m/s²。

力越大，加速度越大。质量越大，加速度越小。

## 2.5 是什么推动汽车？

**是道路在推动**

发动机转动车轮，但发动机是汽车的一部分，而任何东西都不能推动自己。汽车受到的向前力来自**道路**：轮胎上的静摩擦力。

轮胎向后推道路。根据第三定律，道路向前推轮胎，此处的力为 3.6 kN。轮胎没有打滑，所以这是**静摩擦力**，即使汽车正在运动也是如此。

空气阻力向后，并且随 $v^2$ 增长：在 9.6 m/s 时只有 36 N，但在高速公路速度（30 m/s）时为 351 N。汽车速度越快，合力以及加速度就越小。

## 2.6 摩擦力

**先是静摩擦，然后是动摩擦**

在粗糙地面上，推力稳定增加，每秒增加 4.0 N。开始时方块不动：**静摩擦力**恰好与推力相等。

静摩擦力有上限，$\mu_sF_N = 0.50 \times 19.6 = 9.80\ \mathrm{N}$。再用力推，方块就会开始滑动。随后由较小且稳定的 $\mu_kF_N = 5.88\ \mathrm{N}$ **动摩擦力**接管，无论推力多大。红色箭头，即合力，只在推力胜过摩擦力后出现。

## 2.7 第三定律

**力成对出现**

如果 A 推 B，那么 B 会在同一时刻以大小相同、方向相反的力推 A。

6.0 N 的推力使两个方块一起以 1.0 m/s² 加速。要让 B（4.0 kg）获得这个加速度，A 必须以 4.0 N 推它。B 以 4.0 N 推回 A，因此 A 上的合力为 $6.0 - 4.0 = 2.0\ \mathrm{N}$，这正好是 $2.0\ \mathrm{kg} \times 1.0\ \mathrm{m/s^2}$。

一对力作用在**不同物体**上，所以它们永远不会相互抵消。重量和支持力**不是**一对力：它们都作用在同一个方块上。方块重量的作用-反作用伙伴，是方块把地球向上拉。

*图注：A 推 B，B 推 A*

## 2.8 选择一个系统

**内力相互抵消**

在任意你喜欢的物体周围画一条边界，并把它们称为**系统**。系统内部事物之间的力是**内力**。来自系统外任何事物的力是**外力**。

滑冰者 A（50 kg）和滑冰者 B（75 kg）站在无摩擦的冰面上，收拢一根轻绳。绳子以 60 N 拉着他们每个人，因此 A 以 1.2 m/s²、B 以 0.8 m/s² 的加速度相向而行。

把滑冰者和绳子作为系统。张力是内力，并且成大小相等、方向相反的一对，所以相加为零。重量和支持力是外力，但它们相互抵消。整个系统不能加速。它的**质心**保持不动：

$$x_{cm} = \frac{\Sigma mx}{\Sigma m}$$

$$= \frac{m_Ax_A + m_Bx_B}{m_A + m_B}$$

|  | $x_A$ | $x_B$ | $x_{cm}$ |
|---|---:|---:|---:|
| 开始时 | −2.94 m | 1.96 m | 0.00 m |
| 1.67 s 后 | −1.26 m | 0.84 m | 0.00 m |

较轻的滑冰者滑过更远的冰面：1.7 m，相比之下另一人是 1.1 m，恰好保持 $x_{cm}$ 不变的比例。如果他们一开始就是一起滑行的，$x_{cm}$ 也会以同样的速度继续滑行。

## 2.9 质心加速

**$\Sigma F_{ext} = M a_{cm}$**

对系统的每个部分写出 $F = ma$，再把它们相加。内力成对抵消，剩下的就是整个系统的第二定律：

$$\Sigma F_{ext} = M a_{cm}, \qquad M = \Sigma m$$

一个 2.0 kg 方块放在冰面上的 4.0 kg 木板上，一根绳子以 18 N 拉木板。这超过了静摩擦力能够分担的大小（$\mu_sMg = 11.76\ \mathrm{N}$），所以方块发生滑动。2.94 N 的动摩擦力把方块向前拖、把木板向后拖。

| 部分 | 加速度 |
|---|---:|
| 方块：$f/m$ | 1.47 m/s² |
| 木板：$(F-f)/M_{board}$ | 3.77 m/s² |
| **系统**：$F/(m+M_{board})$ | 3.00 m/s² |

检验：$(2.0 \times 1.47 + 4.0 \times 3.77) / 6.0 = 3.00\ \mathrm{m/s^2}$。摩擦力从未影响 $a_{cm}$。从盘子下面猛地抽走桌布，也会发生同样的事：摩擦力是唯一拖动盘子的力，而它只能给盘子 $\mu g$ 的加速度。

## 2.10 斜面

**倾斜坐标轴**

在斜面上，沿斜面方向和垂直斜面方向测量。然后把重量分成两个部分。

| 方向 | 分量 |
|---|---:|
| 沿斜面 | $mg\sin\theta = 9.80\ \mathrm{N}$ |
| 指向斜面 | $mg\cos\theta = 16.97\ \mathrm{N}$ |

物体不会向斜面内加速，因此支持力抵消第二个分量：$F_N = mg\cos\theta = 16.97\ \mathrm{N}$。只剩下沿斜面的分量：$a = g\sin\theta = 4.90\ \mathrm{m/s^2}$。

加入摩擦力后，当 $\tan\theta = \mu_k$ 时，方块会以恒定速度滑动。对于 $\mu_k = 0.30$，角度为 16.7°。

## 2.11 · AP Physics C：与 $v$ 成正比的阻力

**终端速度**

阻力方向与速度相反，并且随速度增加。对于黏稠流体中的小而慢的物体，阻力简单地与速度成正比：$F_d = -bv$。

一个质量为 0.50 kg、$b = 1.25\ \mathrm{kg/s}$ 的球从静止释放。取向下为正：

$$m\frac{dv}{dt} = mg - bv$$

开始时 $v = 0$ 且 $a = g$。球加速时阻力增大，因此合力减小。当 $bv = mg$ 时合力为零：**终端速度** $v_t = mg/b = 3.92\ \mathrm{m/s}$。分离变量，并令 $\tau = m/b$：

$$\frac{dv}{v_t-v} = \frac{dt}{\tau}$$

$$\int_0^v \frac{dv'}{v_t-v'} = \int_0^t \frac{dt'}{\tau}$$

$$-\ln(1-v/v_t) = t/\tau$$

$$v(t) = v_t(1-e^{-t/\tau})$$

这里 $\tau = 0.40\ \mathrm{s}$。经过一个 $\tau$ 后，球达到 $v_t$ 的 $1 - 1/e = 63.2\%$；经过 $3\tau$ 后达到 95%；经过 $5\tau$ 后达到 99.3%。它永远不会完全达到终端速度。

## 2.12 · AP Physics C：真实流体

**位置，以及应使用哪一种阻力定律**

再积分一次，得到下落的位移：

$$x(t) = \int_0^t v\,dt' = v_t\left[t-\tau(1-e^{-t/\tau})\right]$$

经过几个 $\tau$ 后，这是 $v_t(t-\tau)$：球仿佛从一开始就以 $v_t$ 下落，只是晚了 $\tau$ 才开始（下图虚线）。

线性阻力适用于黏稠流体中的小而慢的物体。较大或较快的物体会把流体推开，阻力增长为 $kv^2$，就像第 2.5 节中的汽车。此时 $v_t = \sqrt{mg/k}$。

| 下落物体 | $v_t$ | $\tau$ | 阻力 |
|---|---:|---:|---|
| 雾滴，20 µm | 1.2 cm/s | 1.2 ms | $bv$ |
| 蜂蜜中的钢球，10 mm | 3.5 cm/s | 4.3 ms | $bv$ |
| 雨滴，2 mm | 6.6 m/s | — | $kv^2$ |

对于雨滴，$bv$ 会预测 121 m/s。实际上它以约 6.5 m/s 下落，正如 $kv^2$ 所预测的那样。

蜂蜜中的钢球（图中按实际大小的 10 倍绘制）还受到浮力 $B$，所以 $mg$ 变成 $mg-B$，且 $v_t = (mg-B)/b$。由于 $\tau$ 只有 4.3 ms，它在不到一毫米的时间尺度内就达到终端速度的一定程度，因此看起来像是一开始就匀速下沉。

# 交互场景说明

## 绳子系统（tug）

浅色方框是系统：两位滑冰者和绳子。作用在 A 上的张力和作用在 B 上的张力是内力；它们大小相等、方向相反，所以相加为零。每位滑冰者的重量都被冰面的支持力抵消。没有合外力，质心（四等分圆盘）不能移动。

| 量 | 数值 |
|---|---:|
| $x_A, v_A$ | 0.00 m，0.00 m/s |
| $x_B, v_B$ | 1.96 m，0.00 m/s |
| $x_{cm}=\Sigma mx/\Sigma m$ | 0.00 m |
| 内力：A 上的 $T$ + B 上的 $T$ | $60 - 60 = 0$ N |
| 外力：$\Sigma F_{ext}$ | 0 N |

## 木板系统（board）

抬开后，摩擦力对清晰可见：木板把方块向前拖，方块把木板向后拖，双方都是 2.94 N。在方块 + 木板系统内部，它们相互抵消。只有拉力 $F$ 是外力，所以质心以 $F/M$ 加速，数值处于方块和木板加速度之间。

| 量 | 数值 |
|---|---:|
| $\Sigma F_{ext}=F$ | 18 N |
| $M=m+M_{board}$ | 6.0 kg |
| $a_{cm}=\Sigma F_{ext}/M$ | 3.00 m/s² |
| 方块速度、木板速度 | 分别随动画时间变化；初始加速度对应 1.47 m/s² 和 3.77 m/s² |
| 质心速度 | 随动画时间变化；质心加速度恒为 3.00 m/s² |

## 阻力场景（drag）

球缩小为它的受力图：重量向下，阻力向上。阻力为 $bv$，因此它随速度增加，直到与重量相等，合力（红色）逐渐消失。加速度为 $g e^{-t/\tau}$：开始时最大，在终端速度时为零。

| 量 | 数值 |
|---|---:|
| 时间 | 以秒计的动画时间 $t$；场景按时间变化 |
| 速度 $v$ | 随场景状态变化；单位 m/s，并以 $v_t$ 的百分比表示 |
| 阻力 $bv$ | 随场景状态变化，单位 N |
| 重量 $mg$ | 4.90 N |
| 合力、加速度 | $4.90-bv$ N，$a$ m/s² |

## 蜂蜜场景（honey）

三个力已经平衡：重量向下；阻力和浮力向上。球处于终端速度，因此频闪图像之间的间距相等。这里的阻力是线性的，因为雷诺数 $\rho vd/\eta$（它比较推动流体和流体黏性的相对程度）远小于 1。

## 张力场景（tension）

每根张力都分成水平分量和竖直分量（灰色）。水平分量大小相等、方向相反，因此相互抵消。两个竖直分量相加等于重量。绳子越平，每个竖直分量越小，因此张力必须越大。

| 量 | 数值 |
|---|---:|
| 角度 $\theta$ | 随场景变化 |
| 每根张力 $T$ | 随场景变化，单位 N |
| 竖直分量 $T\sin\theta$ | $T\sin\theta$ N × 2 |
| 水平分量 $T\cos\theta$ | $T\cos\theta$ N，相互抵消 |

## 飞机场景（plane）

四个力，组成两对平衡力。注意它们不是第三定律力对：四个力都作用在飞机上。升力和重量平衡，是因为飞机没有爬升或下沉；推力和阻力平衡，是因为飞机的速度没有改变。

## 静止场景（rest）

方块缩小为一个点，只留下作用在它上的力：它的受力图。两个大小相等、方向相反的力，因此合力为零，它保持静止。

| 时间 | 随场景状态变化，单位 s |

## 摩擦场景（friction）

实时显示方块上的四个力。向上和向下的力相互抵消。水平方向上，摩擦力会与推力匹配，直到推力超过 9.80 N。之后摩擦力降至 5.88 N，二者之差使方块加速。

| 量 | 数值 |
|---|---:|
| 推力 $F_{app}$ | 随场景状态变化，单位 N |
| 摩擦力（静态或动） | 随场景状态变化，单位 N |
| 合力 | $F-f$ N |
| 加速度 | 随场景状态变化，单位 m/s² |

## 第三定律场景（third）

把两者短暂分开后，这对力很容易看清：A 以 4.0 N 向前推 B，B 以 4.0 N 向后推 A。大小相同、方向相反，作用在不同的方块上。

| 量 | 数值 |
|---|---:|
| A 上的 $F$（外部推力） | 6.0 N → |
| $F_{B\ on\ A}$ | 4.0 N ← |
| $F_{A\ on\ B}$ | 4.0 N → |
| 两者的加速度 | 1.0 m/s² |

## 斜面场景（incline）

把竖直向下的重量替换成沿倾斜坐标轴的两个分量。支持力抵消指向斜面的分量。沿斜面的分量就是合力，因此方块沿斜面向下加速。

| 量 | 数值 |
|---|---:|
| $mg\sin\theta$ | 9.80 N |
| $mg\cos\theta=F_N$ | 16.97 N |
| $a=g\sin\theta$ | 4.90 m/s² |
