海洋系列设计系统

日光海浅色是产品壳默认；深海给地图与沉浸分析；红头周报是体裁变体，不污染看板。以下色板、字号、按钮均来自 tokens.css。

三套主题规则

1 · 日光海

产品壳默认

门户与四盘看板使用浅色体系。海军主色与四盘强调色（蓝 / 青 / 琥珀 / 红）只出现在壳层，不混入周报刊头。

2 · 红头周报

体裁变体

data-theme="gazette" 只给 marine-weekly。机关红是刊头，不是看板主色，避免把周报红渗进四盘。

3 · 深海

沉浸分析

data-theme="deep" 用于地图、节点图。表面改暗，语义色（成功 / 警告 / 危险 / 红涨绿跌）与浅色对齐。

兄弟仓库请链接源文件，不要复制 tokens： <link href="https://wangdwn.github.io/design-system/tokens.css">
